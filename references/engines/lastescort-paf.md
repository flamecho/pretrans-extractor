# NK/PAF ＋ PSCB（GameStudio「ラストエスコート -Club Katze-」）

> 単作専用自研。代表作：**ラストエスコート -Club Katze-（PSP, `ULJS00256`, 2010-02-18, GameStudio / D3PUBLISHER, vndb v3556）**。
> 工具 `scripts/lastescort_extract.py`；報告 `提取結果/解析報告/[PSP-JP]ラストエスコート -Club Katze-_解析報告.md`。

## 1. ISO

- 7z **打不开**此 ISO（`Cannot open the file as archive`），但 PVD 在 0x8000 正常（`CD001`）。
- `scripts/lastescort_extract.py` 内置 ISO9660 walker（PVD root record @0x8000 +158/+166），无需挂载。
- `SYSDIR/BOOT.BIN` = **453,220 B 全零占位**；真代码在 `SYSDIR/EBOOT.BIN` = **明文 ELF**（`7f 45 4c 46`，免解密）。
- `SYSDIR/UPDATE/*` = PSP 固件更新（非补丁）。

## 2. NK / PAF 归档（本作 15 个 .paf 全同格式）

```
+0x00 'NK' | +0x02 u16 count | +0x04 u32 数据总长 | +0x08 u32 hdr(=0x14)
0x14 起 count × 16B：[compSize][uncompSize][nameOff][dataOff]
dataOff 依次按 0x800 对齐累加；本作无压缩（comp == unc）
```
- ⚠ **别用 `[nameOff][x][comp][unc]` @0x0c 的错读**：偏移会碰巧算对（comp/unc 落在对的列），但**索引错位**。
  以 `hdr` 字段（=0x14）为准。
- `nameOff` → 0x3ce4 起的不定长记录（`\0` 结尾，约 17 B/条）。**文件名区被逐位置定值加密，未解**
  （551 条 PSCB 名字仅第 12 字节递增；不影响正文）。⚠ 故**无法靠文件名判定脚本顺序/用途**。
- `script.paf`（77 MB）内容：**PSCB ×551**（文本）／`MIG.` ×141（动画）／`NC4` ×194・`NC2` ×2（二进制）／
  `NK` ×85（嵌套归档，内层只有 `AM` 动画＋`MIG`）。**文本只在 PSCB**。
- 其他 .paf：`bgm`/`voice` = RIFF（41/14445 条）；`album/cal/club/com/help/inpt_nm/logo/prsnt/room/shushi/sys/title/wkly`
  = `AM`＋`MIG`（+`MThd` MIDI/PNG）→ **无文本**。系统消息在 EBOOT 字符串表（按 §0 不收）。

## 3. PSCB 脚本

```
+0x00 'PSCB' | +0x04 u32 ver=2 | +0x0c u32 size | +0x14 u32 codeOff(=0x1c) | +0x18 u32 dataOff
[0x1c, dataOff) = 指令区；[dataOff, size) = 字符串池（NUL 分隔）
```
字符串池 = **按发射序铺开**，故**池序＝显示序**（无需解 VM）：

| 池内形态 | 含义 | 处置 |
|---|---|---|
| `…$k` | 一个文本框（一次点击） | 收；`$r`＝框内软换行 → 合并 |
| 无 `$k` ＋含 `/` | **选项组**（`/` 分隔，一行一条） | 收（`戻る/次へ/終了` 视为 UI 剔除） |
| 无 `$k` 长句，且被 **op `0x36`** 消费 | 叙述（本作仅 `/546` 序章 71 条） | 收 |
| 无 `$k` 其他 | 名札（**姓/名分存两条**：`高岡`＋`いずみ`）／回想菜单「タイトル＋あらすじ」 | 丢 |

### 3.1 指令层自证（本引擎的“不解析 VM”技巧）

- `11 00 30 10`（op 0x11）＝**打印文本框**，参数 `06`,`07`,voice-id（`0xffffffff` = 无语音）。
  **出现次数 == `$k` 串数**：全作 **37,570 : 37,570**，551 脚本**逐脚本 1:1 无例外** ⇒ 池序可信。
- `36 00 20 10`（op 0x36）＝**无 $k 叙述打印**：`/546` 恰好 71 次 == 该脚本开场叙述 71 条。
- 因此**只要统计 op 出现次数**即可校验池解析，不必逆出 opcode 表（EBOOT 内**没有 `PSCB` 字面量**，
  引擎不校验魔数，反查 opcode 表成本高）。

### 3.2 陷阱

- ★ **无 `$k` ≠ 非正文**：`/546` 的序章独白 71 条全无 `$k`（由 op 0x36 打印）。
  判据＝**脚本开头的连续无 `$k` 段** + **条数与 op 0x36 计数吻合**（本作 `lead[:n36]`）。
- ★ **每个剧情脚本开头有「タイトル＋あらすじ」两条无 `$k` 串**（例 `ナンバー１ホスト、流聖` ＋
  `指名に困っていた主人公の席に…`）。`/92` 的说明里直接带 `（グッドエンド）`/`（ボーナスエンド）`
  ⇒ **回想/エンド一覧メニューのデータ**、上屏なし ⇒ 不收。**これがあるため「无 `$k` 长句＝叙述」では判別不能**。
- ★ **调试脚本混在剧本档内**：`/545` 标题就是 `キャラ表示確認/キャラ表示確認（表情連続）/終了`，
  内含 `表情：普通/…`、`サイズＳ/…`、`Ｌサイズはありません。` ⇒ **整脚本排除**（376 条）。
- 同一选项组在池内**按使用次数重复存**（`行く/行かない` 在 `/82` 出现 85 次）⇒ 这不是重复数据，别去重。
- 语音/`$` 控制码只有 `$k`/`$r`（`$p`/`$c7` 等为英文串巧合）；**正文内联人名是字面默认名**（`いずみ`）。

## 4. 成果与核对

- 551 脚本 → **38,359 行**（正文 37,192 ＋ 叙述 71 ＋ 选项 1,096），`check_text.py --name 高岡いずみ` **PASS**。
- vndb v3556 cast 8 名全中（**亞沙斗＝「亞」不是「亜」**）；主角 **高岡 いずみ**（Nameable）。
- 字节闭合：全 `script.paf` 扫长 CP932 串，池外命中**全部**落在 `0x413800` 之后的 MIG 区（二进制误读）。
- **跨脚本顺序 = 归档索引序**（无可用顺序表；序章 `/546`、エンド回想 `/89`–`/108` 落在尾部）。
