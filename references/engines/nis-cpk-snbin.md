# SN.BIN · 记录流与 LZSS

## SN.BIN 包装

SN.BIN 可独立或位于 CPK；CPK 的 TOC/ITOC 定位见[CRI](cri-archives.md)。
压缩变体为 u32 原始长度后 LZSS：4096 字节环、写位置 FEE，LSB-first，1 为字面量。
两字节匹配 `off=b0|((b1&F0)<<4)`、`len=(b1&0F)+3`；按匹配实现初始化环并逐字节重叠复制。
先核对长度、消费与头表，再定位代码及场景范围；不能从第一条日文消息起丢掉整个前缀。

## 记录族

| 结构 | 匹配语义 |
|---|---|
| `4F 0D 00 + u16 flag` | 开页，flag 可指示名札 |
| `46 0D 00 + name NUL` | 名札，可含颜色控制 |
| `45 FF FF + u16 idx + CP932 NUL` | 消息串；其他文本前导按命令表区分 |
| `4A FFFF 6A FFFFFFFF 49 FFFFFFFF` | 收页序列；另有其他尾码变体 |
| `01 00 + idx + 字段 + text NUL` | 选择文案与参数 |
| `4F 03 00 00 + text NUL` | 扉文候选，核对显示调用 |

idx 可为消息序号，跳号不等于漏页。空开页不产生正文。
%N 等源换行与收页分别处理；姓名占位符、色码及正文前缀按当前控制表读取。
共享记录形状只决定解析分派，等待和清窗仍由对应版本确认。
