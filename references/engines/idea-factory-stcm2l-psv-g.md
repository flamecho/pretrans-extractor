# STCM2L —— PSV 侧 · **变体 G**（薄桜鬼 随想録 面影げ花, PCSG00485, CP932）

> 本册是 `idea-factory-stcm2l-psv-cp932.md` 的续册。路由见 `../engines.md`。
> **与 B/D/E 同族（CP932、opcode 恒定、CRI CPK）**，但**分段机制与 B 不同**（`0x4BC` 不是断点击）。

## 容器链路（PSV NoNpDrm）
- 源：目录内 `*.pkg`（`\x7fPKG`）＋ `work.bin`（512 B）。
  **许可证即 work.bin**（content id@0x10、**klicensee@0x50:0x60**）。
- `zzzrif.py work.bin zrif.txt` → `pkg2zip -x <pkg> <zRIF>`（**仅解 PKG 容器**，`data/*.cpk` 仍是 PFS 密文）
  → `psvpfsparser -i app/<ID> -o dec -z <zRIF> -f cma.henkaku.xyz`（**前台+放行网络**；成功 = `keystone: matched retail hmac`）。
- ⚠ **日文路径过不了 `pkg2zip`（MSVC/ANSI）** ⇒ 先用 Python `os.link()` 硬链接到 ASCII 路径再喂 `C:/…`。
  （同样适用于 `psvpfsparser` 的前置步骤。）
- `dec/data/GAME.cpk`（**CPK v7**，`CpkMode=1`，9943 条目）→ `scripts/cpk.py`（TOC 含 `FileName`，`crilayla_decompress`）
  → **`script/*.cl3` ×206**（CRILAYLA 压缩）。`SYSTEM.cpk`＝字体 `.ffu`＋音声；`MOVIE/SOUND.cpk`＝影像/音声。

## 脚本格式

```
脚本头 generator 32B("STCM2L May 30 2012 …") + u32 export_addr@0x20 + …
       "GLOBAL_DATA\0" + globals(u32[]) + "CODE_START_\0"(12B)
指令流起点 = CODE_START_ 偏移 + 12          ← ★+12（不是主册 PSP 的 +24）
指令 = [u32 is_call][u32 opcode][u32 nparams][u32 length] + np×[p0,p1,p2]（三元组 = [值,0x40000000,0x40000000]）
文本记录 = [a][L/4][1][L][cp932][pad]（c==1 且 b==L/4 为签名）；param0 = **文件绝对偏移**（多内联）
遍历自停：ln<16 / ln%4 / 越界 / np>0x100
```

## opcode（**全 128 文件一致，无逐文件 Δ**）

| op | np | 含义 | 处理 |
|---|---|---|---|
| `0x4BA` | 1 | TEXT 正文片段；**空串/仅 `#Color` = 段分隔** | 收 |
| `0x4BC` | 1 | NAME 名札（`土方　歳三` / `雪村　#Name[1]`） | 丢，**同时开新「段」** |
| `0x4CF` | 2 | OPT 选项（p0=文本） | 一行一条 |
| `0x4C0` | 1 | TITLE 回想/章题（`事件想起一`/`土方恋情想起三`/`夢のおわり`） | 收（扉题） |
| `0x4BB` | 0 | WAIT = **一次点击** | 断「点击」 |
| `0x41B`/`0x41C`/`0x41D` | 2 | VAR 按名访问变量/资源（`switch`/`flg_memory`/`file_cnt`/`file_cnt2`/`scene_play`/`thread_cnt`…） | **均断「点击」** |
| `0x3`/`0x1EF` | — | branch | **不断点击**，标记「段」＝互斥备选 |
| `0x462`/`0x469`/`0x0`/`0x6`/`0x1b4`/`0x53F`… | — | 控制/资源 | 忽略 |

★ **本作没有 B 的 `0xb9bc`/`0x19c8c` 文本辅助调用** —— 全库扫描确认**只有 `0x4BA` 承载台词**
（ic=1 调用的日文串全是名字输入用字库、资源 ID）。

## ★★ 两次「分段」（本作核心坑）
- **一次点击** = `0x4BB`/`0x41B`/`0x41C`/`0x41D` 之间的全部内容（**`0x4BC` 不断点击**——与 B 相反！）。
- **段** = 「点击」内按 **空 `0x4BA`** 或 **`0x4BC`** 切出的块。

  | 段间是否出现分支 op（`0x3`/`0x1EF`） | 语义 | 处理 | 实测 |
  |---|---|---|---|
  | **有** | 互斥备选（A=字面默认名版 ↔ B=`#Name[1]`/关系称谓版） | **同段取一**（首段） | 272 |
  | **无** | 同点击内的连续地文（物語モード整页） | **合并成 1 行** | 103（全在 10700-10713） |
- 判别**必须用 op 判据**（不是字符启发式，也不是「相邻重复行」）：
    - 只看「空 `0x4BA` 断行」⇒ 10100 的 8 份同文变体被并成 1 行重复 8 次；
    - 只看「`0x4BB` 断点击」⇒ 物語モード 2 段被并成 1 行（内容对）、
      而 10501 手紙的 A/B 会被合并成重复句 ⇒ 错。
- **6 处真分岐**（A/B 去宏后仍不同，已取一）：10501 `千鶴様`↔`妻君殿`／10502 `【千鶴ちゃん】`↔`【ちゃん】付け`、
  `好きだよ、千鶴`↔`千鶴。君が好きだよ`／10503 `千鶴殿`↔`女房殿`／10504 `千鶴へ`↔`オレの嫁さんへ`／
  10100 `蘭方医【雪村綱道】と`↔`蘭方医、【雪村綱道】と`（多一「、」）。

## 宏・话者名
- 宏仅 `#Color[n]`（0/1/7/12 号 → **删**）＋ `#Name[1]`（→**千鶴**）。
  顺序：**先**换 `#Name[n]` **再**跑通用式 `#[A-Za-z][A-Za-z0-9_]*\[[^\]]*\]`。
- **话者名两形态**：① `0x4BC`（10100-10721 主体）；② **10700-10713 用 `0x4BA` 逐条发出**
  （`#Color[0]近藤　勇` 后紧跟 `「…」`）。判据＝「**≤12 字·无句读·无假名 ＋ 后随 `「『（`**」→ 丢（命中 574）。
  不做 ⇒ `藤堂　平助「捕り物なら…」` 之类的**名前缀残留**。
  ⚠ 该形态名札**自带换框语义** ⇒ **丢的同时要 `flush()` 断「点击」**（否则旁白＋名札＋台词会粘成 1 行）。

## ★ 断点击 op 的完整集合（**勿只认 `0x4BB`/`0x4BC`**）
`0x4BB`(WAIT) ｜ `0x41B` ｜ `0x41C` ｜ `0x41D`（后三者同族「按名访问变量」，np=2，
p0 ∈ {`switch`,`flg_memory`,`file_cnt`,`file_cnt2`,`scene_play`,`thread_cnt`,`thread_cnt2`}）。
**判别法（不靠猜）**：全库扫「**夹在两段 `0x4BA` 之间、且中间不含 WAIT/NAME 的 CTRL op**」，逐个人工看前后句：
- `0x3`/`0x1EF`＝分支 ⇒ 互斥备选（不算断）；`0x6`＝goto ⇒ 变体（不算断）；`0x462`/`0x469`/`0x0`/`0x482`/CALL ⇒ 控制（不算断）
- **唯 `0x41B`/`0x41D` 属漏断**（初版只认 `0x41C` ⇒ 5 处「台词框＋地の文框」被粘成一行，用户实测指出）

## 用語辞典（「覚書」）
- `10013.cl3` = **見出し語＋読み**（**124 B/条**，見出し語 @ +0x00..0x20；`u32 n`@0x00 = 271 条）。
- `10012.cl3` = **解説**（**60 B/槽**；槽尾 `[u32 eid][u32 0][u32 flag]`；**flag==0 为条目分隔符**，其 id 为**下一条目号**）。
- 配对＝**同序号**（10013 第 i 条 ↔ 10012 第 i 条；271↔271 逐条抽验一致）。
- 输出 `【見出し語】解説` **一行一条、不带读音、条内换行合并**，**并入成品末尾**。
- ⚠ 見出し語**自带序号**（`土方歳三【二】`/`伏見奉行所【一】`）＝源数据如此，勿改写。
