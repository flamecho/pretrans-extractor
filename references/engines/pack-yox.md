# PACK / YOX

## PACK / YOX

全大写 PACK 的匹配目录自 0Ch 起，每项 90h 字节：两个 hash、offset、size、CP932 name。
核对成员范围与条目数，YOX 脚本与图像、音频分开。
小写混合 PacK/gzip/标签脚本使用[LTE](lte.md)，不能因发行商相同将两种格式混读。

## YOX

YOX NUL 后有版本或标志、代码及 CP932 NUL 池，文本指令可通过 u32 池内相对偏移取串。
池起点应由头与引用验证，最长可解码后缀只能初筛，不能证明代码与池边界。
@L 可为排版换行，@Vs 可引用姓名，@S/@Y 等控制按完整语法读取。
选择和页面按显示调用确认，不因一串含换行就分作多个选项，不默认池序等于运行时序。
