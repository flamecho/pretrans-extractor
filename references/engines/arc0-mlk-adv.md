# ARC0 / MLK · ADV 文本脚本

## ARC0

匹配布局为 `ARC0 + u32 count + 0x10000B 保留区`，索引自 0x10008 起。
成员 268 字节：`name[256] + u32 size + u32 offset + u32 flag`。
确认偏移基准、索引末及成员范围；保留区是否参与变换由加载器确定，不固定其内容或 XOR 键。

## ADV 文本 DSL

`mes(名,文[,声])`、`p()`、`l()`、`select(文,标签,…)` 由运行时命令表分派。
匹配实现中 p 等待并改页，l 等待而保留页内容；mes 的追加或替换方式须同时核对。
select 仅取显示字段。scene 标题、print 调试及资源串按消费者分类；不能因文字像标题就认定上屏。
