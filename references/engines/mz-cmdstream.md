# MZ 命令流（Marvelous 自研）

> 路由与一句话索引见 `../engines.md`。

- **代表**：**幕末Rock 超魂（PSV / PCSG00425）**（原创 PSP《幕末Rock》的 PSV 加料版）。
- **容器链**：PSV NoNpDrm `.pkg` → `pkg2zip -x`（`work.bin` 同目录自动取授权）→ `psvpfsparser`（**用 `-k` klicensee**）
  → `dec/INST.CPK`（CRI CPK 2.x，`@UTF` **明文**，直接 `scripts/cpk.py`）→ `scene/script/*.bin`、`play/script/*.bin`。

## 脚本格式

```
文件   = "MZ\0\0" (4D 5A 00 00) + 命令流          # 文件即一条命令流，无独立段表
命令   = [u16 op][u16 a] + (a-1)×u32               # a = 整条长度/4；a=0 ⇒ 仅 4 字节头
字符串 = [u16 tag][u16 wc] + wc*4 字节 cp932（尾部 NUL 填充）
        tag 0x0003 = 台词 ; tag 0xFB03 = 资源路径/选项/名字表
```
- **自定界**：`a` 是长度字段 ⇒ 顺序走查**必然到 EOF**（实测 3 作全对，delta=0），无需「文本记录驱动扫描」。

| op | 含义 | payload |
|---|---|---|
| `0x62` | **正文（1 条 = 1 文本框 = 1 点击）** | `[u32 msgid][str tag=3][u32 flag(0/1)]` |
| `0x51` | **选项**（连续多条 = 一组） | `[str tag=FB03][u32 跳转偏移]` |
| `0x2C` | **ライブ歌詞**（`play/*`） | `[u32×6][str tag=3]`；第 2 个 u32 = 时间戳（单调） |
| `0x8C2F` | 名字表（`[str…]`，如「桂/高杉」「龍馬たち」「ト書き」） | **不取**（不加说话人前缀） |
| `0xFB03`(独立) | 另一形式的名字表（「坂本龍馬」「高杉晋作」…） | 不取 |
| `0x4C` | 演职员表（staffroll） | 不取 |

## 关键结论

1. **`msgid` 全局唯一且按显示顺序递增** ⇒ 正文按 msgid 升序排序即得**游戏内显示顺序**，不必猜文件顺序。
   实测 幕末Rock：13,058 个唯一 msgid，跨 78 个 scene 文件呈连续分区间（`OP_002001`=0..87，`m_001..m_010`=130..7954，
   `ED_001..005`=8010..8790，`b_*`=10000..12775，`m_011..m_013`=20116..21743，`b_016..018/ED_006..008`=21792..22864）。
   ⚠ 少数文件（`b_013001`/`b_015001`）是**摘要/复用载体**，msgid 范围与正文重叠 ⇒ 按 `(msgid, 文本)` 去重。
2. **框内换行 = 字面量 `\n`（`5C 6E`，非 0x0A）** ⇒ 合并时删这 2 个字符。字体切换写作 `\fnt0`/`\fnt1`（ASCII 字面量）⇒ 删。
3. **PUA 是「大号标点」字形槽**（cp932 用户定义区）：`U+E000`=**！**、`U+E001`=**？**、`U+E0B1`=**・**。
   判别法 = **前接两字**：断定助动词（ぜよ/じゃ/ます/です）后接「！」，疑问（のか/んだ/だと/かよ）后接「？」。
   同一行内会出现「正文自带小 `！`」＋「PUA 大 `！？`」并存 ⇒ 两者确为不同字形，不是替换槽错位。
4. `play/oto00..28.bin` = **ライブ歌詞（卡拉OK字幕）**：每条记录 = 一个字幕提示单位（长短不一，单字居多），
   其余 PUA 为演出计时标记（无日文）⇒ 整串剔除、剔后无日文者丢弃。**跨记录合并规则不可靠，原样一条一行。**
5. 馆内观看载体（**不收**）：`NOINST.CPK/systemdata/` 的 `ui_skit_*.skt`（幕間劇，`SKTH` 容器）、
   `ui_profile.pfl`（角色资料）、`ui_system_text.stb`（系统消息）。
6. **`staffroll.bin` 也在 `scene/script/`**，别整目录一把梭 ⇒ 按文件名排除。

## 幕間劇容器 `SKTH`（`NOINST.CPK/systemdata/ui_skit_00/01/02.skt`）

- 头 = `"SKTH"` ＋ u32 ＋ u32 `0x10` ＋ u32 `0x1e/0x0a/0x09`；其后为**槽序列**：
  槽 = `[u32 字段]` ＋ cp932 文本（NUL 填充），槽长多为 **0x28(40) / 0x3c(60)**，按 `40,40,60` 成组；
  槽内文本可含 **0x0A 多行**（同一文本框软换行，扫描时勿把 <0x20 一律当终止）＋ 可含 `\n` 字面量。
- 内容 = **52 本短篇搞笑剧**（每本以标题卡开场、以 `『标题』　おわり` 收尾 ⇒ 标题可完整枚举：
  出会いを記念して／桂と龍馬／鬼軍曹桂／龍馬の野望／龍馬の失恋／その後の新選組／酔いどれロック1〜3／
  お登勢殺人事件／桂の発明品／雨に唄えば／近藤の遺産？／熱血高杉／ナデシコ沖田／沖田のバスケ／
  誠仮面の特訓1・2／松陰先生の秘技／しばしのお別れ …）。4 本仅剩占位标题 `スキットタイトルNN`。
- 文本 2,377 槽；**含跨槽「引擎写入回声」（约 25% 重复）**。清洗三步（已实现于 `makumatsu_extract.py::extract_skits`）：
  ① **续行合并**：槽尾 `（「『` 未闭合 ⇒ 与下一槽同属一文本框，先并成一行；
  ② **回声去重**：与最近 4 条已保留行相同 ⇒ 丢弃；
  ③ **孤立闭括号片段**：其内容已在全文别处出现 ⇒ 丢弃。另丢**独立名札行**（行尾全角空格，如 `晋作　`）。
  清洗后 1,767 行。残留：跨本回声（距离>4）、槽内「名札＋正文」粘连（如 `晋作　龍馬くんが…`）未强行剥离。
