## B) RE:VICE[D]（PCSG00382）—— **固定 opcode、CP932、双换框符**

- 容器：**ZIP 型 VPK**（非 NoNpDrm，`data/*.cpk` 明文）⇒ `7z x` → `cpk.py` 直接解 **GAME.cpk**，
  **无需 psvpfsparser**。剧本 = `script/1-scenario/*.DAT` ×82；`2-scene`×69 仅 `\u3000`、`0-init`×6 系统 ⇒ 排除。
  `system/**` 仅 `.tid` 纹理；`database/strSystem.gstr`(GSTB) 系统串表；`db*.gbin` 数值表。**无 用語辞典**。
- **字符串编码 = CP932**（不是 UTF-8）。
- **opcode 为固定常量、无 Δ 平移**：

| opcode | 含义 | 处理 |
|---|---|---|
| `0x4ba` | push 文本片段；**空串（`[0][1][1][4]`+4×0）= 换框符** | 收 |
| `0x4bc` | push 人名札 | 丢弃，但**视为断框** |
| `0x4cf` | 选项（p0=文本，p1=目标） | 收（一行一条、按序） |
| `0x4bb` | 换框 / 等待点击（np=0,len=16，全库 31,667 次） | 断框 |
| **`0x41c`** | **按名访问变量/资源的通用 op**（np=2，param0=名） | **断框** |
| `0x6` | goto（builtin） | — |

- **`0x41b/0x41c/0x41d` ＝「按名访问变量/资源」的通用 op**，param0 即名字。实测名表：
  `switch`（选择结果变量）·`色変化判定`·`中央win`·`flg_memory`·`scene_play`·`adv_part`·
  `リョウガ好感度`/`ヒナツ危険度`/`覚醒度`/`sen01_cnt`…·`res_yuki01〜15`/`res_iro15`…（资源，每文件固定次数）。
- **★ 断框判据＝四元集合**：`0x4bb` ｜ 空 `0x4ba` ｜ `0x4bc` 人名 ｜ **`0x41c` 变量 op**。
  两段文本之间无任一 ⇒ 同框（软换行）合并。
  `0x41c` 断框的字节码证据：其后必跟**新 `0x4bc` 人名**（106 例）或**立绘/背景状态 op**（`0x457`/`0xa538`）
  ——即「状态变更属下一框」，且断点两侧各自是完整语义单元。
  ⚠ 只认 `0x4bb` 会并句；只靠「句中 `」`/`（`」等字符启发式**会漏 100 处旁白段**（25405 − 25305）——
  **必须用 op 判据**。
- **★ 文本记录＝预排版「显示行」**：单条 `0x4ba` 文本**硬上限 28 字**（实测 43,815 条记录的直方图
  峰值 14-17、0 条 ≥30）⇒ **记录 ≠ 框，框 = 连续记录**。因此「相邻记录合并」是本作的正解粒度。
  框记录数分布：1 条 8,824 / 2 条 12,920 / 3 条 2,948（合计 **97.2% ≤3 行**），4〜10 条仅 225 框（0.9%）。
- **两种显示模式（官方截图实证，vndb sf78848-78864）**：① **窗口模式**＝左下带装饰框 + `Name` 牌，
  **满载 3 行**；② **无窗全屏地文**（文字直接叠背景，s52）——长地文用此模式。
  ⇒ 「4〜10 行」的长地文是**脚本层的单条 message**（无任何断框 op），非漏拆。

- **两种「显示文本的辅助函数调用」**（`is_call==1`，op = 函数代码偏移，不是 builtin 号）：
  - `0xb9bc`：np 恒 = 8，参数分两组 `[id][文本…][id][文本…]` ＝**互斥双写变体**（直写名版 / `#Name[1]` 版）；
    实测**恒取第 1 组＝不含 `#Name` 的直写版**（符合规范口径）。
  - `0x19c8c`：np=2，p0=文本（独白段）。
- **`0x4bc`/`0x4bb`/空 `0x4ba` 三者作用**：`0x4bb`→`0x4bc` 是最常见「新框＋说话人」模板；
  紧凑场景（371/372）靠空 `0x4ba` 分行。
- 变量：`#Name[1]`→**アイカ**（主角，Nameable）；`#Color[n]` 丢。全篇无其它宏。
- 行数演算：仅 `0x4bb` 24,467（422 处 `」「`）→ ＋人名 24,778 → ＋空文本 25,209 → ＋`0x41c` **25,405（`」「`=0、引号全配对）**。
- 工具：`scripts/revice_extract.py`（自包含，依赖 `cpk.py`）。
