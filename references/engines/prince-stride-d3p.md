# 引擎：D3P 系「CRI CPK ＋ 自建字符集/位图字体」· 他作 —— プリンス・オブ・ストライド（PSV）

代表作：**プリンス・オブ・ストライド（PSV PCSG00491，2015）**。
与 **STORM LOVER 系列**（见 `stormlover-d3p.md`）**同族**：同为 `USRDIR/sc.cpk`（脚本 CPK）＋ `USRDIR/lt.bin`（字形图集），
基础字符集**同版**（cp932 原码序剔 0x81FC/Greek/Cyrillic/0x849F，`scripts/stormlover_charset.py` 直接复用）。
**逐作差异全部在第 2/3 节**，换作必回查。

## 1. 容器 / 解密
- 源＝Rar5 **未加密**的 **NoNpDrm app 目录树**（`app/PCSG00491/`，文件为**加密态**）。
- **许可证就在包内**：`sce_sys/package/work.bin` → `util/zzzrif.py` 直接生成 zRIF（无需 games.json）。
- `psvpfsparser.exe -i app/PCSG00491 -o dec_app -z <zRIF> -f cma.henkaku.xyz`（**前台 ＋ 放行网络**）；
  成功判据 `keystone: matched retail hmac`。
- `eboot.bin` → ELF：`util/self2elf.py -k …/sce_sys/package/work.bin`（本作 ELF **无** code→Unicode 表 / 名字候选表）。
- `sc.cpk`＝正文唯一载体（**6.0 MB / 272 条目 / 无 TOC 只有 ITOC** ⇒ 条目名＝ID，align 2048，无压缩无加密）；
  `union.cpk`＝图、`pr.bin`/`vo.awb`＝音。

## 2. ★ 条目结构（与 STORM LOVER 不同）
- 条目 ＝ **`0x2000 B 头` ＋ u16 LE 码流**。头部含 u32 参数表（形如 `[u32][pad][u32 递增偏移表]`），
  从 0 直接解码时这些值 < 0xFF00，不会产生伪命令；**条尾**另有「全角空格填充 run（≥6 个 　 ＋ 个别杂码）」需剔。
- 命令集：

| cmd | 含义 |
|---|---|
| `FFF0 <样式><NAME>` | 名札 → 丢弃（**两形态**：(a) `<NAME>` 在本 run；(b) 本 run 只有样式符，名字随后由 `FF4D` 给，中间夹一个**空 `FFFF`**） |
| `FFFF <TEXT>` | 文本框（＝一次点击） |
| `FFFE <TEXT>` | 框内换行（合并） |
| `FFFB` | 消息分隔 |
| **`FF4D <样式><TEXT>`** | **行内关键词/人名插入 → 保留**（样式符**恒为首字**，须无条件剥 1 字，即使该字是 `（`/`「`） |
| **`FF4C <TEXT>`** | 行内续写 → 保留 |
| `FFE6` / `FFE7` | 主角 姓 / 名 占位（宏），且**其后继 run 是正文本体**（`cur += 宏值 + run`） |
| 其余 `FFxx`、`≥0xFE00` | 参数·UI（`FF33` 最多，run 为 1–2 字装饰/参数）→ 丢弃 |

- ★ **同段双写（坑 B24）**：脚本把同一段场景**发射两次**——一次人名**字面**、一次经 FFE6/FFE7 宏。
  归一化后两段全同 ⇒ 需**整段折叠**（`fold_repeats()`，仅紧邻重复时折），否则相邻重复行 ~750 组。

## 3. ★ 字符集：基础区同 STORM LOVER V；二级区**逐作独立**
- 基础区（code < 3456）：`CHARSET[code]`（`scripts/stormlover_charset.py`），**与 STORM LOVER V 同版**（`あ`=209 实证）。
- 二级区（3456..3525）＝本作自用字形槽，`CHARSET[code]` 为 JIS 二级字基线假象，**须查字表**。
- **`lt.bin` 规格（与 STORM LOVER 不同）**：**392 B/字形 ＝ 28 行 × 14 B（4bpp，28×28）**、
  **无头部、索引 == 游戏码**；文件 `1,382,400 ＝ 392×3526 ＋ 192 零填充 ＋ 16 B 哈希`。
  判定链：自相关峰 14 B / 392 B；`あ`(209) 渲染校验。工具 `scripts/prince_stride_lt.py`。

### ★★ 定值法（三证合一，秒级，**不用穷举/不用 OCR**）
1. 字形渲染 ＋ **人工目视单字**；
2. **真实台词上下文仲裁**；
3. ★ **结构性约束：槽序 == 该字在 cp932 中的序号升序**（本作 57 槽**严格单调**实证）。
   用法：先用若干「文脉可定」的槽锚定，再把每个未知槽压到「相邻已知槽之间」的极小候选窗口，据字形挑出。
   ⇒ 一次通过，无枚举。（锚点示例：`3465埃`=3859 ／ `3489璧`=5049 ／ `3494瞰`=5202 ／ `3500腑`=5622 ／ `3512贔`=6148 ／ `3516騙`=6614 ／ `3517黎`=6798）

字表（57 槽）见 `scripts/prince_stride_run.py` 的 `SPECIAL`；完整对照＋锚点句见
`提取结果/解析报告/[PSV-JP]プリンス・オブ・ストライド_解析报告.md` §3。
唯一非汉字槽：`3456 = ─`（U+2500，满格横线；基础区剔了 `0x849F`(＝`─`) 后由游戏重建，用作 `──` 破折号）。

## 4. 成行 / 交付
- 一次点击＝一行；名札（含「空 `FFFF` ＋ `FF4D`」形态）整段丢弃；主角名内联（`NAME_SUB={FFE6:桜井, FFE7:奈々}`）。
- **选项 ＝ 连续 `FFFF` 链**：每条 run 形如 `<样式符><文本>`；**组内首条无样式符、其余恒有 1 个**；
  单符号 run（`　〃`/`　；`/`　ー`）＝**组分隔符**（一链可含多组＝时限制选择的多个分支）；链尾填充 run 剔除。
  **就地输出**（忠于剧情顺序）；链内含系统菜单项（`最初から開始する`/`シーンNから開始する`）时**整链丢弃**。
- 系统/UI 剔除：`ばばば、`／`シーンスキップしました。`（每条目共通导入块，225 条）、
  `クリアデータが存在するため…`／`どのシーンからゲームを開始しますか？`／`「ＶＳ…」…シーンNから…`、
  `試合「…」をスキップしますか？`；**纯人名行**（相手选择菜单残行）用**名札表整表导出**比对剔除。
- 本作**无用語辞典**。

## 5. 主角（外部核对）
- **主角 ＝ 桜井 奈々（Sakurai Nana）**，**不可改名** ⇒ 正文**字面出现**（`桜井` 933 行 / `奈々` 329 行）。
- 名札里主角名经宏 `FFE6`/`FFE7`（口径 `FFF0 <样式> FFE6 FFE7 FFFF <正文>`）；一人称**无宏**（`FF08/FF0F`=0，正文写 `私`）。
- 名札表整表导出（`prince_stride_run.collect_cast()`）＝**零成本 cast 核对**：抽 464 条签名，与动画官网名单**正反双向核对全中**
  （方南/西星/三橋/一条館/花京院 共 30 人 ＋ 游戏原创 河原崎莉子・高原耕一・颯田佳月・黒部加紋 等）。

## 7. 【同族】Vamwolf Cross†（PSV PCSG00467, D3P/VRIDGE, 2015）—— 2026-10-12

**同族判定**：文件集与 プリンス 完全一致（`USRDIR/{sc.cpk, union.cpk, pr.bin, lt.bin, lt26.bin, vo.awb, se.awb}`）；
`lt.bin` 同规格（**392 B/字形＝28×28 4bpp、无头、索引==游戏码**）；基础区码表**同版**（直接复用 `stormlover_charset.py`）。
**但命令分配/容器细节不同，逐作必核**：

| # | 差异点 | プリンス | **Vamwolf** |
|---|---|---|---|
| 1 | 条目尾 | — | **尾 16 B 哈希** ⇒ 解析须 `raw[0x2000:-16]`；**不切会被并入末个 `FFFF` 的 run，产出 ~147 个含 PUA 的假选项** |
| 2 | 正文 opcode | `FFFF <TEXT>` | **`FF95 <3 码前缀><TEXT>`**（前缀恒 3：maxlen / 行数 / 样式）；`FFFF` 空 run ＝ 开框 |
| 3 | 选项 | 连续 `FFFF` 链，非首条剥 **1** 个样式符 | 连续 `FFFF` 链，**非首条恒为「`　`＋样式符」2 码**（首条无前缀）；单符号 run ＝ 分隔/终止 |
| 4 | 开头的表区 | — | `0x2000` 起先有「样式/字符定义表」（`FFE4 FF33 ─ …` 循环，含 `FFFF/FFE6/FFE7` 噪声）⇒ **从该条目首个 `FFF0` 起解析** |
| 5 | 行内宏 | `FF4D/FF4C` | **`FFE6`＝姓 / `FFE7`＝名**；★**宏链**：`FFE6` 后紧跟 `FFE7` 须一并接续（只认「前 token＝FF95/FFFE」会丢名） |
| 6 | 同段双写 | 有，须 `fold_repeats` | **无**（实测块数 0）⇒ **不可折叠**（会误删行） |
| 7 | 系统条目 | 系统行内联 | **`EXCLUDE={0156}`**：条头字段＝`voice_not_exist`，内容全为教程/帮助 ⇒ 整条排除 |

- ★★ **二级区定字钥匙**：**JIS 二级汉字严格按 cp932 码升序**（63 组实测单调）＋「JIS 一级汉字」混排（破坏单调）
  ⇒ 用**单调窗口压缩**（夹在相邻已知槽间）定二级字，用**同字体字形比对/文脉**定一级字。共 114 槽（表见解析报告）。
- 主角 ＝ **白河 セリ**（vndb **v16468**，可改名 ⇒ 只经宏）；内联 `FFE6/FFE7` 填默认名「白河 / セリ」。
- 工具：`scripts/vamwolf_run.py`（提取）· `scripts/vamwolf_lt.py`（字形渲染，`--grid`、`VW_TH`、`VW_SC`）。
  报告：`提取结果/解析报告/Vamwolf Cross†_解析报告.md`。
