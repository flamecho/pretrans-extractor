# VFS3 / PAK

## VFS3

头包含目录表，28 字节目录项后为文件数和40字节文件项：u64 off/cs/us、CRC、ID、folder、u16 comp、i16 dict。
随后指针定位块长表和 UTF-16LE 名称表，成员 off 可相对紧随指针区的数据基址。
zstd 无帧块可共享熵表，依据块长表和解压长度重建完整帧，不能逐块独立解码。
块表有逐文件记录及扁平数组等布局；元数据项、裸存占位与实际块长分别消费，不固定帧头或131072字节分组条件。

## 脚本变体

| 载体 | 结构 |
|---|---|
| PAK word-size 流 | u16 size_words；总长为 size_words×2，参数决定变长头 |
| message 记录流 | u16 total；文本可由01或03及ID、长度承载 |
| talk DAT | 固定索引指向带前缀的 CP932 NUL 载荷 |
| script DAT | 32、u8长度与CP932载荷等类型化文本 |

空记录仍按长度推进，不能用两字节重同步或行首 ASCII 清理修正头长。
R/%n 可能排版换行，FA 等可等待；页高由实际显示配置决定，不按三个物理行固定拼页。
符号字形取当前字符表和图集，姓名宏与图标映射不跨作品继承。
