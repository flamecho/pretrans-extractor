# HuneX「Ogre」系 · PSP 变体 —— 乙女的恋革命★ラブレボ!! Portable（字形码制）

> 由 `hunex-ogre.md` 家族总则派生（2026-10-17）。**本作是该家族里唯一「文本 = 2 字节字形码」的一作**，
> 与 CP932 直写的 カレイドイヴ / マジきゅん 完全不同族。路由见 `../engines.md`。

## 1. 平台 / 源 / 容器
- `[PSP-JP]乙女的恋革命★ラブレボ!!Portable.iso`（ISO9660，2010-04-05）→
  `PSP_GAME/USRDIR/res/script/{scradr.mrg 98,904B, scrbin.mrg 2,877,328B}`。
- **`BOOT.BIN` 全零**（3,926,912B）⇒ 本作必须解 `EBOOT.BIN`（`~PSP`）：
  `scripts/pspdecrypt/pspdecrypt.exe EBOOT.BIN` → `tag D91613F0 type 2` → MIPS32 LE ELF。
- 两个 mrg 都是 **`mrgd00` ×36 成员**：`scradr` = 各成员「剧本名 + 序号 + 偏移」ASCII 表；
  `scrbin` = 各成员 MZX0 压缩脚本流。★★**解压后再整段 XOR 0xFF**（命令名/文本一起 XOR）。
- 脚本语法沿用 Ogre：`_CMD(args);`，文本指令 **`_ZM<8位id>(…)`**（= 一次点击 = 一框）。
  **无 `_MTLK` 名札、无 `_MSAD` 续框、无选择肢指令**（养成选择走 UI 菜单，文本在 `data.afs` 的 CSV 里）。

## 2. ★★ 字形码（本作核心；与 JIS 不是常数偏移）
`_ZM` 内是混合流：单字节 ASCII（`^` `$n`）＋ 2 字节字形码（首字节恒 ≥0xA0）。

```
idx = (b0 - 0xA0) * 60 + (b1 - 0x3F)      # b1 ∈ 0x40..0x7B ⇒ 一页 60 格
  0..134  HuneX 标准字序（" 　、。，．・：；？！゛ヽヾゝゞ〃々〆〇ー―‐～∥｜…‥“"”≪≫《》＜＞＿＋－×÷＝±αβγ（）■〈〉「」『』【】￥＄％＃＆＊＠※○●◇◆□▲♪★０-９Ａ-Ｚａ-ｚ"）
  135     空槽（0 命中）
  136..218 平假名（JIS 区 0x24 原序 ぁ→ん，83 字）
  219..304 片假名（JIS 区 0x25 原序 ァ→ヴ，86 字）
  ≥305     汉字，JIS 区 0x30 起 **行内 94 进**（level-1 全量；本作最大 idx 3330）
```
- 字符来源 `res/ccc/jis2ucs.bin`（`jis2ucs[jis_u16]`，0x10000 项）。
- **定标四条（别重推）**：
  1. `a072/a073` 在 72% 的框首/框尾成对 ⇒ 「」；`a040/a041/a042/a048/a049` ⇒ 　、。？！（框首缩进/句末）。
  2. 字序假设用「HuneX 标准字序」，idx 0..134 与 HuneX 公开实现里的 `Constants.normal_char` 前段逐位吻合（**外部参考，不在本包**）。
  3. 假名段用**频次剖面**定边界：idx139(26,941)=い、idx218(22,398)=ん ⇒ 平假名起点 **136**（≠135）。
  4. 汉字段用「お〔989〕ちゃん＝お兄ちゃん」定基址 305；★**必须行内 94 进**（`0x3021 + n` 的 u16 直加会得到 `駆` 而不是 `兄`）。
- ASCII 内联：`^`(0x5E)=框内软换行（合并、不出行）；`$2`…`$0`=强调（去标记留文字）；`$n`=名字槽标记。

## 3. 名字宏（EBOOT 名字表 @ `0x1e35d0`）
`ヒトミ` / `桜川` / `＊Ｂ` / `一ノ瀬　蓮` / `華原　雅紀` / … 连排（后面接全部名札名）。
- `＊Ｂ` = 主角**姓**（桜川，2 处）／`＊Ｃ` = 主角**名**（ヒトミ，236 处）／`＊Ａ` 0 处。
- 默认名 **桜川 ヒトミ**（可变名）；外部核对：tvtropes／namu wiki／bangumi 一致。
- 佐证：`「私、３年の＊Ｂ＊Ｃです」` ⇒ ＊Ｂ=姓、＊Ｃ=名。
