# Rejet ADV（`PacK` gzip 容器 ＋ 明文标签脚本 `.ald`）

> 一句话：**`PacK` 头 + 0x400 对齐的 gzip 成员流**，成员里是**明文 CP932 标签脚本**（不是字节码）。
> 首作/唯一确认作：**ビタミンR（PSP `ULJS00592`，2013-08-08，D3P/Rejet，vndb v11985）**。
> 判型关键串（EBOOT.dec 串池）：`disc0:/PSP_GAME/USRDIR/PACKFILE.BIN`、`.ald`／`.bnd`／`.lt(lay)` 文件名表、
> `ADV_select` / `ADV_textLF` / `ADV_WORDS` / `jCADV_select`、`CRI Atom`（音频）。**无引擎版本横幅**。

## 1. 源与容器

- `SYSDIR/EBOOT.BIN`（`~PSP`，tag **D91613F0**，`scripts/pspdecrypt/pspdecrypt.exe -o <out> <in>`）→ MIPS ELF。
- `SYSDIR/BOOT.BIN` 与 EBOOT 同尺寸，**未使用**；`INSDIR/DATAINST.BIN`＝`PGD` 加密的 PACKFILE 安装副本（与文本无关）。
- **唯一文本载体 `USRDIR/PACKFILE.BIN`**。

```
PacK 容器
0x00 "PacK"  u32 count=4257        // 实测 4256 个成员 + 1
0x10 16 B × 4257 头部表            // ⚠ 不能用来取偏移，见 §1.2
数据区：gzip 成员，全部 0x400 对齐
```

### 1.1 取成员（可靠路径）

扫全文件的 `1f 8b 08 00`，**每一处都在 0x400 边界上，且 4256/4256 全部可独立解压**
（`zlib.decompressobj(31)`；头里 MTIME/XFL/OS 全 0）。解压合计 165,443,089 B。
成员顺序＝打包顺序：脚本注释 `ファイル名：VTR_01_010.txt` 随序号单调递增，与头部表 `index` 低字节一致。

### 1.2 头部表的坑（别照 offset/size 读）

- 记录 16 B，字段 4 形如 `(x<<8)|index`（低字节＝记录序号），字段 1 ≈ 解压后大小（`0xFE16` 对 PIC1.PNG 65,045 B），
  **没有直排 (offset,size)**；字段 1/3 具体语义未定，**不需要**。
- `identify.py` 会把它判成「无已知魔数 / 熵 8.0 高度加密」——那是 gzip 流的正常表现。

### 1.3 成员类型

| 类型 | 数量 | 判据 |
|---|---|---|
| 贴图 | 1,551 | 头 `texture PSP 1.00` |
| PNG / CRI / 二进制 | 少量 | `\x89PNG`、`@UTF`… |
| **剧本脚本** | **666（含 `<pb>` 的 669 减去 3 个测试稿）** | 明文 CP932 标签文本 |
| CSV 配置 | ~10 | `0010.bin`＝默认名、`0011/0016/0019/0029`＝变量/章题表、`0017.bin`＝**用語辞典**、`0020/0021`＝おみくじ |

## 2. 脚本语法（明文标签）

```text
<block name="…">                 段落（<jump block=> 的落点）
<pb>                             换页            ← ★一次点击
<wait key="true">                等待按键        ← ★一次点击
<textbox visible="on|off">       <textboxtype type="dialogue">
<set position="背景下" object="学校_廊下.png">   <facechange> <move> <clear target=…>
<voice name="KAZ_03780" object="立ち絵中">  <se> <bgm> <effect> <movie> <place>
<select> → \t<case value="选项文本" block="…">   <tkmstart>/<tkmcase value=…>/<tkmend>（ツッコミ机关）
<jump file="vtr_01_010_1">  <value name=…>  <if type=…>  <addlove>/<addscore> <scenarioend>
行内：<tips name="辞書035">肥えた疑惑</tips>  <color value="cccccc">…</color>
      <ruby value="ぶり">鰤</ruby>   ← 保留基底字，丢读音
```

- **文本行**：行首 `＠<名>` ＝名前札 ⇒ 丢（SKILL.md §0）；`＠　`（＠＋全角空格）＝地の文无名牌；
  其余非标签行＝台词/独白。块内物理换行＝软换行 ⇒ 合并（`''` 拼接，只去行尾空白与块首缩进）。
- **注释** `//…` 整行丢（注意存在 `//<pb>＠瑛太` 这种「被注释掉的文本」24 行）。
- **跨行标签**：`<facechange … time="3006"` 换行后才是 `>`（全库 3 处）⇒ 先按「未闭合 `<`」与下一行拼接。
- 换行混用 `\r\n` 与裸 `\n` ⇒ 一律 `splitlines()`。

### 3b. 双产出（本族必做；skill `S6-lines-dual.md` §2）

`<pb>` 与 `<wait key="true">` 语义不同（清框 vs 不清框），两条都是「一次点击」⇒ **同时出两版**：

| 文件 | 口径 | 本作行数 | 交付 |
|---|---|---|---|
| **`X_全文本_双版对照.txt`** | 同框先列各段再列合并行（`A,B,C,ABC`；单段框不重复） | 46,229 ＝ 45,655 ＋ 574 个多段框 | ✅ **唯一交付** |
| `X_全文本.txt` | 一次点击 = 一行（两处都断） | 45,655 | 中间校验（`--all`） |
| `X_全文本_一框一行.txt` | 一个文本框 = 一行（只在 `<pb>` 断） | 44,683 | 中间校验（`--all`） |

判定 B 类（`<wait key>`）成立的三条实测：**0/972 重报名牌**、**969/972 后接 `　` 占位行**、
**972/972 位于正文中缝（段首 0 处）**。闭合＝点击版 − 972 ＝ 页版；页版每行均可由点击版相邻行直接拼接（0 处不一致）。

## 变体 B：`PACK` 容器 ＋ `YOX` 串池字节码（スカーレッドライダーゼクス STARDUST LOVERS，PSP，2011-12）

> 同一发行/同一构建链（EBOOT tag `D91613F0` type 2），但**容器与脚本体都不同**：
> `PacK`+gzip+`.ald` 明文标签 ≠ `PACK`+`YOX` 字节码。判型时先看 `USRDIR` 里是 `PACKFILE.BIN` 还是 `image.bin`。

### B1. 容器 `USRDIR/image.bin`

```
0x00 "PACK"      u32 count = 345
0x0c 表项 ×0x90  [0]=hash [1]=hash [2]=offset [3]=size   name@+0x10（CP932，NUL 结尾，最长 0x74）
```
- **`[2]/[3]` 直排可用**（不同于 `PacK` 的 `(x<<8)|index` 陷阱）；`[0][1]` 是散列，无关。
- 闭合：`Σ size = 1,227,749,106` ＋ 表头 0xc21c ≈ 文件 1,228,181,951。
- 条目：`SCRIPT/**.SCE` 163 ／ `P/P###_###.BIN`（粒子 `EFFECT2`）122 ／ `PSMF/*.PMF` 29 ／ `SOUND/*.AT3` 27 ／ 其余 icon/texture/font。
- `INSDIR/IIMAGE.BIN`＝安装副本，忽略。

### B2. 脚本 `YOX`（`.SCE`）

```
0x00 "YOX\0"  u32 flags(0x10000000)  u32 …       // 头部 0x10〜0x20（含 2011/09 编译日期）
0x20 …………………  指令流（op + 定长参数；文本 op 以「池内相对偏移」u32 取串，如 `1e 04 <off>`）
<pool>           串池：连续 NUL 分隔明文 CP932，末条 "<脚本名> - end"（少数写作 `tr_00_000 - end`）
```
**取池（免反汇编）**：取「能按 CP932 线性解到文件尾的最长后缀」——合法字节集 `20-7e` / `a1-df` / 双字节 `81-9f,e0-ef`+`40-fc`；
163/163 脚本 0 例外，末条 `- end` 可自校验。**池序＝编译序＝显示序**（逐文件读通、跨文件连贯）。
