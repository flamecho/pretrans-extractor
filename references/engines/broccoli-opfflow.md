# Broccoli · OPF 指令流

## OPF 流

匹配记录以 `FF <op> <u16 id LE> <u16 b> <u16 c> …` 起，头长随命令而变。
op0A 可携带文本样式，op00 可为四字节头文本；op0E 可承载选择和收束操作。
样式 ID、姓名槽及 ruby 类型按当前表解释，不固化作品样式编号。

## 解码与显示

文本可逐字节 XOR FF 后按 CP932 解码。填充与 NUL 按所在视图区分：raw FF 取反为 NUL，raw 00 取反为 FF。
ruby 的基底、读音及续文分别读取，不固定取字符串后半。
空文本、等待与清页配合定义边界；页内改行和演出码由字形表及处理器确认，不能按圈号外观统一删除。
