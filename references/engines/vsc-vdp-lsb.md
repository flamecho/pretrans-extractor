# VSC · VDP 容器 + LSB 脚本（ラスト・エスコート2 等 / ヴァンテアンシステムズ）

> ⚠ 同社早期（2004）另一套格式：`DATA/TML/TMLPACK.PAC` + `*.TML` 字节码 + `vlLZSS`，见 `vsc-vl-file-tml.md`（召しませ浪漫茶房）。
>
> 实例：ラスト・エスコート2 ～深夜の甘い棘～（`SLPS_258.45`, PS2, 2008-02-21, vndb v1980）。
> ⚠ **同系列前两作（`SLPS_255.91` / `SLPS_256.73`）是 `DATA2/ADV.FPK` + `.VML`（另一套格式，见 `d3p-ps2-fpk-vml.md`）**。
> 判型：ISO 根有 `DATA/*.VDP`（而非 `DATA2/`）、ELF 无 `ADV.FPK`；`*.VDP` 头 = ASCII `VSC_VDP_FILE`。

## 1. 识别特征

| 看什么 | 值 |
|---|---|
| ISO 根 | `SYSTEM.CNF` + `SLPS_xxx.xx` + `DATA/`（`SYSTEM.VDP` `GIMAGE*.VDP` `VOICE_*.VDP`）+ `SOUND/` `MOVIE/` |
| 归档 | `VSC_VDP_FILE` 魔数；脚本全在 `DATA/SYSTEM.VDP` 的 `SCRIPT` 条目 |
| 脚本后缀 | **`.LSB`**（本作 765 个）；正文是 **cp932 NUL 结尾串**（不是 JIS 7bit！） |

## 2. 容器
```
ISO → DATA/SYSTEM.VDP
  0x800 起条目表，每笔 0x34：name[16] + 16B(0) + u32 flags + u32 size + u32 ? + u32 indexOff + u32 dataOff
  flags 低 16 位 = 条目数
SCRIPT：indexOff 处 765 笔 × 0x28（off@+0 / size@+4 / name@+0x10），dataOff 处数据（0x800 对齐）
```
工具 `scripts/vdp.py`：`list` 列条目 / `x <条目名> <outdir>` 导出（自动校验每条首 u32 == size）。

## 3. LSB 结构
```
0x00 u32 size / 0x04 u32 cmdCount / 0x08 u32 ? / 0x0C u32 cmdTableOff(0x58)
0x10 u32 bodyOff / 0x14 u32 0 / 0x18 场景名 cp932（不渲染）
```
正文区 = 一串 NUL 结尾 cp932 串，**语义由串的邻近关系决定**：

| 形态 | 判定 | 含义 |
|---|---|---|
| 名札＋正文 | 两串**紧邻**（名札 ≤8 字，正文紧随） | 一次点击 |
| 主角行 | `26 00` 紧邻正文串 | 名札 = `0x26` 名宏（只 1 字节，不成串） |
| 选项 | `ff`×4/8 + `cc`×4 + `[u32 A][u32 B]` + 若干紧邻串 | 选择肢 |
| 孤立串 | 前 8 字节为字段（u32 `<0x01000000` 或 `-1`） | 旁白/字幕（扉文、时间跳跃） |

★ **不要硬解消息头长度**：`[u32 op][u32 id]` 之后可能跟 4/8/16 字节字段，op ∈ {0,1,2,4,0x82,0xFE…} 长度不定。
按「紧邻串对」判定即可，前作 `ADV.FPK` 的 `68/64/F6` 记录式**不适用**。

## 4. 正文内控制字节

| 码 | 语义 | 处理 |
|---|---|---|
| `0x5C` / `0x23` | 同框软换行 | 合并（本作 14,769 / 163 处） |
| `0x26` | 主角**名** | inline（后随「ちゃん」949 例） |
| `0x25` | 主角**姓** | inline（`%さん` / `%　&` 全名） |

**校验判据**：合并后每框 1–3 行（1:12,100 / 2:6,958 / 3:3,902），**单段 ≤18 全角字** ⇒ 18×3 文本框成立。

## 5. 主角名
ELF 名槽 = **两个 8 字节定长槽（名 在前、姓 在后）**：
`0x10CBD8 / 0x10D340 / 0x10F098 / 0x1100A0` → `芹香\0` + `安藤\0` ⇒ 默认 **安藤 芹香**（vndb c35939）。
全 765 个 LSB 里字面 `安藤`/`芹香` **出现 0 次** ⇒ 姓名只经宏插入，无「字面姓氏是别人」的坑。

## 6. 易错
1. **别按 JIS 7bit 解**（那是前两作）；本作就是 cp932，`+0x80` 会全错。
2. 串内允许出现 `0x20–0x7E` 单字节 = 控制码（`0x25/0x26/0x23/0x5C`），解析时不能当 ASCII 拒绝，也不能当正文留下。
3. 串首尾常粘 1 字节结构量（长度字节，如 `0x41`=`A`）⇒ 交付前裁掉纯 ASCII/半角残片。
4. 选项块前导可能是 `ff`×8 或 `ff`×4（两种写法都出现过）。
5. `..\` 断串：源数据存在 `帰って` + `82 22`（非法尾字节）这类截断串，`read_str` 会拒收 ⇒ 属源缺陷，别硬拼。
6. 去重：`VZ1xxx` 整批复刻 `VZ0xxx`（本作 124 个文件正文完全重复）。

## 7. 工具（工作区 `scripts/`）
`vdp.py`（VDP 解包）/ `lsb.py`（LSB 解析成行）/ `build_ls2.py`（全文本+折叠+垃圾过滤）/ `check_text.py`（品检）。
