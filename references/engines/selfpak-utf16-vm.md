# SelfPAK · UTF-16 VM

## PAK布局

头可含data_start、块数、版本、名称表位置；块表有20h或28h起点、size累积、align4及仅入口等变体。
按头与加载器确认字段，不默认第一个表字段为offset或所有末块延伸到EOF。
数据流可跨块；仅在块表是入口索引时连续解析再按起点归属，独立成员仍遵守各自范围。

## UTF-16文本记录

| 布局 | 读取 |
|---|---|
| 0321加四个u16，可带0060 | 长度和NUL共同验证，named/plain分别解释 |
| 0323加四个u16 | 可无0060，并含后置语言段 |
| u16长度、0060、文本 | 长度单位与NUL是否计入按版本确认 |

后置UTF-8段可使下一记录落在奇数地址，不能整段固定两字节步进。
记录尾mark有u16和u8两种位置；05/0B等语义须从当前处理器确认。
自动推进、点击与清屏分开，不根据括号是否闭合推定续页。

## 模板、词条与选择

姓名可用@分隔或内联，ruby为`$[基底$/读音$]`，样式、姓名和词条引用按完整语法扫描。
`#`等分支分隔不能固定取第一版；选择标签40xx、分隔$d及嵌套条件前缀须结合命令表读取。
词条有样式串及字段式布局，字段len/NUL与变长附属命令共同定界。
缺字、姓名及版本映射以当前字体和初始化数据为准，不保存作品专用字符替换。
