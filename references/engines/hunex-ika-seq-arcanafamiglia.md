## 7. ★★ 压缩变体：アルカナ・ファミリア フェスタ・レガーロ!（PSP，2012-12-13，HuneX）

> 与 Real Rode **同族但升级**：文件头标识 `IKA SEQ SYSTEM v3.4 HuneX 2009`（AFS[0]/[1]）／`v4.2 HuneX 2011`（AFS[2]）；
> ELF 里另有 `IKA SEQ VER4.3`。**Real Rode 的明文 HFU2 在这里被逐块 LZSS 压缩**。

### 7.1 源 / 容器
- 源：ISO9660 → `PSP_GAME/USRDIR/DATA/GAMEDT.AFS`（CRI **AFS**，7 成员）。`0FLIST.DIR` 列 GAMEDT/VOICE00/VOICE01/VOICE_SYS.AFS。
- 成员：`[0]`ADVDT(85 MB,HFU2×1413)＝表情/动画库／`[1]`GAMEDT(16.7 MB,HFU2×95)＝UI+**ワード辞典**／
  `[2]`**SCRIPT**(5 MB,HFU2×273)＝剧本文本／`[3]`CRI 数据／`[4]`SE／`[5][6]`BGM。**文本只在 [2]（＋[1] 的辞典）**。
- `SYSDIR/BOOT.BIN` **全 0**；真码在 `EBOOT.BIN`（`~PSP`）→ `scripts/pspdecrypt/pspdecrypt.exe` 解出 MIPS ELF。

### 7.2 HFU2（本变体的坑）

```
"HFU2" + u32 count + u32 X + u32 1 + count×16B{u32 off,u32 size,u32 size2,u32 hash}
★ 绝对块位置 = X + off[k]（X = 头部大小，AFS[0]=0x6000 / AFS[2]=0x1800）
  size = 16 + payload_len ; size2 = 解压后长度
```
- ⚠ **`off` 是相对 X 的偏移，不是绝对偏移**（Real Rode 是绝对）⇒ 同引擎跨作可变，**逐作实判**。
- 块内：`'UFFA' + u32 payload_len + u32 out_size + u32 0 + u32 0`（16 B）→ 载荷自 +16 起。
- ❌ 试图「按 `off[k]`..`off[k]+size[k]` 逐块独立解压」会 **272/273 全短**（流其实以 UFFA 头对齐，读越界才够）。

### 7.3 LZSS（`cLz.cpp`，经典 Okumura）
- dict `0x1000`；**dictpos 初值 `0xFEE`**（= 0x1000 − 0x12）；dict 清零。
- `flags >>= 1`；`(flags & 0x100)==0` ⇒ `flags = src[i] | 0xFF00`；**bit0 = 1 ⇒ 字面量**。
- match（2 B）：`off = low | ((high & 0xF0) << 4)`、`len = (high & 0x0F) + 3`。
- ⚠ **不要加 `+MAXLEN`**；BELIEVER! 的 HLZS 要 `+0x12` 且另有 0x20 头 —— **属 HESL/UNAS 族，不可套用**。
- 实证：`EBOOT.BIN.dec` 解压器 `0x08894AFC`，调用方 `0x0889491C`（`dictpos=0xFEE`／`memset(dict,0,0x1011)`／校验 `UFFA`）。
  正确定义下 **273/273 块解压长度全中**、`5C` 记录有效率 **97.4%**。

### 7.5 ワード辞典（用語辞典）
- 载体：`GAMEDT.AFS[1]` 解压流内 `0x27b050` 起、**116 条**、固定记录 `0xF0 B`：
  `[12B 头][見出し語 NUL 终止][解説（`\x00`=换行，NUL 填充）]`。
- 見出し語字段**非定长**（`フェリチータ（初期設定）` 24 B），取「首个 NUL 之前」。
- 输出：`【見出し語】解説文` 一行一条、不带读音、并入成品末尾。

## 8. 幽霊船の魔術師（PSP，2012-06-21，`IKA SEQ SYSTEM v3.4`，vndb **v10272**）

> 与 §7 **同容器/同压缩（UFFA+LZSS 参数逐条一致）**，但 **X、命令集、宏、有无辞典 全不同** ⇒ 同族**必须逐作实判**。

### 8.1 容器与成员（`GAMEDT.AFS`，7 成员）
- 剧本＝**AFS[2]**（HFU2×126，**X=0x800**，解压 7,663,600 B）。Festa 的 X=0x1800 ⇒ X 逐作变。
- `[0]`表情/动画（192 MB 解压）／`[1]`嵌套 HFU2×7（二进制，无正文）／`[3]`嵌套 HFU2×10＋`(c)CRI`（媒体）／`[4]～[6]`SE/BGM。
- `BOOT.BIN` 全 0；`EBOOT.BIN`（~PSP）用 `scripts/pspdecrypt/pspdecrypt.exe` 解（tag `D91613F0`）→ MIPS ELF。

### 8.2 文本命令（**比 Festa 少**；无 `0x80`/`0x78`）

| cmd | n | 语义 | 条数 | 处置 |
|---|---|---|---|---|
| `0x3E` | 1 | 名前札 | 11,965 | 丢 |
| `0x4C` | 1 | 複数名札（`リベルタ他`） | 38 | 丢 |
| `0x3C` | 3 | 台詞/地の文 | 11,966 | 收 |
| `0x4D` | 1 | 複数名の後のセリフ（合唱 `『魔術師』『愚者』`） | 38 | 收 |
| `0x41` | 4 | 選択肢（連排=同組） | 1,031 | 只取串 |

- **字节闭合**：成员[2] 内 25,038 条 `5C` 记录 **100% 归入 {名札, 正文, 选项}** ⇒ 无第 4 类载体，无遗漏。
- 引号：**`「」`=0**（原文不用）；`『』` 才是原文引号。唯一缺陷＝`『お嬢！お嬢様……` 缺闭合 `』`（源字节本无）⇒ skill `pitfalls/C-deliver.md` ⑧ 整行定值表补。
- **本作＝无声主人公**：名札 38 种里**无 フェリチータ**、全篇正文都带名札 ⇒ 主角唯一的「台词」是**選択肢**（非提取缺陷）。

### 8.3 ★★ 主角名宏 `＄`（全角 U+FF04）—— 两作通用，此前 Festa 漏判
- 正文中 `＄` 只出现在 `0x3C`，且**只后接 3 个固定串**：`＄フェリチータ`／`＄フェル`／`＄フクロータ`（主角名/昵称/宠物名）；
  这三个词在正文中 **100% 带 `＄`**，其余人名（リベルタ・ノヴァ・デビト・ルカ・ダンテ…）**0%**。
- **决定性证据**：EBOOT 解密 ELF `0x1c79dc` 处有名字槽默认值表 **`＄フェリチータ\0\0＄フェル\0\0\0\0＄フクロータ\0\0\0\0`**
  ⇒ `＄<默认名>` ＝ **姓名槽插入宏**（引擎以槽当前值替换整段 `＄X`）。
- **处置＝删 `＄`、保留默认名**（主角名 inline）。⚠ 与 §7.4 的 `＠`（显示名＠内部名）**不是一回事**。
- 通用教训：**「字面名 vs 宏注入名」必须分开判**；判定钥匙＝**引擎字符串表**（EBOOT/ELF 里的 `＄<默认名>` 表）比正文词频更硬。

### 8.4 用語辞典：**本作没有**
- EBOOT 内 `辞典`/`用語`/`ワード` = **0**（仅 `セーブ`/`ロード` = 系统 UI，按 SKILL.md §0 不收）；成员[1]（Festa 辞典位）为二进制、无成句日文
  ⇒ 成品只含正文＋选项，**不产出附属文件**。

### 8.5 成品
`提取结果/アルカナファミリア_幽霊船の魔術師_全文本.txt`（**13,035 行**＝正文 11,966＋複数名セリフ 38＋選択肢 1,031）；
`check_text.py --name フェリチータ` → PASS（残留 [W] 相邻重复行 28＝原文重复）；重复度 6.5%（多路线共场景）。
外部核对：vndb v10272 cast 12 人，除 **`ヨシュア`（游戏内统一写法）vs vndb `ジョシュア`** 的拼写差异外全中。
