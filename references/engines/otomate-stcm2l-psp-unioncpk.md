# STCM2L · PSP「UNION.CPK」侧（アンジェリーク 魔恋の六騎士）

> 路由见 `../engines.md`。同族另见 `idea-factory-stcm2l-psp-cpk.md`（SBL/アーメン/ガーネット/Jewelic/マイナスエイト）。
> **本作是同族第 6 样本，且记录布局与前五作都不同 —— 别套 k=12。**

- **作品**：アンジェリーク 魔恋の六騎士（PSP **ULJM05986** v1.01，2011-11-17，**Otomate**，vndb **v8799**）。
- **容器链**：`*.chd`(v5/zstd) → ISO9660 → `PSP_GAME/USRDIR/UNION.CPK`
  （CPK v7，**TocOffset=0 ⇒ 无文件名**，条目名＝纯数字 ID；`INSDIR/UNION.DNS` 是同内容 **PGD 加密副本**，
  `pgdecrypt` 解出 230,482,016 B ＝ 与 `UNION.CPK` 同尺寸，白解）；`STREAM.CPK`＝HCA 语音、`MOVIE.CPK`＝视频、
  `SYSDIR/BOOT.BIN` 2.5 MB 全零。
- ★ **EBOOT 是明文导航牌**：`~PSP D91613F0 type2` → 解出 ELF，串表含
  `ART2 / MGP2 / STCM2 / CLC2` ＋ 目录 `system/sub/script/back/chara/etc/sound/memuni` ＋ 格式 `%s/%05d`
  ⇒ 数字 ID 即路径；剧本段＝**id 03000〜03639（406 个）**。
- ★ **剧本文件数闭合技巧**：CRILAYLA 块尾保留 0x100 B 未压缩原文头 ⇒ **raw 搜 `STCM2L` 的命中数＝剧本数**
  （本作 406/406）。同理可用来判断「文本是否只在这些条目里」，不必逐条解压。
- **记录布局（与 マイナスエイト 不同）**：`payload = 48B 参数头（4×(ptr,color,color)）+ 文本记录链`，
  正文记录的 `k` **不固定**（48 / 36 / 24 皆有）⇒ 必须「从 0 起 4 字节步进 + 失步重同步 + 命中即跳记录尾」，
  不能写死 `k==12`。一次点击 = 一个 unit；框内多记录合并成一行。
- **选项**：`SEL_nnn` 组标记 + 逐条选项文本，末端 `select`；一个选择支可出现 `SEL_nnn` **两次**
  （4 选项＝`SEL+2选项+SEL+2选项`）⇒ 取「首个 `SEL_` 到 `select` 之间的全部选项 unit」。
  ⚠ **选项文本不能过「裸名过滤」**（`一生懸命に帰りたいと頼む` 这类短句会被误删 93 条）⇒ 选项 unit 先标记再放行。
- **名札**：每档固定 **49 条裸名辞書**（7 骑士×3 组 + `序章/1章…終章` + `レジェッタ/ヴィ/セラ/シャロン` + `処理開始`）
  → 全部丢弃；行内名札用「≤12 字・无句读・下一条以 `「`/`（`/`『` 起头」判定，`#Name[1]` 名札同规则。
- **主角**：**テレサ**（Nameable）。`#Name[1]` 7,099 处，其中 **6,866 处是名札** ⇒ 行内仅 233 处，
  与 `check_text --name` 的 233 完全吻合（可当宏覆盖率自校验）。脚本内字面 `テレサ` 仅 3 处（条件/默认名表）。
- **排除**：3021＝シーンあらすじ表（`穏やかな日々`/`軋む日常`…）、3020＝シナリオ表（396 个 `EVxxx_xxxx`）、
  3019＝システムメッセージ、41000–51999＝音声/动画键小表（u16 对，无文本）。**本作无用語辞典**。
- **原文手误（不改写，报告留证）**：`…会えるの？]`（ASCII `]`）、`『…手紙にしてみたんだ」`（`『` 开 `」` 收）。
- 工具：`anki_unpack.py`（分块解包，避开本机 ~200 MB 解析峰值）＋ `anki_extract.py`。
