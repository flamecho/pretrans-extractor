# 引擎：BROCCOLI / Sanctuary・EMIQ `ADV`（`MES.DAT` ＋ ±0x20 CP932 シフト）

> 代表：**恋戦隊LOVE＆PEACE THE Ｐ.Ｓ.Ｐ.**（PSP, 2012-08-30, vndb v8092）
> 工具：`scripts/lovepeace_extract.py`（容器→コマンド→成行 一発）

## 1. 容器

`PSP_GAME/USRDIR/MES.DAT` に全脚本（195 個の `.MES`）。ヘッダ：

```
+0x00 u32 count
+0x04 count × 0x40：[+0x00 u32 size（※信用しない）][+0x04 name[0x20]][+0x3c u32 offset(0x800 整列)]
0x618 以降データ
```

★ **`size` は隣ブロックと 1 個ずれる**（実測 `size[i] == 実長[i-1] - 4`）⇒
**ブロック境界＝次エントリの offset、実長＝末尾ゼロ詰めを Trim** で取る。
★ `.MES` ブロック内ヘッダ：`[u32 n][u32 ver=3][n×u32 記録 offset][(n-1)×u16 ?]`、
**コマンド開始 = `8 + 4n + 2(n-1)`**（n はブロック先頭 u32）。145 ブロックで全成立。
★ データ末尾の後ろに**非ゼロのゴミ領域**が残る ⇒ `0x00` が 64 連続したら終端とみなす。

別 DAT：`RES.DAT`＝資源索引（36 条、`[u32 size][name[0x18]][u32 offset]`、索引の後ろに `NAMES.DAT` 資源名表が連結）、
`GRP.DAT`（頭 `\0PGD`、圧縮画像）、`SE/MUSIC/VOICE.DAT`。`BOOT.BIN` は**全零**、`EBOOT.BIN` は `~PSP`（`mod_name`=`lovep`）。

## 2. 文字コード（本エンジンの核）

**格納バイト `b` → `(b + 0x20) & 0xFF` を CP932 として解釈**。すなわち SJIS 各バイトから `0x20` を引いた形。
- ELF 実証：`0xf548` 付近 `lb $v0,($t3) / addiu $a0,$v0,0x20 / sb $a0,($t3)` の逐字节ループ。
- `0xEA` → `0x0A`（8bit 溢れ）＝**同一ボックス内の軟改行** ⇒ 成行時に結合。
- **表示用文字列（op `0x4e..0x51`）のみシフト**。資源名（`VOICE\…`/`BG\…`/`SYSTEM\…`、op `0x2b..0x4d`）は**生 CP932/ASCII**。
- 行内マーカー：`@l`＝大文字タグ（剥がして文字は残す）／`｛ヨミ／親文字｝`＝注音ルビ（親文字を採る）／`$f`=姓・`$n`=名 の主人公マクロ（正式名で inline 置換）。

## 3. 命令長（ELF 0xf420 の二分探索ディスパッチ）

| op | 長 | 意味 |
|---|---|---|
| `0x00..0x2a` | 3 | `0x03 <u16>`=消息 ID／`0x07`=框尾(クリック待ち)／`0x04,0x05,0x08,0x09`=選択組の前後／`0x0e`=数値引数 |
| `0x2b..0x4d` | 1+str+1 | 生文字列。`0x2c`/`0x34`=BG、`0x32`=ラベル、`0x35`=文字列、`0x37`=**ボイス**、`0x3e`=`return`、`0x44`=選択 ID |
| `0x4e..0x51` | 1+str+1 | **表示用（+0x20）**。`0x4f`=**名札**／`0x50`=**本文**／`0x51`=**選択肢** |
| `0x52..0x70` | 9 | 演出/画像/效果 |
| `>=0x71` | — | コマンド流には現れない（現れたら末尾ゴミ） |

選択組：`32 <label>` → `04` → `08 01 00` → 反復(`44 <sel_n_xx>` ＋ `51 <選択肢>`) → `09 00 00` → `35 <sel_n_01>`。
⇒ `0x51` の数 == `0x44` の数（745:745）。

## 4. 成行・排除

- 一次クリック＝`0x50` 1 個＝1 行。`0x07` は框尾。名札 `0x4f` は**全捨**（話者接頭辞なし）。
- 収録：`JPROLOGUE1..5` ＋ `J01..J06`（6 路線 × 10 章 × 前後編）＋ `J0N_PSP_XX`（各路線の後日談→その路線の末尾）。
- 排除：`ADVMENU/AUTOSAVE/OPTION/SAVE/LOAD/QSAVE/QLOAD/MANUAL/MUSIC/SHOP_MODE/NAMESET/RTITLE/SC_END/MC_INIT/START/MAIN/MAIN0/LOG/DEBUG`
  ＋ `CG_*`/`SCE_*`（0 条の `0x50`）＋ `DB_*`（図鑑・メール・效果表；`DB_SCEFF` に `※ランダム動き量0` 等の制作注記のみ）。
- システム確認文（`セーブしますか？` 等）は全て排除側のファイルに**生 CP932**で存在。

## 5. 実績

恋戦隊LOVE＆PEACE THE Ｐ.Ｓ.Ｐ.：145 ファイル → **38,327 行**（本文 37,582＋選択肢 745）、
ブロック失步 0（全 145 ブロックがブロック尾 64 B 内に着地）、`0x50` 数 == 行数（1:1）。
主人公 **正義 愛子**（`$f`=正義／`$n`=愛子）。
