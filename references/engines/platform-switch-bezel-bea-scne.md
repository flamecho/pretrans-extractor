# Nintendo「Bezel Engine」＋ `.nx.bea`(SCNE) 剧本读取

> **触发**：romfs 里有 `boot.lua`（内容含 `BezelEngineInitializer`／`BezelColor`）、
> `Archive/*.nx.bea` 一大堆、**没有** `Data/Managed`。⇒ **不是 Unity**，别去找 Assembly-CSharp / TextAsset。
> 2026-10-26 首次打通（even if TEMPEST 連なるときの暁，NS，keygen 16）。

## 0. 一句话链路

```
NSP(PFS0) → 单个 Program NCA（Titlekey crypto, keygen 16, romfs 未压缩 7.5 GB）
  └ Archive/static~NN_MM.bin.nx.bea   ← 每章一个
       └ .bea = SCNE 容器，**负载是 zstd**（magic 28 B5 2F FD）
            └ 解出 BIN_ 字符串池：一个字符串 = 一个文本框 = 一次点击
```

⚠ 别被「SCNE 不是 zlib」误导：本轮上游代理试 zlib/LZ4/LZSS 都失败而误判「块格式未知」，
**实际负载首 4 字节就是 zstd 魔数 `28 B5 2F FD`** —— 先扫常见容器的魔数，再谈逆向。

## 1. 取 romfs（不必落 7.5 GB 副本）

`scripts/nsp_plainromfs.py`：PFS0/NCA → 未压缩 romfs **就地 list / get**，直接按偏移读，不切大文件。

取键要点：
- 内容密钥 = `AES-ECB-dec(titlekek_0f, tik[0x180:0x190])`
- 段 CTR = `LE-u64(fs头 +0x140) << 64 | 段内绝对偏移/16`
- **keygen ≥ 16 ⇒ `_sw/merged.keys`**（`prod_fixed.keys` 只到 `titlekek_0f`）

## 2. `.nx.bea` = SCNE 容器 + zstd

解 zstd 后得到 `BIN_` 字符串池，实测布局：

| 偏移 | 内容 |
|---|---|
| `0x0C` | 字符串数 `N` |
| `0x18` | 字符串区 base |
| `0x1C` 起 | `N × u32` 偏移表 |
| 池内顺序 | **[ID/标签块] + [日文块] + [英文块]**（两语言等长） |

**自证（必做）**：`0x1C + N*4 == base`（本轮 30/30 文件全部满足）。
该判据能一次性排除「偏移表算错/漏了头部字段」这类错位。

## 3. 成行（L0）

**一个字符串 = 一个文本框 = 一次点击**；框内 `\n` 是排版换行 ⇒ **合并进同一行**。

自证（本轮实测，可复用）：
- 行数分布 1/2/3 行 = 8,910 / 5,390 / 3,131，**4 行以上仅 100 条**（全是整页「新聞記事」）；
- 续行带缩进的只有 48/12,244（**0.4%**）；
- 行宽上限 32 字（与 76/32 这类硬顶一致）。

## 4. 宏与转义

| 形态 | 含义 | 处理 |
|---|---|---|
| `######` | **主角名占位**（390 处） | 回填官方默认名；**同池内常并存 `「…アナスタシア…」` 与 `「…######…」` 两条，可互证默认名** |
| `#s0` | 話者名占位（用語条内） | → `〔話者名〕` |
| `\f` / `\cN` | 引擎转义（换色/换页） | 剥除 |

## 5. 收录与排除

**收**：章节 `NN_MM`（正文）＋ `90_01`（番外）＋ `91_01`（各人「その後」）＋ `clue.bin` 用語。

**不收**：
- `static~start.bin` —— **开发调试场景**（`テストA〜H`、`あああ…いいいい…`、A/B/C 同文三份）
- `localize`（UI 文案）／`name`（角色表）／`still`／`music`／`flag`（系统表）
- `scb_` 场景图（只影响「路线顺序」，不含正文）

## 6. 两个交付时必须声明的限制

1. **章节顺序**按文件号 `00→27→90/91`，本作是多线 AVG，**文件号 ≠ 单线通读顺序**。
   要按路线重组，得再解 SCNE 的 `scb_` 场景图（本轮未做，报告须写明）。
2. **「实名版 / 占位版」成对重复**：同一条台词会以 `アナスタシア` 和 `######` 两份出现，
   占位替换后逐字相同 ⇒ **只留一条**（本轮 326 组）。工具里是一行判断，想保留双份可关掉重跑。
