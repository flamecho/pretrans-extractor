# Daisy2 · DDP2 / DDP3

## DDP2 / DDP3

按 DDP2 / DDP3 签名、头字段和记录表选择布局。
DDP3 变长记录可含 UTF-16LE 名称、偏移、原始长度与存储长度，记录之间可有 padding。
DDWuHXB 可落在压缩块首个字面量内，实际压缩起点应由记录偏移确定；不能固定魔数前退两字节。
原始长度同时可参与变换键派生，不能绕过索引只扫描压缩标记。

## 自定义 LZ

| 控制字节 c | 操作 |
|---|---|
| 00–1C | c+1 个字面量 |
| 1D / 1E / 1F | 下一字节+1E、BE u16+11E、BE u32 的长字面量 |
| 20–3F | dist=(c>>2)&7，len=(c&3)+3 |
| 40–5F | dist=next，len=(c&1F)+7 |
| 60–7F | dist=((c&1F)<<8)\|next，后读长度；FE/FF 为扩展长度 |
| 80–FF | dist=((c&1F)<<8)\|next，len=((c>>5)&3)+3 |

回拷起点为 dst-dist-1；允许重叠，核对输入消费与输出声明长度。
文本过滤、键派生及命令语义仍按匹配加载器处理，不保存主程序地址或单作键值。
