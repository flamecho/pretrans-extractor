# RealLive

## SEEN 与字节码

按 SEEN 索引和编译版本读取场景、解压流及字节码，复用匹配的 rlvm 读取模型。
头部目录覆盖、消费长度和压缩校验分别验证；未索引尾部不自动视为已解析。
Textout、串参数、ruby、系统标题、变量及远调用分别分类。
场景范围由实际跳转和调用决定，不用场景号阈值排除共用结局。

## 消息状态

pause、spause、br/par、msgHide 与窗口切换分别核对等待、追加、排版和清屏。
WINDOW 的 R_COMMAND_MOD、NAME_MOD、字体与容量会改变显示，不将源码换行或一个 Textout 当作固定点击。
姓名标签按最终可见状态处理；清页与窗口重置后不无条件继承前页名札。
NAME 插槽沿配置和赋值求值，不改写源中的字面姓名。

## 控制流

远调用和非文本子程序可在消息页尚存时执行，不自动生成页界。
MenuReturn 等系统命令可能重置并跳转至菜单而不继续下一指令，须纳入可达性分析。
