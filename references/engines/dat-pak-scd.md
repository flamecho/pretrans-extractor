# DAT / PAK / SCD

## 容器

外层可串联 ZIP 块并按 0x200 对齐，依据 EOCD、声明长度和下个块头推进。
内层 DAT 记录为 `u32 count + count×(name[20h],u32 size,u32 offset)`。
size 在 offset 前，须同时核对表尾、成员范围和末项。

## SCD 文本与选择

文本为 `u16 len + len 字节`，编码按读取器确认；len 可含尾 NUL。
会话可连续存角色 ID、名札、正文三个长度串；旁白为另一命令参数布局。
选择命令 61/14 可用 scene_id、idx 引用 CHOICE.BIN，不扫描所有连续字符串当正文。
显示页按实际消息与等待调用确定，页内反斜线控制参数前向消费。
含控制字节的记录不能整条过滤；合法控制与未知字节分别登记。姓名宏及选项补充按引用读取，不固化姓名长度或漏块 ID。
