# System-NNN · SPT

## SPTHEADER0

整文件XOR FF后核对SPTHEADER0及u32头值20h、66660001、55550001。
匹配header[4:6]为消息count/base，[6:8]为杂项count/base；逻辑地址乘4得到字节偏移。
字符串按地址表读至NUL，严格CP932，NUL后的对齐填充不解码。
指令为word_count、group、opcode、operands，从header[0]×4起按word_count前进。
标签表及代码终点按头和结构确认，不固定所有版本为header[9]×4-16。

## 消息组66660006

| opcode | 匹配行为 |
|---|---|
| 22220001 | ADV消息，可替换旧缓冲 |
| 22220002 | 新全屏页，可清旧缓冲 |
| 22220003 | 保留并追加全屏文本，可产生新增点击段 |
| 22220004/05 | 等待或效果，按参数解释 |
| 22220006 | 文字选择候选，核对实际调用 |

操作数宽度和消息索引位置随版本确认；索引顺序恰好等于池序只是覆盖证据，不能当普遍规则。
多击页保留新增段及合并页，无新正文的重复等待不输出空段。

## 配置与文字

FXF/XTX可定义nameWindowFlag、姓名、加载顺序及样式。姓名首行与正文CRLF按当前名窗处理。
`#［…］`注音、姓名宏及图标按完整语法解释；图标不能因编码存在就认作汉字。
字符串起点用地址表与对齐校验，不反扫NUL或清掉行首半角字符补救错位。
