# KiriKiri · XP3 / KAG

## XP3 容器

XP3 可为独立文件或 PE 附加区。内嵌归档先确定 XP3 起点，并区分绝对偏移与相对归档偏移。
索引头随版本变化，按标志及长度解出原始或 zlib 索引，不能把所有版本当作裸 zlib。
索引由 `File` 块及 `info/segm/adlr` 子块组成；info 名称为 UTF-16LE，常见 segm 项为 28 字节，包含标志及 u64 偏移、存储长度和原始长度。
文件可跨多个段；分别还原后按段序拼接，验证长度与来源范围。
更新归档按运行时覆盖顺序处理，同名成员不并存输出。

## 过滤与编码

内容过滤可为整文件、分段 XOR 或插件自定义变换。压缩顺序、过滤范围及键来源由匹配索引和插件读取确认。
索引明文不证明成员明文；压缩长度相等也不证明字段无误。
脚本可混用 CP932、UTF-8 和 UTF-16LE，按 BOM、字段与实际读取器区分。

## KAG 扫描与宏

扫描 `[tag ...]`、`@tag`、标签、转义、引号及参数内括号，不以第一个 `]` 或简单正则截断属性。
支持 `@macro/@endmacro` 与 `[macro]/[endmacro]`，按参数、条件和执行顺序展开。
宏、`emb`、ruby 基底和标签属性都可能直接显示文字，不能仅删除标签后取裸行。
从 MainWindow 的 tag 分发表、MessageLayer、Config 和项目宏确定语义；同名宏不跨项目继承定义。

## 显示状态

| 状态或命令 | 判据 |
|---|---|
| `r`、物理换行、ignoreCR | 区分排版与脚本换行 |
| `l/p` | 等待和追加；是否清屏由具体 handler 确定 |
| `er/cm/ct`、clear2 | 核对清理的窗口与重置状态 |
| position、frame、current | 跟踪活动字层、最终矩形和前后台状态 |
| link/endlink、按钮宏 | 按显示调用收取选择文字 |

可忽略等待的配置须核对初始值；菜单是否可见不决定默认点击行为。
容量分页使用最终 frame、字形前进量、边距、行距、缩进及禁则，不以字数或引号平衡推断。
名札来自可见字层或宏状态；清页后是否保留姓名沿重置路径确认。
