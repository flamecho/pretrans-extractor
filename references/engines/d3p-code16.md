# D3P / Vridge · 双字节码流

## 容器与码流

常见载体为 CPK 剧本成员与外置字形表，成员可包含前置参数表和双字节码流。
先确认码流起点、结束、字节序与参数区，不能从文件头直接将所有 u16 当字符。

| 命令族 | 用途 |
|---|---|
| FFFF / FFFE | 消息或排版候选，具体推进语义按变体核对 |
| FFF0 | 名札及样式字段 |
| FFFB / FFFD | 消息分隔或结束 |
| FFE6 / FFE7 | 姓、名插入槽 |
| FF4D / FF4C / FF8F 等扩展 | 内联文本、样式或追加，按参数用途区分 |

不能把所有 FFxx 当控制码后整体删除；扩展参数也可能含正文或名札。

## 字形与文本

基础字符区可与 CP932 原码序相关，但专用槽、装饰和字形尺寸会变化。
按字体数据长度、行距、步长、像素深度及已知字符确认布局，不移用固定尺寸、阈值或槽表。
索引升序只能在证明与字符序同构时缩小候选，最终仍核对字形和文本上下文。
姓名参数可能由独立命令补写；追踪样式、名札和正文字段，按可见性关联。

## 选择与变体

选择按钮中的装饰字形与显示文字分开消费，不能按标点种类删除任意行首字符。
直写姓名与宏版可能为互斥显示分支；同文不足以证明重复消费。
