# HuneX Ogre · MRG / MZX0

## MRG 与 MZX0

`mrgd00` 头为六字节签名与 u16 count，目录常见四个 u16 字段 `(sector_off,offset,ssize_upper,size)`。
该布局的 `data_offset=8+count*8+sector_off*0x800+offset`，长度由高位与低位字段联合计算。
外置 HED/NAM 表和自包含 MRG 均有变体，核对表字段及成员映射后读取。
MZX0 为 magic、解压长度与 LZ77 数据；字面量可做 XOR FF，环形缓冲及重置周期按匹配解码器处理。

## 脚本与显示

常见脚本为 CP932 的 `_CMD(args)` 流；分隔、括号、引号和转义按实际语法消费。
`_ZM`、`_MSAD`、`_SELR`、`_MTLK` 分别定位文本、追加、选择和名札候选，仍须核对具体调用语义。
`@n` 可为页内暂停或换页，不能跨变体固定定义；结合追加命令、清屏及等待路径维护段与页。
守卫块可能只更新条件，也可能显示正文；空守卫、制作命令与资源变换不自动终止消息。
邮件、短场景和标题可由独立命令发射，文本范围不限于主打印命令。

## 字形码变体

部分平台的文本为双字节字形索引，而非直接 CP932；从对应字体表、索引计算与已知明文确定映射。
插入宏、姓/名分隔符及样式按字段消费；固定槽表和姓名值不跨作品继承。
