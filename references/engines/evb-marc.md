# EVB / MARC

## CPK / MARC

外层 CPK 使用匹配 CRI 解析器。MARC 为自定义索引容器，目录项提供成员起止位置，可同时包含字体和同码域系统串。
字体、文本及资源成员按签名与用途分类，压缩和脚本字段不由文件后缀推断。

## EVB 文本参数

此指令族使用 FE 前缀，正文打印族可含 FE 00、FE 02 与带样式的 FE 30/31/32。
0A 00 是消息终止候选，也可能在字体码或操作数中出现；按完整指令头与参数位置定界，不能裸扫每个 0A。
文本中的 ASCII 只有在文本参数范围内才作为字符，参数字节不得进入解码缓冲。
标题、注音与强调包装可能使用不同终止或打印路径，分别核对读取语义。

## 自定义字符与显示

字形码可基于 JIS 分区重排，但标点、异体与专用槽随版本变化。
消息终止、续写、姓名宏和装饰按实际处理实现解释，不以引号或可解码性替代参数边界。
