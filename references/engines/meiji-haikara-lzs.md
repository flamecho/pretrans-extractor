## 2. `.lzs` 圧縮（★要点）

`[u32 解凍後サイズ]` ＋ **Okumura LZSS のバイト入替・LSB-first 変種**：

```
フラグ 1B / 8 トークン, LSB-first, bit=1 → リテラル
マッチ = 2B [b0][b1]: len = (b1 & 0x0F) + 3 (3..18)
                      off = b0 | ((b1 & 0xF0) << 4) (0..4095)
リング 4096, r0 = N - F = 0xFEE, ソース = ring[(off+k) & 0xFFF]（絶対位置）, 初期値 0x00
```

- **確定手順（列挙に頼らない）**：① 120 本で「長さ完全一致＋ストリーム完全消費」→ layout A のみ生存
  ② 2.27MB `DEBUG.lzs` でも同条件成立 ③ 環起点 0 だと日本語文字数 39,107→69,251（起点 0xFEE が正）
  ④ 本文が完全通読可能。
- ⚠ 見かけ上「距離＝off−1」に化けるのは **r0=0xFEE の絶対インデックス**だから（`dist` 実装は誤り）。
- 共通 NSO/NCA 手順は `engines/switch-nca.md` 参照。`hactool -t nsp` は失敗 → **`-t pfs0` で展開**。

## 3. SCD（脚本）構造

```
0x00 u32x4: [u16 a][u16 b][u32 = コマンド列開始 b][u32 c][u32 0]
0x10 ファイル名 + 0xFF pad（0x40 まで）
0x40..b アセット台帳（0x40B/件 <u32><u32 off><u32 size><u32 idx><name 0xFF pad>）
b..   コマンド列 <u16 tag><u16 size(自身の 4B 含む)><payload>
```

- **メッセージノード = tag `0x10`（35,002）／`0x11`（227）**：
  `10 00 | XX | N(u32) | N(u16) | 話者ID(u32) | <u16 len><utf8> ×3`
  = `[ボイスID("-1"=無音)][名札][本文]`。文字列 3 個未満のノードは本文なし。
- **話者ID(u32) → 名札**は全作安定（`0x00`久史 `0x01`銀之助 `0x02`楓花 `0x03`賢 `0x04`徳治郎、
  `0x0a`-`0x12` 脇、`0xc8`+ モブ）。名札表 188 種。
- 行内制御：`%`=姓／`&`=名（主人公宏、本文に出現）／`\`=框内改行（合并）／`$`・`#`=用語マーカー（記号削除）／
  `+`=姓名区切り（削除）。→ `%`=芳川 `&`=けい。
- **選択肢は SCD に無い**（tag 0x68 が 1 件だけでキャラ ID 参照型＝文字なし）。
  **選択肢テキストは `CORE` 側**：0x99e7000〜 に `<u32 len><u32 slot(0-3)><utf8>` が 383 件連続。
- CORE にはこの他「キーワード一覧」（0x99e0c70 付近、0x50B/件 `<u32><u32 id><char[0x48]>`、
  見出し語のみ・解説なし＝KWLIST メニュー索引）→ 用語辞典ではない。
