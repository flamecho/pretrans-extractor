# Koei CDAR v2/v4（コルダ・遥か・下天の華）

> 路由 / 一句话索引见 `../engines.md`。

- **Koei CDAR v2/v4（コルダ/遥か）**：文本记录 `04 <u16 len> <cp932> 00`；一次点击=框边界 BOUND/M91/C7。参考 `koei/Cdar.cs`。工具 `corda_*_extract.py`/`haruka*_extract.py`/`geten_extract.py`。
  - **CDAR v4 容器**：`CDAR`＋u32 ver=4＋u32 count；`16+count*4` 起为 count×12B `{off, decompressed_size, stored_size}`；首字节 0x78→zlib；子条目可为嵌套 CDAR。
  - ★**内联插入有两套定长表（遥か5 实证，2026-10-07）**——**别照搬 コルダ/下天の華 的「文本内联」路线**：
    | 指令 | 查表 | 表位置 | 记录 |
    |---|---|---|---|
    | `02 <id>` + `1e 05290204` | 脚本用语表 | 母表 leaf base `0x1c9e6` | 52B＝語 19B＋読み 33B，0–499（空槽 `仮`） |
    | `02 <id>` + `1e 05b2027e` | 用語辞典表 | 同 leaf base `0x149e0` | 64B＝flag＋見出し語 19B＋読み 32B＋半角カナ，0–367（空槽 `用語予約NNN`） |
    | `1e cf 02 1e 0a` + 02/1e 链 | 名变量 | — | `0x329007e7`=名 / `0x01cb013a`=姓 / `0x2350067d`=姓+名 |
    - 母表 leaf（size 167,270）同时含 章題表 / 地图名 / 角色表(`0x55e9`) / 史実年表；用「52B 首条 = `御使い`」定位。
    - **「用語予約３６８」字段＝基址钥匙**：说明 slot 索引 ≠ 用語 ID，反推 `0x1a5e0 − 368×64 = 0x149e0` 才对得齐（否则整体错位）。
  - **leaf 尾部签名可当分类器**：`CLOSE+C7+1e 5e9008d3`＝用語辞典解説文；`CLOSE+M91+1e 5e9008d3`＝系统/UI（整体排除）。
  - 用語辞典 見出し語↔解説文 の対応表は DATA.BIN 内に無い（遥か5 / 下天の華 共通）→ **順不同2リスト**で出す。
  - 工具：`haruka5_extract.py`（遥か5 定稿・自包含）。
  - ★★ **同一作の FD（風花記）で「插入机制改为内联」的实证（2026-10-07）** ⇒ **同族引擎必须重新求证，不能照搬本体**：
    - **TERMOP(`1e 05290204`)/GLOSSOP(`1e 05b2027e`) 计数 = 0**（本作无定长表插值）。
    - 用語・続き 均为**普通 `04` 文本记录内联**，前导两种：`02 <u32 id> 1e 4e 04 3a 14`（APP1）／`1e a6 04 a8 14`（APP2），
      二者后 **100% 紧跟一条 `04` 记录** ⇒ 「记录扫描 + 合并」即可，**无需查表**。
    - 名变量 INS `1e cf 02 1e 0a` 布局**与本体完全相同**（`0x329007e7`=ゆき / `0x01cb013a`=蓮水 / `0x0b49032e`=蓮水ゆき）。
      ⚠ `02 <var>` 形式多数出现在**条件链操作数**（并非显示文本），只有紧跟 INS 链的才内联。
    - **選択肢 = `1e c6 02 87 06` / `1e 72 03 91 0b` 前导的 `04` 记录**（正文流内、1 记录 1 条）；
      ⚠ **デバッグメニューも同じ op を使う**（構造で分離不能）→ 内容で除外（`〜場合$`/`〜は？$`/`〜をセット`/`イベントが呼ばれました$`/`〜周目`）。
    - 母表 leaf（`風花記` = 174,924 B）**見出し語表 = stride 64B，base 0x167c0**（`[12B][見出し語 19B][読み 33B]`, id 0..511）。
      ⚠ 锚定须**双重**：`桐生 瞬` 在同 leaf 出现 2 次（另在 0x65f1 的 52B 系表区），取「+64B が `坂本龍馬`」的那个才是真基址。
      後半混入**英語表現 81 条**（含占位 `英文作成中２`）。
    - 尾部签名分类同样适用：`CLOSE+C7+1e 5e9008d3`＝用語辞典解説文（含少量系统串须二次内容过滤）；含 `1e 5e9008d3` 的其他 leaf＝系统/UI・教程。
    - ★ **冒頭修正版 leaf（overlay）**：序章冒頭が `leaf 18`（本編 126 記録・旧稿）と `leaf 4999`（9 記録・修正版＋末尾で入口ラベル `イベント・共通序章頭` を宣言）の 2 つに存在。
      ゲームが表示するのは `4999` ⇒ **大 leaf の対応冒頭を差し替え、小 leaf 単体は出力しない**。
      判定＝「同タイトル・冒頭が逐条位置対応（≥n−2 一致かつ ≥1 相違）・末尾にラベル宣言」＝ overlay。本作で該当 1 対・誤検出 0。
    - 工具：`kazahanaki_extract.py`（風花記 定稿・自包含）。
