# Koei · CDAR

## CDAR

v4 头为 `CDAR + u32 version + u32 count`；`16+count×4` 起为 count 个 12 字节记录：off、原始长度、存储长度。
成员可为 zlib 或嵌套 CDAR，按记录及载荷识别，不能只凭首字节 78 决定压缩。
v2/v4 的头与目录布局分别读取，叶节点类型由内层指令确定。

## 文本与表引用

匹配文本记录为 `04 + u16 len + CP932 + NUL`。BOUND、M91、C7 等调用与清页、等待共同定义显示段。
02 整数可能是条件参数、词条或姓名变量；只有在相应插入链内才展开。
用语表可有 52/64 字节记录，按索引、表结构和相邻槽验证基址，不固化绝对地址或人物锚点。
同一词条编号可对应不同表域，保留引用上下文。尾部调用可辅助分类解释文、菜单和教程，但不能替代显示取证。
