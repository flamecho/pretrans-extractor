# Bezel · BEA / SCNE / SCB

## SCNE / BIN_

BEA 成员可包含 SCNE 包装及 zstd 数据。先按头和长度还原，再识别 BIN_ 或指令文件。
BIN_ 的已证索引布局在 0x0C 保存 N、0x18 保存字符串基址，0x1C 起为 N 个 u32 offset；验证 `base == 0x1C + N*4`。
本地化键、语言区、文本区和引用共同确认语言及用途，不能固定切前后半池。

## SCB 字节码

文件树、名称长度、ASST 等包装字段和参数单位有变体；先核对 u8/u16 名长及数据起点。
记录的 wc 可表示包含头部的 u32 总字数，不能当作操作数数量；下一记录位置由记录总长得出。
字符串参数可能有四字节对齐及定长前置字段，文本、name、资源与演出 opcode 分别处理。
带日文参数的演出命令可显示叙事文本，分类不限于主 text opcode。

## 显示与模板

提交、等待、清屏及追加调用确定段页，字符串数和相邻 opcode 频次只用于定位。
name 与 text 的关系按字段和可见状态确认，标签不以长度或标点过滤。
