# 引擎：D3P 自研 ADV（CRI CPK ＋ 自建位图字体）— STORM LOVER 系列（PSV / PSP）

代表作：**STORM LOVER V（PSV PCSG00735）**、**STORM LOVER 2nd V（PSV PCSG00736）**、
**STORM LOVER 夏恋!!（PSP）**。D3Publisher / VRIDGE。

> **PSP 版（夏恋!!）** 与 PSV 版同族但有 4 处差异 → 见 `engines/stormlover-d3p-psp.md`。

## 容器 / 解密
- 源＝Rar5 **未加密**（注释是下载站广告）的 **NoNpDrm 目录树**（`app/<TITLEID>/`）。
- **PFS 解密**：`psvpfsparser.exe -i app/<ID> -o dec_app -z <games.json 的 zRIF> -f cma.henkaku.xyz`
  ⇒ 成功判据 `keystone: matched retail hmac`；**须非沙箱放行网络**（否则 `parsing files.db… Error: expected value`）。
- `eboot.bin` → ELF：`util/self2elf.py -k …/sce_sys/package/work.bin`（pycryptodome；ELF32/ARM/全 Thumb）。
- **`USRDIR/sc.cpk`＝唯一剧本文本容器**（CRI CPK v7 rev13，无压缩无加密）；`union.cpk`＝图/音；`vo.awb`＝AFS2 音频。
  条目名为数字；V=1179 条 / 2ndV=939 条。

## ★ 文本编码：自建字符集 ＋ 自建位图字体
文本＝`sc.cpk` 条目内的 **u16 LE 码流**（非 cp932）。

| 层 | 规则 |
|---|---|
| **基础区** `code < 3456` | `char = CHARSET[code]`，`CHARSET` ＝ cp932 有效双字节码**原码序**，剔 `0x81FC` + Greek(0x839F-0x83D7) + Cyrillic(0x8440-0x8492) + `0x849F`。**V/2ndV 同版**（验证：kana 200-359、759 会 / 828 学 / 3180 木 全中） |
| **二级区** `code ≥ 3456` | **逐作独立的自用字形槽**（`CHARSET[code]` 在此是 cp932 基线假象，勿用！）。槽数＝字体覆盖上限（V=3586 / 2ndV=3624） |
| `USRDIR/lt.bin` | **字形图集**：`648 B/字形 = 36 行 × 18 B`（4bpp，36px/行）；**字形索引 == 游戏码**，从 0 起；文件尾 16 B 哈希 |

### 二级区定值法（可复用）
1. 渲染 `lt.bin` 槽位字形（`PIL`，4bpp 高半字节在前）。
2. **逐槽人工辨字**（**36 px 辨字必错**：餃↔馥、闊↔閹、犧↔… 同类字形）。
3. **用真实台词上下文仲裁**（最高优先级）：`わさび[3457]の味`→**丼**；`白色[3530]星`→**矮**；`切[3531]琢磨`→**磋**；
   `竹[3534]`→**箒**；`迂[3562]`→**闊**；`[3563]石`→**隕**；`[3567]舌`→**毒**；`師匠破門の[3619]滅`→**殲**；`怪[3622]そう`→**訝**。
4. 三证合一（字形＋文脉＋"槽序≈cp932 码序"单调性）后落 `SPECIAL`。

### 命令集（≥0xFF00）

| cmd | 含义 |
|---|---|
| `FFF0` | 说话人名字段（名札）→ **丢弃**（不加说话人前缀） |
| `FFFF` | 正文框开始（**＝ 一次点击**），其 run 恒为正文 |
| `FFFE` | 框内换行（合并时去行首全角空格） |
| `FFFB` | 消息分隔 |
| **`FF0F`** | **主角一人称宏（私）**（2ndV 实测；锚句 `[FF0F]は２年に編入予定の[FFE6][FFE7]です`） |
| `FFE6` / `FFE7` | 主角**姓 / 名**占位（运行时宏；填游戏默认值） |
| 其余 `FFxx` | 图标 id / 坐标 / 表格参数 → run 丢弃 |

> ⚠️ **宏语义逐作核**：V 用 `FF08`＝一人称（私）＋`FFE6/7`＝姓名；**2ndV 无 FF08，改用 `FF0F`**。

### 尾块（两作同构、偏移 +46）
`[ｃｍ][ｋｇ][①..⑳][Ⅰ..Ⅹ][㊤][㊦]`（V 3524..3557 / 2ndV 3570..3603）。
字形虽为带装饰边框的圈数字/罗马数字，**实为邮件装饰绘文字**，必须按文脉改写为对应文字（2ndV 已落地）：
- **对象类**：Ⅲ=**メール** / Ⅳ=**携帯** / Ⅷ=**雨**（`いつでもⅢください`→メールください；`専用のⅣ`→専用の携帯；`Ⅷが降ったら`→雨が降ったら）。
- **分隔类**：①..⑳ 与 Ⅴ/Ⅹ（同一封邮件里 ⑪/① 混用 ⇒ 通用分隔、无固定所指）→ 按句读落「。」（前接 ？！。…、」 时不重复）。
- 判定要点：**对象类需做「近义复现即丢弃」**（同小句 ~12 字内已出现 メール/携帯/電話/雨 等 ⇒ 该装饰是重复强调，直接删），
  否则产生 `メールⅢと電話Ⅳ`→`メールメールと電話携帯` 式重复。
- 实现：`scripts/stormlover2_charset.py` 的 `DECO_SEP`/`DECO_WORD` ＋ `scripts/stormlover2_run.py` 的 `fix_deco()`。
- ⚠️ 不可把「词」直接写进 SPECIAL：那样 slot 词与正文同词无法区分，去重失效。

## 成行 / 交付
- `一次点击＝一行`；名字札区 `FFF0..FFFF` 内整段跳过；主角名 inline（`嵐山`/`真理`）。
- 剔除**系统·UI·调试**行：`〜演出です`／`〜のテスト`／`選択肢N`／`分岐N`／`バカップル〜`／服装差分表（`名前　制服　表情`）／商店价格表（`メガネ　２万円`）／入口头部残留。
- 残余（游戏数据固有，非缺陷）：引号差 6、行首 `「` 未收尾 6 行（UI 片段分框）、相邻重复行。
