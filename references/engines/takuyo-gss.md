# Takuyo · LSDARC / SCR

## LSDARC

LSDARC V.100 常以索引和数据文件分离保存。目录项提供名称、偏移、存储与还原长度以及打包状态。
打包成员可带 `LSD\x1A`、enc、pack 与 unpacked 字段；压缩和加密选择以实际头为准，不由后缀决定。
裸成员与压缩成员分别校验范围、消费和还原长度。

## SCR 指令

已证 SCR 1.10 / 2.00 共享 `u16 opcode | u8 size | u16 id | operands` 布局；SCR 3.00 等版本须重核读取宽度。
版本串之后的参数独立读取，不能并入版本号。

| 操作数类型 | 布局 |
|---|---|
| 01 / 05 | 四字节值 |
| 02 / 04 / 06 | 双字节值 |
| 03 | NUL 结尾 CP932 串 |

按 size 消费全部操作数；真实文本参数可能与文件名、槽位、标志和分支值混排。
`%s` 类替换源位于对应操作数中，按槽及控制流求值，不把正文参数本身当替换源。
选择从组记录与字符串字段读取，flag 或索引后缀由写入用途证明后才剥离。

## 入口与显示

调用、尾调用、标签和原生动态分派共同确定场景范围与顺序；静态未引用不足以排除额外剧情。
消息、标题、选择及语音字幕可由不同命令显示，覆盖对应参数读取路径。
正文内部换行与等待分离，窗口、控制码及打印器决定点击和自动分页。
