# HuneX · HESL / HESE / HDLG

## HESL / HLZS

HESL 链接容器提供条目位置、长度和名称；偏移基准以头字段及所在包区段确定。
HLZS 包装包括版本、存储和解压长度，内部为 HuneX LZSS，常见字典 0x1000、最大匹配长度 0x12。
先验证容器范围、解压长度与消费，再识别 HESE 或 HDLG。

## HESE 内联变体

指令框架、参数宽度和内联串位置随版本改变；文本、名札和选择分别按处理函数分类。
自定义字形码须通过 CSB 表与字体槽核对。CSB 可为固定宽度记录；基址差和额外字形数由已知明文与对应表确认，不将 Shift-JIS 偏移当作通用解法。
用同时包含假名、汉字和符号的独立样本校验映射，单段假名可产生错误基址假象。

## HDLG 外置变体

HESE 可只保存文本索引与变量，台词另存于 HDLG。无内联日文不足以排除文本。
HDLG 常见头为 `magic + version + count + dataOffset + offsets[count]`，数据区为 NUL 结尾 UTF-8 字符串。
本地化键、语言配置、引用和调用区分正文、姓名及系统项，不使用固定索引阈值分区。
`<br>` 和姓名标签按匹配语法解释；一条 HDLG 项是否一次点击由 HESE 显示调用确认。
