> > 适用：裏語 薄桜鬼（無印）／ ～暁の調べ～ 两作均确认存在。

## ★ 台詞バリアント機構（2026-10-14 追加，**本引擎标志性特征**）

**现象**：同一句在脚本里**并排存了多份**，线性扫描会把它们都取出来（成品 1,594 行 = 4.8%）。

**判据（三条，齐了才定性）**：
1. 两版是**独立指令块**（各自 pos / 各自 `0x2f`），不是提取重复；
2. 中间夹 **`0x1e`（len=0）** —— 实测 928 对近重复中 **77% 由 `0x1e` 分隔**；三层 marker 为
   `0x1c`（組開始）→ `0x1e`（区切り）→ `0x1f`（終了），偶见 `0x2a`（改ページ）夹在中间；
   典型帧（e0 @0x2b0c）：`0x105{idx,"chara_02_1.enc"}` → `0x1c` → `[0x2d 名][0xb6][0x2f…]` →
   `0x31` → `0x1e` → `[0x2d 名][0xb6][0x2f…]` → `0x31` → `0x1f` → `0x2b`；
3. 两版**各带自己的 `0x31`（连番台詞ID）与 `0xb6`（8B，紧跟人名，值也连番）** ⇒ 引擎当**两条独立台詞**登记。

**变体差异分类**（928 对，已排除立绘指令块；差「→」左=A 右=B）：

| 类 | 对数 | 差异 |
|---|---|---|
| 完全相同 | 15 | 纯重复 |
| **仅称呼差异** | **532** | A 字面默认名 ↔ B 宏/代名詞/関係語 |
| 称呼+少量改写 | 160 | 同上 + 词语微调 |
| 内容不同（真分岐） | 221 | 不可删 |

- **A 版 = 名前ベタ書き**（`梢` / `霧島梢`），**B 版 = `&pcl` / `彼女` / `あいつ` / `妹` / `妹よ` / `あなた` / `君` / `お前` / `こいつ`**；
  也有整段删名（`落ち着け、梢` ↔ `落ち着け`）与姓差分（`か、桂さん` ↔ `霧島さん`）。
- **表记也随之变**：A `来ます` ↔ B `きます`（汉字↔平假名）。实例：`必ず戻って来ます/きます`（e6、e53）。
- 推断（**未确证**）：A/B ≈「音声に入っている名前を読む版 ↔ 名前を言わない版」，`0xb6` 疑为 `{キャラID, ボイス番号}`。
  语音库 `sound/btlvoice.awb` 是 **CRILAYLA 压缩**（头非 AFS2），未解析 ⇒ 无法用 AWB 条目数验证，**勿据此断言**。

另有 370 对仍差称呼/表记。`221` 对真分岐**必须保留**。去重只应针对「归一后全同」的 427 对。
