# FPK / VML

## FPK 容器

此布局的头含 count、数据总长、表起点与数据起点；目录常从 0x20 起，条目为 `name[16] + u32 size + u32 offset + u64 pad`。
验证 `dataStart == 0x20 + count*32`、成员范围与对齐；同后缀 FPK 不保证同格式。

## VML 记录与编码

VML 头为 headerSize、tableOff、count 和 fileSize。指令由 `u16 id + 00 FF` 及按 id 定义的操作数组成。
文本载荷可为 JIS X 0208 的七位字节，将每字节补高位后按 EUC-JP 解码；不以假名样本验证 CP932 偏移。

| 记录 | 语义 |
|---|---|
| 64 / 65 | 名札与无名状态 |
| 66 / 67 | 消息开始或消息属性 |
| 68 + u8 len + payload | 正文片段，len 为字节长度 |
| 69 | 页内排版换行 |
| 6A / 6B | 姓、名插入 |
| 6C | 样式或强调控制 |
| 6D / 6F | 消息结束候选 |
| 1F6 + idx + text，1F7 收尾 | 选择组，idx 不天然等于显示顺序 |

## 显示

消息范围由开始、结束、等待及清屏路径共同确认。同枠多条 68 为排版片段时拼接，心声与台词同页不凭标点拆开。
自动分页须根据窗口与处理实现确认，字体和窗口容量不写成跨版本常量。
选择逐记录按调用序取文案；名札及插入宏采用当前输出规则。
