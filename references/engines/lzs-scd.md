# LZS / SCD

## LZS 与 SCD

LZS 可为 `u32 outBytes + LZSS`：LSB-first，1 为字面量；匹配 token 的
`off=b0|((b1&F0)<<4)`、`len=(b1&0F)+3`，4096 字节零环，写位置 FEE。
off 是环绝对下标，逐字节重叠复制；核对声明长度、输入消费和还原结构。
SCD 头给出命令流起点，资产记录可为 40h 字节项；命令为 `u16 tag,u16 size,payload`，size 含四字节头。

## 文本布局变体

10/11 消息载荷可包含编号、话者、标志及 voice/name/text 长度串。
串的 len 可含 NUL、另加 NUL，或带不同 padding；先以匹配字段和多条记录验证，不能用一字节重同步替代布局。
无名消息可少一个姓名字段，不能固定总取第三串或最后一串。
CORE 可存选择与词条表，依据场景引用和结构定位，删除绝对表址与固定姓名 ID。
`%/&/*` 等姓名槽、反斜线排版及词条标记按当前宏表处理；页界由实际显示调用确定。
