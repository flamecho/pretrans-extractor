## 2. `pasc` 节点格式（★自校验）

```
文件头 = 32B: 'pasc\0\0\0\0' + u32(?) + ...        节点链自 0x20 起
节点   = [u32 type][u32 len][u32 size][u32 x][…extra…][string(len 含 NUL)][pad 到 4B]
         串起偏移 header = size - align4(len)     (头长随 type 变: 2->16, 6->28, 54->28, 56->48)
         下一节点 = pos + size                     (链恰好吃掉整个文件: 1161/1161 自校验通过)
```
`len` = 串长含结尾 NUL；非串节点 `len=0`。**不要写死头长**，一律 `size - align4(len)` 反推。

## 4. 成行规则

- 续写：`2/8`(文本) ＋ `4/5/7`(变量) ＋ `9`(标记) 拼一行；框内 `\n` 合并。
- 断行：`1`(框容器) / 语音 / 条件 / 标签节点。
- `6` 旁白自成一行（空串仅断行）。
- `54/58` 起新行后**仍吸后续 5/8**（实证 `5+8+5+8` → `〔変数・来訪者1〕様と〔変数・来訪者2〕様…` 一行）。
- `56/60/63` 各占一行，顺序即显示顺序。
- ★★ **正文句号写在 cp932 `0x8140` 槽（=全角空格 `U+3000`）**，须还原为「。」：
  正文节点 `2/6/8/56/60/63` 内 `U+3002` **实测 0 个**，注释节点 `0` 才用标准 `0x8142`（481 个）。
  位置分布 87% 落在**行尾/节点尾**（行尾不会有填充空格；多行节点里仅 22% 每行都带 ⇒ 非填充；日语中空格不承担句读）
  ⇒ 语义即句号。**还原规则**：① 前一字为句末标点（`？！…‥～♪」』】`）或位于行首/文本开头 ⇒ **删**（标点已足/续行缩进）；
  ② 其余 ⇒ **「。」**。（须在合并 `\n` 之前跑）
  还原后 `。`=32,776、`、`=16,923（≈1.9:1）、行尾 `。`=16,969、`U+3000` 残留 0。

## 5. ★框内演出控制码（无字形 ⇒ 非显示）

`2` 号串内出现 `0x8760`(133) / `0x875f`(28) / `0x8751`(64)。**`font/system.paf` 字形码表内不存在**
（`0x8740–0x875E` 整段缺）⇒ 引擎不渲染，属框内演出码 ⇒ **删除**。
★判定依据：`0x8751` 出现在**右括号之前**（`…ちょっとうれしい⑱）`）且与 `\n` 并存 ⇒ **非换框码**；
若误当「换框」拆行会产生 36 处孤立 `）` 行（引号不配对）。删除后括号全配对。
