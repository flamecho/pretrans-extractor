# Koei · PASC

## PASC 节点

gzip 载荷可还原为 pasc，匹配布局为 32 字节头后节点链。
节点 `u32 type,len,size,x + extra + string + pad`，len 可含 NUL，字符串头长可由 `size-align4(len)` 计算。
仅在确认字符串位于节点尾时使用该公式；无串节点 len=0，按 size 推进，核对全链与表范围。

## 字形与显示

PAF 码表及 PAR/GXT 图集决定字符槽的实际字形；CP932 解码结果不一定等于显示字符。
句号占空格槽、圈号作演出码等映射须由当前字形与 handler 证明，不跨作品保存固定替换表。
节点 type 的正文、注释、姓名和演出用途分别确认；页界按消息与等待调用读取，不按物理换行切分。
