# WillPlus / AdvHD · WSC

## ARC 与旋转变换

ARC 头为 `u32 extGroupCount`，组项为 `ext[4] + u32 count + u32 tableOffset`；
成员为 `name[13] + u32 size + u32 offset`，共 21 字节。
匹配的 WSC/SCR 每字节解码为 `rotl8(c,6)=(c<<6|c>>2)&0xFF`。
先确认变换后的头和指令结构，不能因密文中出现类似 opcode 的字节就判明文。

## 指令变体

选择项可为 `2B + 文本 NUL + 3B 头(01 XX 03) + 目标指令`。
跳过三字节头后按 opcode 分派目标：`07` 读 NUL 脚本名，`06` 读五字节操作数；不能固定跳四字节。
SCR 与 WSC 的操作数宽度不同；使用匹配版本表，不能直接继承所有 opcode 长度。
op41、opB6、op42 的前缀可含消息 ID，但相邻字段并非同一域。解析消费到 EOF 后仍须核对字段与 handler，避免重同步掩盖错位。

## 显示

`%K%P` 可表示点击后翻页，字面 `\n` 为排版换行；等待与清屏分别记录。
`%O` 等演出标记按完整语法读取。合法半角假名保留，不作为失步字符自动删除。
