## 1. 容器链

```
ISO9660
 └ PSP_GAME/USRDIR/UMD.CPK          ★ CRI CPK，scripts/cpk.py 解包
    ├ event.enc       ← 唯一剧本源（.evt 脚本的归档）
    │   無印 2,065,227 B / 249 entries @LBA 242512；暁 2,167,088 B / 158 entries @LBA 54512
    ├ event/eventFileListTbl.dat    定长 68 B 路径表（event/station/S01101.evt …）
    ├ event/{flag.dat, eve_flag.h, tutorial.dat}
    ├ table.enc / book.dat / defNpc.dat / termItem.dat
    ├ FontData.l / FullFontData.l / IndDivFontData.l（映射表，`[u32 ?][…]`；IndDiv = **Unicode 码位表**，
    │   首项 0x4E9C 亜 / 0x5516 唖 / 0x5A03 娃 / 0x963F 阿 = 日语常用汉字表前四字）
    └ text/TextData*.bin
```
- 暁 另有 `chapterSelect.dat`（含主角姓「霧島」、兄「聡介」）；`voice.awb` 702 MB 在 CPK **之外**。
- EBOOT 内脚本路径模板：`event/{ev/E%03d, call/C%03d, npc/N%02d, terminal/T%02d, station/S%04d,
  report/R%02d, board/B%02d, gameover/G%02d, menu/M%03d}.evt`。**CPK 里没有 `.evt`**（都在 event.enc 内）。
- 其它魔数（小端字符串）：`SAVE`(0x45564153)、`EVNT`(0x544e5645)、`CDVD`。

## 2. 解密：EBOOT.BIN = `~PSP`

- 头 magic `7e 50 53 50`，`mod_name` = `URA`；`EBOOT.BIN = 0x157 头 + 加密 ELF`（`0x2C` 字段 = 文件大小）。
  暁 为 `0x158` 头 + 2,236,328 B ELF（同样 `tag D91613F0 / type 2` 可解）。
- **`pspdecrypt`（John-K/pspdecrypt，解密代码源自 PPSSPP＋libkirk）可解**：
  `./pspdecrypt.exe EBOOT.BIN` → 输出 `tag D91613F0 with type 2`，得 **MIPS32 LE ELF**（2,959,929 B）。
- 下载须走 `api.github.com/repos/<owner>/<repo>/releases/assets/<id>`（加 `Accept: application/octet-stream`）——
  直连 `github.com/.../releases/download/...` 被墙。
- 反汇编工具：**capstone**（`pip install capstone`）或 rizin；本机无 java（Ghidra 需 JDK 21+）。

## 3. ★ 脚本容器 event.enc 与 LZO1X-1 压缩

```
event.enc = u32 count(=249) + count × 12 B 记录
记录 = { u32 size | 0x80000000 , u32 size2 , u32 offset }
  bit31        = 压缩标志（218 压缩 / 31 未压缩）
  size         = 压缩后字节数（Σsize = 2,053,832 ≈ 文件数据区，实证）
  size2        = 解压后字节数（Σsize2 = 5,150,404；解压 249/249 命中 100.0%）
```
暁の調べ：`count=158`（132 压缩 / 26 未压缩），解压 Σ=5,576,900，命中 **158/158**。
**判「是否压缩」只看 bit31 —— 不能靠"能否读出明文"**：LZ 的字面量本身就是明文，旧判断据此误判为"未压缩"。

**解压器（EBOOT）**：加载链 `0x5a8d0`(事件脚本加载) → `0xb04e0`(读 u32 count) / `0xb050c`(取条目)
/ `0xb5688(handle,0,"EVNT",0)`(打开流) → `0xb0590`(读条目到缓冲)；再由 **`0xb03fc`** 检查
`表 + index*12 + 7` 的最高位（即 bit31）决定：**未压缩 → `memcpy`**；**压缩 → `0x3734`(init) →
`0x377c`(decode) → `0x3748`(fini)**。

**`0x377c` 即 LZO1X-1 解码**（特征常量与识别法见 skill `03-archive.md` A14）；移植实现 **`scripts/lzo1x.py`**。

## 4. 脚本指令格式

解压后 = **`[u32 cmd][u32 len][len 字节 data]`**，可无缝覆盖整条 entry（e4 实测 end pos == len）。

| cmd | 含义 | 处理 |
|---|---|---|
| `0x2f` | **台词正文** | 收 |
| `0x21` | **选项** | 收 |
| `0x2d` | 说话人名（全名，如「高杉　晋作」；主角位为 `&pcl`） | 丢弃（§0 不加前缀） |
| `0x2e` | **无说话人的文本框**：地の文（叙事/年表）＋ 系统·任务·道具·技能消息（1,116 块） | ⚠ 只收地の文（见下） |
| `0x31` / `0x20` | 名字输入用**字库**（单字：ァ/院/魁…） | 不收 |
| 其它 | 立绘/坐标/BGM/资源名（如 `0x74`+`ev_0407_1.gim`、**`0x105`**+`chara_02_1.enc`） | 不收 |

### ★★ opcode 表**跨作品整体平移**（不可照搬！）

無印 `0x2f`(台词)/`0x21`(选项)/`0x2d`(人名)/`0x2e`(无说话人文框)/`0x31`·`0x20`(字库)
→ **暁の調べ 全部 +5**：`0x34` / `0x26` / `0x32` / `0x33` / `0x36`·`0x25`。
五者一致 +5 ⇒ 枚举表前部多 5 项，属**平移**而非巧合。**判别法（不靠猜）**：① 承载**长日文句**者＝台词
② **成组出现**(连续 2–6 个)者＝选项 ③ **单字**者＝字库 ④ 紧跟名札后者＝人名。表见 `scripts/urakata_extract.py` 的 `OPCODES`。

- 文本 = **纯 cp932**；data 以 **`00 00`** 收尾并**对齐填充到 4 字节**（故常见 `00 00 00 00`）。
  ⚠ 取文本务必 **`d.split(b'\x00')[0]`**（按 `d[:-2]` 会残留 NUL ⇒ 整块被弃）。
- 内联控制码：`@1r`/`@4r`（着色开始）、`@17r`（恢复）—— 全库仅 16 处，去除后保留被着色文本。
- 主角名宏 **`&pcl`** → 默认名 **「梢」**（EBOOT `0x1c4308`；姓「霧島」`0x1c4378`；可改名）。

## 5. 成行（「一次点击 = 一行」）

- **一个 `0x2f` 块 = 一次点击**；
- **紧邻的两个 `0x2f`（其间无任何指令）合并** = 同一文本框的软换行；
- 被 `0x2d`(换说话人) 或 `0x31` 分隔 ⇒ 独立成行；
- 全角空格 `\u3000` = **两义**：① 日文**折行标记**（块首）→ 删；② **全角拉丁词间空格**
  （「Ｐｌｅａｓｅ　ｔｅｌｌ　ｍｅ」）→ **留**。判据＝两侧是否均为全角**字母/数字**
  （U+FF10-19/FF21-3A/FF41-5A）；**全角标点不参与**（否则「！　」后的折行空格被误留）。
  ⚠ 一律删 ⇒ 英文黏成 `Ｐｌｅａｓｅｔｅｌｌｍｅ`（暁 24 行受影响）；`is_text` 白名单**须含全角拉丁**，
  否则「　ａ　ｒｅａｓｏｎ」整块被弃并**打断合并**（引号不配对的隐性成因）。
- 选项（無印 `0x21` / 暁 `0x26`）按出现顺序**逐条独立成行**。

## 6. 排除

- **立绘/表情**：控制走 **opcode `0x105` + 资源名**（`chara_02_1.enc`），**不进文本块** ⇒ 无需文本过滤。
  仅留一个保护判据 `is_lie()`（去「」后按 `\u3000` 分段、**所有**段都在「部位词∪表情词」表内；实测两作命中 **0**）。
  ⚠ 曾以子串 `'全身' in t` 判立绘 ⇒ 误杀正文（無印 12 条 / 暁 11 条：「私は全身が熱くなっていく…」），**已废**。
- **调试 entry**：关键词见 `scripts/urakata_extract.py` 的 `DEBUG_KW` ⇒ **整条 entry 丢弃**。
  無印：146 特效测试 / 197 图片切换 / 198 立绘·NPC 管理表；暁：**34** 口パクテスト(8,606 块) / **150·155·156** シーン再生テスト。
- ★★ **`0x2e` 不能整体当系统消息排除**（2026-10-14 修正，曾因此丢正文）：它是「**无说话人的文本框**」，
  系统/任务/道具/技能消息与**地の文（叙事・年表）共用同一 opcode**。判据两条（命中即收）：
  ① 不含系统关键词（`覚えました`/`入手しました`/`仲間`/`受領`/`依頼`/`ください`/`ますか`/`よろず屋` …）
  ② 以 `。` 收尾。全库 **244 个唯一值逐个过目**，命中者仅 **4 句/26 块**：
  `文久三年――京。`(2) / `――安政五年。`(2) / `――同年、冬。`(2)（entry 147·148 序章）＋ `今は何もないようだ。`(20)（e0/4/5/6 的「調べる」地の文）。
  实现：`scripts/urakata_extract.py` 的 `is_narration()`；地の文**独立成行**（不与 `0x2f` 合并）。
- 说话人名（`0x2d`）：**空名 `len=4`（全 0）＝ 无说话人**（系统消息/地の文的前导），非空才是名札。
  实测该域 15,347 个日文块以 **5 字**「高杉　晋作」为主，≥8 字仅 61 块且全是名札（`浅葱色の羽織の男一`）⇒ **不藏台词**。
