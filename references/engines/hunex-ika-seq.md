## 1. 源与容器

- 源：PSP ISO9660 → `PSP_GAME/USRDIR/data/test/script.bin`（Real Rode 12,881,920 B）。
  同目录 `advdt.bin` / `gamedt.bin` / `model.bin` **同为 `HFU2` 且块内再嵌套 `HFU2`**，熵 4.3〜5.8，**无明文文本**（正则假命中）⇒ 文本只在 `script.bin`。
- `SYSDIR/BOOT.BIN` 可**全零**（本作 4,244,004 B 全 0，不可用）；真码在 `EBOOT.BIN`（`~PSP` 加密，需解密见 `01-psp-eboot.md`）。本作未反 eboot。

```
HFU2 容器（LE）
u8  magic[4] = "HFU2"
u32 count                       // Real Rode script.bin = 578
u32 tableEndAligned             // 表尾对齐值（非关键）
count × { u32 off; u32 size; u32 size2(=size); u32 hash }   // 16 B/条，表起 0x10
```
- `off` 0x800 对齐，且 `off[k+1] == ceil800(off[k] + size[k])`（逐条验证）。
- ⚠ **`off` 是读盘用的扇区对齐偏移，不是数据逻辑起点**：多块 `d[off]` 落在指令/字符串中间；
  块尾到下一 `off` 的"填充区"往往仍是**上一版编译的残留字节**（不是 `0xFF`）⇒ **别用 off/size 切块做走查**。
- 块 0 = 文件头（`HFU2` 头＋目录表；`0x2430–0x2800` 为 `0xFF` 填充）。
- `0x2800` 起有明文引擎标识：`IKA SEQ SYSTEM  v3.1 HuneX 2007 `（+ `FILETOPADDR` / `CHARID_LABEL` / `TEXADD_LABEL` 等链接标识）。

## 2. 字节码

**指令头**：`26 <u8 cmd> <u8 0x24> <u8 nargs>`（恰 4 B，恒以 `0x26` 起）。
- 每 (cmd, nargs) 的**操作数长度固定**（可用"下一个 `26 ?? 24 ??` 头之间的间距"统计出来；少数命令带字符串/表达式操作数 ⇒ 可变）。
- 操作数里会出现**成对表达式记号** `25 <tag> <val> 25 <tag>`（tag = 0x4C/0x2F/0x47/0x50…，5 B/组），与 u16/u32 立即数混排 ⇒ 走查须逐命令建表，**别想一条通式走完**。

**两条自定界记录（关键：扫这两条永不失步，§铁律 2）**

| 记录 | 布局 | 备注 |
|---|---|---|
| 字符串 | `5C <u8 L> <SJIS (L−4) B> 00 00` | **L ＝ 记录总长（含 `5C` 与 len 两字节）** ⇒ 文本字节数 = `L−4`；最大 L 实测 151 |
| 标识符 | `23 <u8 L> <ASCII (L−1) B> <u8 tag>` | 资源/标签名，可带前导 `#`（`#JUMP_SIRO_35`、`FACE_EFF05_CAT`）；末字节 tag ∈ {01,02,03,0B,11…} |

★ **踩过的坑**：`0x5C` 同时是 **SJIS 的合法尾字节** ⇒ 裸扫 `d[i]==0x5C` 会命中文本内部（假阳性约 12%）。
**判据＝要求前面 4 字节恰为文本命令头**（`26 <cmd> 24 <n>` 且 `d[i+4]==0x5C`），一次筛净。

## 4. 成行（本族要点）

1. **★ 引擎自动补开引号**：数据里**只有闭引号 `」`**（Real Rode：`」` 32,929／`「` 仅 2）。
   判据：`0x3C`（台词）32,924/33,094 以 `」` 收尾、**0 条以 `「` 起首**、**0 条含非末尾 `」`**（无内嵌引号）；
   `0x44`（地の文）仅 3 条以 `」` 收尾（作者手误）。
   ⇒ **凡以 `」` 收尾且不以 `「` 起首的行前置 `「`**（含以 `『` 起首者 → `「『…』って」`）。
   ⚠ 不补则 `check_text.py` 引号配对必判 **[E]**（数量差 = 缺失条数）。
2. **`@n` ＝ 同一文本框内软换行**（Real Rode 唯一控制码，26,201 处）→ **合并**（两个文本命令都适用）。
3. **主人公名宏＝全角＠**（U+FF20 / SJIS 0x8197），姓名札与正文**同用** ⇒ inline 替换为默认名（Real Rode「ニィナ」，可改名）。
4. `0x41` 选项：一行一条、按序（连续 `0x41` ＝同组）；图片式无字选项不存在。
5. 排除：本作 `script.bin` 内**无**日志/回想载体、**无**系统・UI（`セーブ`/`ロード`/`用語`/`辞典` 关键字 = 0）、**无**用語辞典、**无**教程。
6. 578 区块各带**同一套 184 标签的共用子程序库**（`BG_ADDR`/`FACE_EFFECT`/`Sub*`…），**库内零文本**（否则会现 578 次重复台词——实测无）。
7. **⚠ 约 20.5% 为整段精确重复**：同一场景在多个路线档各编译一份（Real Rode 最大单段 **656 条逐字相同**；例 `0x13800` 与 `0x19800` 两区块前 229 条相同）。
   **默认按文件顺序全量保留、不删改**（§0 保留原文）；如需"去重版"另出（判据＝同长度精确重复段整段删）。

## 6. 迁移提示（同族新作）

1. `7z l` 看 `USRDIR`；`grep -c HFU2` 找主脚本（`data/test/script.bin` 一类）。
2. 先 `identify`/magic 确认为 `HFU2` → 读 count/表 → **不按 off 切块**。
3. 扫 `26 ?? 24 01 5C` / `26 ?? 24 04 5C` 并**统计各 cmd 出现次数**，用"与姓名札 1:1 交替""绝大多数以 `」` 收尾"两条判据**现场推定哪条是台词/地の文/选项**（逐作可能变）。
4. 查控制码 = 收集串内所有非日文字符（本族极简，通常只有 `@n`）。
5. 主人公宏：找"姓名札里高频出现、正文里也出现"的那个非日文字符（本作＝全角＠）。
