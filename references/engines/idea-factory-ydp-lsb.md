# Idea Factory／Otomate PSP · **YDP1 + LSB**（カヌチ 二つの翼 系）

> 识别特征 → 容器链路 → 脚本记录 → 成行 → 易错。首段读通即可动手。

## 1. 识别特征（30 秒）

- 母本：PSP ISO，`PSP_GAME/USRDIR/DATA_<X>/` 下放 **`*.YDP`**（`SYSTEM.YDP` / `BGCG.YDP` / `CH.YDP` / `BGM.YDP` / `SE.YDP` / `VOICE.YDP`），
  另有同名 `INSDIR/*.YDP`——那是**安装用加密副本**（头 `\0PGD`），不要用。
- `SYSTEM.YDP` 头 4 字节 = ASCII **`YDP1`**。
- 已知作品：カヌチ 二つの翼（黒き翼＝`DATA_B`、白き翼＝`DATA_W`，2008/2009，vndb v1762／v1763）。
- 脚本组名固定 **`SCRIPT_LSB`**（`EV<章><節>-<塊>.LSB`），同盘另有 `SCRIPT_DAT`（事件标题等 `.DAT`）、`SCRIPT_EFF`（特效 `.gim`）、`BINARY`（各类 List 表）。

## 2. 容器：YDP1

```
0x00 'YDP1'
0x04 u32 文件总大小
0x08 u32 (=0x20)
0x0C u32 组表字节数（= 组数 × 0x20）
0x10 u32 数据区起点（= 全局文件目录末尾）
0x14 u32 (?)
0x18 u64 0
[0x20] 组表：每条 0x20
       name[16] | stored u32 | orig u32 | flag u16 | count u16 | group_off u32
[0x20+tblsize] 全局文件目录：每条 0x28
       name[16] | a u32 | b u32 | c u32 | size u32 | size2 u32 | rel_off u32
[0x10] 数据区
```

- 组数据起点 = **头 0x10 字段** + 组表里累积的 `group_off`（按组表顺序紧密排列）。
- 文件绝对偏移 = 组起点 + `rel_off`；**`rel_off` 是组内相对**，每个新组归零。
- 组归属：按目录顺序遍历，`rel_off` 变小 ⇒ 进下一组；`rel_off ≥ 当前组 stored` ⇒ 跳过空组。
- `stored == orig` ⇒ 该组**明文**（`SCRIPT_LSB`／`SCRIPT_DAT`／`SCRIPT_EFF`／`BINARY`）；
  `stored < orig` ⇒ LZSS 压缩（FONT／CHAPTER／BG／CH／MINI_CH 等图片组，本作未解）。
- **闭合判据（决定性）**：`Σ 各组 stored + 头 0x10 == 文件大小`。
  カヌチ黒翼：`0x395AC00 + 0x30E98 = 0x398BA98` ✓。对不上就是组归属算错了。
- 目录起点不在 `0x20+tblsize`：中间还夹了 0xF8 字节别的东西。
  稳妥做法＝从 `0x20+tblsize` 往后扫，取「本行 + 0x28 + 0x50 三行都是可打印名」的位置。

脚本：`scripts/kanuchi_ydp.py`（工作区 `scripts/kanuchi_ydp.py`）。

## 3. 脚本：LSB 记录

明文 cp932，记录形态：

```
[记录头][名札\0][正文\0]     有名札
[记录头][正文\0]            无名札（头尾常见 0x0026 / 0x0040 之窗口码）
```

- **名札判据：名札串与紧随其后的正文串「零间隔」**（名札的 `00` 之后立刻是正文首字节）。
  名札长度 ≤12 字、不含 `。！？、…「」（）`，多以平假名动词尾结尾者**不是**名札（那是选项）。
- 记录头长度不一（8/10/12/24 B 都有），**不要试图按固定头长走**——用正文串自定界即可。
- 头的末尾常是 `… 00`，所以「前面是 0x00」**不能**用来判正文。

## 4. 成行

| 码 | 含义 | 处理 |
|---|---|---|
| `5C`（`\`） | 框内软换行 | 合并（一次点击 = 一行） |
| `5C 5C`（`\\`） | 翻页（下一个文本框） | 断成新行 |
| `26`（`&`） | 主人公**名** | 行内替换（カヌチ＝アキ） |
| `25`（`%`） | 主人公**姓**（`&・%`＝全名） | 行内替换（カヌチ＝ミヤズ） |
| `40`（`@`） | 另一位可改名主角（カヌチ＝カヤナ） | 行内替换 |
| `24`（`$`） | 主人公**真名/イミナ** | 行内替换（同 `&`） |
| `23`（`#`） | 用語辞典关键词标记，成对 | 去壳留词 |

**选项块**：`FD FF FF FF` + 8 字节（两个 u32）+ **连续 N 个 NUL 结尾串** = 该次选择的全部分支。
选项与正文同流、同样是一行一条；两组选项彼此**零间隔**，所以「零间隔串对」会把第 1 个选项误当名札吃掉。

脚本：`scripts/kanuchi_text.py`（工作区 `scripts/kanuchi_text.py`）。

## 5. 易错（本作实踩）

1. **选项被当名札吃掉**：`A？\0B？\0` 两个选项零间隔 ⇒ 按名札规则 A 被丢。
   修法＝①先扫选项块，块内偏移**永不判名札**；②`len≥4 且以平假名动词/助动词尾结尾（いくすよかてるなわねのどばらりけせめろぶぐず）` 不判名札。
2. **指令字节被读成正文**：`26 26 00`（op `0x2626`）→ 串 `"&&"` → 替换宏后输出「アキアキ」（本作 563 行）。
   修法＝纯标点/纯宏串必须**含至少一个日文标点**（`…‥、。！？・` …）才收；单字符串一律不收。
3. **名札本身含宏**：结尾改嫁后名札写成 `&・キリヒ`。⇒ 名札黑名单里**不能**禁 `&@%$`。
4. **空正文框的名札**：`名札\0` 后直接跟窗口头 `64 00`（正文为空）。⇒ 补判据：串后紧跟 `64 00` 且 ≤8 字、无平假名、非纯汉字 ⇒ 判名札。
5. **半角假名／PUA／希腊字母**：都是「字节被错读」的信号，不是原文。用**字符白名单**（平假名/片假名/汉字/`3000-303F`/全角/`2026 2015 2014`/ASCII 白名单）一次挡掉。
6. **`5C` 要在 ASCII 白名单里**：漏了它会把带 `\` 的正文整条丢掉（本作曾因此少 3 万串）。

## 6. 附：用語辞典 `DICT/Lib_*.bin`
