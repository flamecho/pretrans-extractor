# BlueImpact · BSF1

## DAT 目录

匹配布局为 `u32 dir_size` 后的变长条目：`u32 entry_size,data_offset,data_size + name NUL`。
entry_size 含 12 字节字段及名称，数据区自 `4+dir_size` 起；确认目录闭合、偏移基准和成员范围。
同名脚本按加载器的补丁优先级选择，不能固定 game00 为所有版本的覆盖层。

## BSF1

BSF1 后为 `name NUL + u32 absolute_offset` 标签表，空名终止占一字节。
标签可指向 EOF 空段；代码起点在终止符后。
匹配记录中 u16 op<=38 为 `op + u32 L + L 字节参数`，其余可为裸 CP932 NUL 串。
参数内结构由 opcode 定义，不能重复按 L 读至末尾；越界或缺 NUL 应报出。

## 消息状态

文本登记器可新建消息或延长当前记录，绘制器可能只在首行清窗。
从登记、等待和清窗命令确定页及新增点击段，不能把每条裸串固定当一页。
标签和未注册脚本通过真实调用核对；指针表引用与代码直接引用分别搜索。
