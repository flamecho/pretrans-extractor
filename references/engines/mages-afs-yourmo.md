# MAGES.（旧 KID/5pb.）PSP 自研 —— CRI AFS ＋ NUL 分段文本池

> 代表作：**ユア・メモリーズオフ～Girl's Style～**（PSP `ULJM05435`，2008，vndb v1964）。
> 判型特征：容器 `AFS\0` ＋ 文本池内以 **`%K%P` / `%W` / `%V`** 收尾的记录。
> 与 STCM2L / Koei CDAR / HuneX / Zerodiv 均不同族（无 magic、无指令链、无槽数）。

## 1. 容器

```
ISO9660 → PSP_GAME/USRDIR/SCENE00.AFS
  header: 41 46 53 00 | u32 count(=203) | count×(u32 offset, u32 size)
  条目 offset 全部 0x800 对齐；块间 0 填充；块尾亦可能有 0 填充/碎片
```
- 只有 `SCENE00.AFS` 含剧本；`BGL*/BGS*/VO*/SE*/CONFIG/FONTS/ICON/OBJ*` 为图音资源。
- `SYSDIR/BOOT.BIN` 头 16 字节全 0（非明文 ELF），本作**用不到**。

## 2. 块内布局

```
[0x0000 – X]  二进制表：立绘/坐标/名字池/分支名/调试表（逐块不同，含 PUA 伪文本）
[X – 末]      文本池：CP932 字符串，以 \0 分段
```
- 文本池起点**不写在头部**，须用「第一个含终止命令的段」反推（本作 blk96 = 块内 0x5B65）。
- 块 0 特殊＝**全作选项总池（330）＋名字池（138 种名札变体）**；实操中 327/330 与各块内嵌选项逐字重复 ⇒ 只需收内嵌。

## 3. 记录＝一次点击

一条记录以**终止命令**收尾；`\0` 只是分段符（一框可被拆成多段）：

| 命令 | 语义 | 处置 |
|---|---|---|
| `%K` | 点击等待（主力） | 终止 |
| `%W` / `%V` | 演出框等待（`%S064%FS%LC…%FE%LE%W`） | 终止 |
| `%N`（段尾、无 K/W/V） | 少数框收尾 | 终止（须带正文） |
| `%P` / `%N`（尾） | 清屏 / 不就屏 | 剥 |
| `%p` | **选项等待** | 剥；其后无码段＝选项 |
| `%N`/`%n`（段中） | 框内软换行 | 合并 |
| `%FS/%FE` `%S0xx/%O0xx` `%LC/%LE` `%t0xx` `%CFxxxx` | 样式／色／字号／歌词时序 | 剥 |
| `%D` `%s` `%d` | 数值/格式变量（仅系统・debug） | 属排除块 |

名札内嵌记录首部：`【海】` `【俊一＃】`（心の声）`【くーた(声)】`（声音）`【拓(ラ)】`（广播）`【拓？】`（未知名）`【俊一２】`（第二形态）`【海＆俊一(海)】`（双人）；**按规范整段剥离**。

## 4. 三个必须处理的形态

1. **一框多段**：`%O032`（样式结束）夹在两段之间会把一框切开 ——
   `【俊一】「あ！　それ、どこにあっ……`（无终止） ＋ `ツっ！」%K%N`（终止） ⇒ **拼接成一行**。
   实现：`buf` 累积到下一个终止段再 flush。
2. **块前命令区里的内联正文**：blk199 @段3514 `【スタッフ１】「５・４・３――」%N` 位于文本池起点（3517）之前，
   前面只隔着 `%L1` / `～　%T2　～` 等纯命令段 ⇒
   **向前回退**（跳过纯命令/空段，遇正文则纳入，遇二进制则停）才不会漏。
3. **`%W`/`%V` 段与 `%K` 段同等对待**：只认 `%K` 会漏 32 条演出文本（序章夢境/歌词/舞台）。
