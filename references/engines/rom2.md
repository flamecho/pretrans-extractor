# ROM2

## ROM2 / SNR

ROM2 为资源归档，SNR 头含 SNR 签名、文件长和区段偏移表。
代码、名称、菜单及媒体表按头声明定位，不保存固定脚本流地址。
匹配消息记录为 `87 + u16 A + u8 F + 01 + u16 C + u16 LEN + content`；验证 LEN 与命令范围。

## 文本与选择

content 可含名札、@r 排版、@v 语音、@b/@</@> 注音及 %0 姓名宏。
控制按完整参数读取，注音取基底；姓名初值取配置或输入表，显示方式按窗口处理。
选择可为长度块内 NUL 串列表，另有目标表；核对项数、块长与分支引用。
页界依据消息、等待及清页命令，菜单字符串不能因位于代码前部就整体排除。
