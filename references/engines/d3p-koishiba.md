# 引擎：D3P/Vridge 自研 ADV · **恋は校則に縛られない！（PSP）** 变体

> 同族总册＝`stormlover-d3p.md`（PSV V/2ndV）＋ `stormlover-d3p-psp.md`（PSP 夏恋!!）。
> 本册只记**本作差异**：字形尺寸、槽表、`FF8F`、选项装饰。

- 源：`<游戏 dump 目录>/定时/[PSP-JP]恋は校則に縛られない！.zip` → 单 ISO（1.69 GB）
- 编号 **NPJH50704**（PARAM.SFO）／開発 Vridge／販売 角川ゲームス／2012-11-29／vndb **v9178**

## 容器
- ISO9660 → `PSP_GAME/USRDIR/DATA/sc.cpk`（**CRI CPK v7，420 条目，无压缩无加密**）＝唯一剧本容器
- `union.cpk`＝图/音；`vo.awb`/`se.awb`＝AFS2；`pr.bin`＝二进制（非文本）；`EBOOT.BIN`＝`~PSP`（未用）

## ★ 字形：`lt.bin` = **16 × 16 / 4bpp / 128 B 字形**
- 450,560 B ÷ 128 = **3,520 字形**；索引 == 游戏码。
- 自相关峰 **8 B（行距）/ 128 B（字形步长）**；4bpp **高半字节在前**。
- 锚字：566=`一`、1335=`口`、209=`あ`、53=`「`、147=`１`。
- 与夏恋!! PSP（18×18 / 162 B）**不同**，勿混用渲染器（`scripts/koishiba_font.py`）。

## ★ 字符集
- **基础区 0..3455 ＝ cp932 原码序**（与 D3P 全系同版；剔 0x81FC/Greek/Cyrillic/0x849F）⇒ 剧本直读可懂。
- **专用槽 3456..3512 共 52 个**，逐作独立：

  `―丼儘儚凛誉咄嗅嗟囁姜矮恫惧痺麻憑掟揉煽敲晰曖噌鬱墜淹煌璧疵癇皺盒眩羨磋祟筐箋籠絆腑舐菓藉謳贅躾軋轢鑽騙`

  ⚠ 与 STORM LOVER V 的 3524..3557 装饰区、2ndV 的 3570.. 无关；**逐作重标**。
  ⚠ **常用汉字也会占槽**（誉・痺・麻・菓・墜・疵 等）⇒「cp932 索引 < 3456 必属基础区」这条判据在本作**失效**，
  只能以 **lt.bin 字形** 定值（并核 `CHARSET.index` 是否真被正文使用：如 `華`=736 已用 14 次 ⇒ 槽 3486 不可能是 華）。

## 命令集（≥0xFF00）

| cmd | 含义 | 处理 |
|---|---|---|
| `FFF0` | 名札：run＝`<样式符><NAME>` | 丢弃 |
| `FFFF` | 框开始＝一次点击 | 起行 |
| `FFFE` | 框内换行 | 合并 |
| `FFFB` / `FFFD` | 消息分隔 / 框结束 | 收束 |
| `FFE6` / `FFE7` | 主角 姓 / 名 宏 | 名札区丢；正文 inline |
| **`FF8F`** | **同框另段文本**（咳き込み `コホッ、コホッ――」`） | **并入当前框** |
| 其余 | 语音 id / 坐标 / 图标 | 丢 |

## 选项
与正文同流（连续 `FFFF`）。每个选项带**装饰字形**（游戏码 <0x20 标点槽，或 `《〕［『≠♂｛｜”‘～＜；：゜？` 之类被当按钮图标）；
另有**单独成框的框线括号**（`《`/`［`/`』`/`（`/`〕`）。
⇒ 处理：① 首码 <0x20 全剥；② 首装饰字形剥一个（剥后须立刻是正文起首）；③ 纯装饰符号行（无假名/汉字/数字且非 `「…」`）整行丢。
