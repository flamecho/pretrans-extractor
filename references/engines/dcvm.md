# ROFS / DCVM

## ROFS 与压缩块

ROFS 数据可按 1024 字节分页，页头 `u16 0x19A6 + u16 type + u32 comp + u32 raw`。
type=1 为单 zlib 流；type=2 可为 ZPZP 多流包装，其头提供流数、头长与偏移表。
按表逐流还原并拼接，原始块与压缩块分别识别；未知页头不直接当作文本。

## DCVM 区段

DCVM 区段常为 `[tag][u32 size][data]`，size 含八字节段头。

| 区段 | 用途 |
|---|---|
| STR | 按类型分组的字符串池，池序不等于显示序 |
| FTBL | 名称、地址、flags 等符号信息，funcid 在各块内解释 |
| CODE | 导出桩、函数体和调用；部分代码只注册对象 |
| STBL | `size,count,offsets[count]`，偏移基准由 STR 布局确认 |

STBL 可提供编译发射序，使用前核对引用与实际调用；不能由可读串邻近地址猜偏移基准。
VM 的立即数宽度、栈式跳转和局部符号地址依据读取原语确定，不继承特定主程序的指令表地址。

## 文本与状态

正文、心声、选择、资源、标签及姓名可能同池存储，通过引用用途分类。
消息末控制、选择组、样式和变量按显示调用解释，不按行首字符、串长或池序排除。
