# RPG Maker

## 容器与事件

MV/MZ 以 JSON 数据和运行时 JavaScript 为主，VX Ace 使用 RGSS 数据及 Ruby 运行时。
Map 和 CommonEvents 均可承载剧情，入口、事件页条件及调用共同确定范围。
RGSSAD v3 签名为 `RGSSAD\x00\x03`；索引 key 可由 `seed*9+3` 初始化，成员数据使用条目给出的 key。尾部不足四字节按匹配实现处理。

## 消息与选择

| 事件 | 处理 |
|---|---|
| 101 / 401 | 开始消息并添加文本行 |
| 102 | 选择组，关联当前事件用途 |
| 105 / 405 | 滚动文本，按连续显示序列消费 |
| CommonEvent 调用与事件页 | 维护执行条件与来源 |

事件组不天然等于一页。窗口尺寸、行高、背景、位置、need_new_page 与插件决定自动分页和续写。
\!、\^ 等控制码按 Window_Message 的实际处理解释，排版与内部等待分别跟踪。
\N[n] 从 Actors 或运行状态求值，\V[n] 跟踪变量赋值；确定不了的槽按既定模板策略处理。
