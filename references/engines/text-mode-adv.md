# 文本方式 ADV

## 表与行式脚本

此文本方式 ADV 可在 PSARC 中保存 UTF-16LE 的行式脚本、标签表、指令字典与 scrlst 流程表。
先读取资源指令表和脚本标签，分离命令、姓名与真实显示文字；不能只用串长、标点或角色词表分类。
标签表映射全局步号与 label，scrlst 关联脚本、入口及步范围，文本順序由执行关系确认。

## 显示与选择

一物理行可为指令、消息片段、名札或选择，步号不等于输出行数。
软换行与原文空白按显示实现处理，姓名占位沿定义与初始化求值。
选择结合后续分支标签和调用读取，选项组的步计数与逐项输出分别核对。
同宿主的二进制表可能为其他作品或编辑器残留，核对实际调用后分类。
