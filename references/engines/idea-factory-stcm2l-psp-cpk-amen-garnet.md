## ② アーメン・ノワール ポータブル（2012 Otomate／Design Factory）

- **★ PSP 侧 第 4 布局（`アーメン・ノワール ポータブル`，2012 Otomate／開発 Design Factory，`ULJM06064`）—— 与 SNOW BOUND LAND 同族但**判据完全不同**：**
  - 容器链：ISO9660 → **`USRDIR/UNION.CPK`（CRI CPK **v7**，4304 条目，**条目名＝纯数字 ID**，无目录层级；4141 条 CRILAYLA 压缩）**
    → 脚本 = **`STCM2L` 魔数的条目（ID 3xxx，共 157 个）**。★ `INSDIR/UNION.DNS` = `\x00PGD`（key 1/drm 1）
    → `scripts/pgdecrypt.exe` 解出，**md5 与 `USRDIR/UNION.CPK` 完全相同** ⇒ 媒体安装副本，无更新数据，可整体忽略。
    ★ `SYSDIR/BOOT.BIN` 整文件全 0（无明文 ELF），真码在 `~PSP` 的 EBOOT.BIN（本作未解密，结论不依赖）。
  - **★ 每个脚本开头都带一段逐字节相同的「公共前导块」**（`色変化判定`×4／`1sho`〜`7sho`／`1day`〜`3day`／`makuai`／`wipe_a/b`／`suma`…）
    且 **`3400`–`3484` 共 85 个脚本只有该前导块（各 298 条记录）** ⇒ **必须靠「资源名规则」在行层滤除，勿按文件删**。
    系统脚本 `3000`–`3007`／`3100`／`3200` 同理（零台词）。
  - **★ 代码段 = `[u32 size][payload]`；payload = `[12B「槽」× k][文本记录…][12B 收尾 `[0][cmd][flag]`]****
    - 槽 = `[u32 值][0xff000000][0xff000000]`，值 = 「该记录头在文件中的**绝对地址**」= 引用该记录；
    - 文本记录 = `[0][L/4][1][L][cp932 text][NUL pad]`，`L = align4(bytelen+1)`，`L/4` 复写。
  - **cmd（收尾三元组中段）＝ 语义**：`0xd4` flag1 = **正文框（3 槽；槽内多段直接拼接 = 一个文本框）**；
    `0xdf` flag4 = **名札框（1 槽）——既装角色名，也装 `　　　` 缩进叙述与 `【…】` 说明 ⇒ 必须靠内容分**；
    `0xe7`/`0xe6` = **选项（1 槽）**；`0x34` flag2 = 记录＝`select` 的**选项组终止标记**；其余 cmd = 立绘/背景/音效/变量/wipe 资源指令（记录多为资源名）。
  - ★★ **选项组判据 = 「`select` 记录之前、紧邻的一串『恰好 1 槽』op」**（遇 3 槽正文框或名札框即停）。
    **同一条 cmd 兼作正文与选项**（实例：提问行 `「……。クリムソンは……」` 与选项 `何者なの？` 都是 `0xe7`）
    ⇒ **只按 cmd 分派会把提问行当选项拆成多行**（本会话踩过：成品引号不配对 10 处）。
  - ★ 少数 op 的收尾三元组是 **16B**（如 `[0][1][0xbc0c][4]`）⇒ cmd 探测须容错，不可硬取「末 12B」。
  - **主角宏 `#Name[1]`**（全库只有这一个 `#Name` 索引，9,973 次；9,812 次为独立名札框）→ **ナスカ**（vndb v4633 Protagonist）。
    ★ 样式标签（`#Color[7]`/`#Scale[1.8]`/`#Pos[0,23]`）须**先剥再 strip 空白**，否则 `#Pos…#Scale…　　 「…」` 会残留行首全角空格。
  - 名札表 87 种；vndb 16 名全中；另 16 项（`ムーン`/`オロチ`/`八咫烏`/`アーロンダイト`/`アンドロマリウス`/`アシュラ`…）＝ ＣＡ（契約兵器）名・賞金首名・PSP 追加角色 ⇒ **非缺陷**。
  - **要收**：正文（台词/独白/地の文）／选项／`　　　` 缩进叙述／`【…】` 说明／直接上屏特效行／**结局标题卡**（`ソード　バッドエンド`）。
    **不收**：资源符号／角色名札（含无假名汉字的装饰性名札 `【――――】`）／`select` 标记／系统脚本／空壳脚本。
    **本作无用語辞典**；CPK 内另有 `3011`（**手配書データ**：懸賞金/契約ＣＡ/ランキング/説明文）与 `3010`（サウンドテスト 曲目表）
    ⇒ **図鑑/UI 菜单，按 §0 不收**（结构：`3011` = 变长记录 `[u32 0x00010259+][u16][cp932][00][FF pad]`）。
  - **原文缺陷 3 处**（2 处整框缺收尾 `」`＋1 处双 `」`）⇒ **整行定值表**修（`FIX`）。
  - 工具：`scripts/amennoir_extract.py`（可直接吃 CPK 或已解包目录；参数集中在顶部 `KEEP_IDS`/`SYM_*`/`FIX`/`HERO`）。
    产物 **23,501 行 PASS**（65 个剧本）；报告 `提取结果/解析报告/アーメン・ノワール ポータブル_解析报告.md`。

## ③ ガーネット・クレイドル ポータブル ～鍵の姫巫女～（2011 SPICA／オトメイト，`ULJM05858`）

- 容器：ISO9660 → `USRDIR/CPK/DATA{0,1,2,3}.CPK`（CRI CPK，条目名缺失 ⇒ 纯数字 ID）。
  **`DATA0` = 6 MB／521 条目，全部 `STCM2` 脚本**；`DATA1`=CG(ART2)／`DATA2`=影片+BGM 子 CPK／`DATA3`=语音 ⇒ **正文只在本 CPK**。
  ★ `SYSDIR/BOOT.BIN` 全 0；`EBOOT.BIN` 未解（结论不依赖）。
- 头：`"STCM2 File Make By Minku 07.0"`；`0x20`=exports_offset（代码终点）；`CODE_START_`+24 = 代码起点。
  op = `[u32 size][payload]`，payload = `[12B 槽×k][文本记录×m][12B 收尾 [0][cmd][flag]]`（与 ② 同族）。
- ★★ **cmd 集与 ①② 都不同**（换作必须重统计「cmd × 槽数 × 记录数」）：
  `0xd4`=**说话人框开始**（带脸参数）／`0xd2`=正文片段 **或 名札**／`0xd3`=片段+框末／
  `0xe7`(1 槽)=框末变体／**`0xe7`·`0xec`(2 槽)=选项**／`0xe6`·`0x33+'select'`=选项组终止。
- ★★ **名札＝结构判定，零猜测**：`0xd4` 与「其后紧跟的 1 槽 `0xd2` 文本 op」全库 **19,461:19,461 严格 1:1**
  ⇒ 该 op 即名札（丢）。名札内容无一以 `「` 开头、无长句 ⇒ 无误杀。**「槽数」是最强判据**（正文/名札 1 槽、选项 2 槽）。
- 扉文/章题卡：非文本 cmd 的日文记录 **且其后 1〜3 op 内有「≥5 槽 + 记录以 `IMG`/`BG` 开头」** ⇒ 收一行（85 条）。
  同一批标题在「路线跳转表」里成组出现（各路线设一次再统一画一张菜单图）⇒ 被判据自然排除。
- 空串占位：记录 `FF FF FF FF` 经 **cp932 解成 `U+F8F3`×4** ⇒ **空串（非未解析）**，剔除。
- ★ CRILAYLA：`scripts/cpk_v1.py` 在本作**越界失败**；用 `scripts/cpk.py` 版（多级 2/3/8/13 bit）一次通过。
  **自证：解出必须等于 `STCM2 File Make By Minku 07.0`。**
- 名札表 64 种；vndb **v1739** cast 9 全中（主角 `天橋 美紅`/Nameable → 默认名 `美紅`，全库 `#Name[1]` 8,499 处**全在名札** ⇒ 成品 0 次，正文只称 お姫様／アミーラ／貴女）。
- 工具 `scripts/garnet_extract.py`（`SKIP_IDS`/`MEMO`/`TAGS` 在顶部）；产物 **30,235 行 PASS**。
