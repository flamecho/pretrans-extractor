# 验收、完整性与报告

## 交付自检

### 验收

1. 按[完整性](verification.md#完整性)核对源、收录、排除、未决项与输出关系，复用解析统计。
2. 按边界、姓名、宏和异常类型抽查；同源同规则分组核对，不逐条重复调查同类警告。
3. 核实[字符基线](verification.md#字符台账)，运行品检并保存结论。

`check_text.py <文本> --report <报告>`，按下表添加参数；执行路径见[工作区](workspace.md#工作区与记录)。

| 条件 | 参数 |
|---|---|
| 已证双版 | `--dual --expect-dual` |
| 已有页映射 | `--layout-map <映射>` |
| 精确例外 | `--allow <文件>` |
| 已知姓名出现检查 | `--name <姓名>` |

退出码 0 不证明语义或覆盖正确。编码、控制码、未解宏、未知字符及版式冲突须处理；已授权模板用来源映射生成精确例外。
引号、长行、重复、ASCII 和标点警告回源归因，不能为消警告改原文。

### 验证复用

从既有报告或解析摘要查通过记录、相关依赖及品检参数。任务中断不使已完成检查失效；输入未变则复用，只补未完成项。变化后按下表验证。

| 变化 | 范围 |
|---|---|
| 源、解析器、显示配置或转录 | 更新受影响产物，核对语义、覆盖并品检 |
| 后处理、映射、字符基线或例外 | 核对关联输出，重跑受影响检查 |
| 品检实现或参数 | 重跑对应检查；实现变更另跑回归 |
| 文档或落位 | 核对改动的引用及路由；只有提取规则实际改变才更新产物 |
| 清理临时目录 | 核对目标路径与归属；复用报告中的验收结论，不另跑品检或摘要 |

检查生成新异常或相关输入改变才复跑。解析缓存与查询复用见[探查与记录](workspace.md#探查与记录)，不另建相同的审计流程；新增检查须能发现已有断言未覆盖的错误。结果保存到[报告](verification.md#外查与报告)。

## 完整性

### 范围

按指定范围核对脚本、入口、场景表、调用、补丁及额外剧情，只探查未知或文本链路相关载体。
文件名、静态未引用及探针零命中不足以排除正文；回想表可能遗漏序章、坏结局和动态调用。
排除须有记录用途或已证控制流依据，保留源位置及理由。

### 结构

复用解析统计，选择能约束当前格式的检查。

| 结构 | 检查 |
|---|---|
| 目录、头部、长度及地址表 | 字段语义、记录范围、覆盖与未消费区 |
| 池与引用 | 真实文本参数的地址、长度、索引及用途分类 |
| 内联文本 | 记录边界与载荷；存疑时查体外候选 |
| 明文脚本 | 命令、宏、分支及调用链 |
| 原生编译剧情 | [显示调用及字段](script-structure.md#原生显示调用)，含包装、间接分派和共用表变体 |

代码按读取原语推进，填充、数组和媒体区单独处理；常量、颜色、变量及跳转值不加入文本引用集合。
未引用串按用途分类，不要求未引用日文为零；已定位原生显示调用时不再全量导出字符串池。
非法引用或失步由解析器造成时修正；源自带缺失标签或损坏操作数登记异常，不能因分析失败删除正文。

### 源与输出

分别计正文、选项、名札与宏、系统、资源、空项及未决项，解释注音、宏、合并及分支展开造成的差额。
`最终行数 = 段行数 + 多段页数 + 额外条目数`；计数由源命令、页映射和调用变体得出。
源消费与派生重复分别计数；不同源或分支同文保留，去重须证明重复消费、日志或资源副本。

字节消费完整不证明编码或显示正确。
缺口修正后复查受影响范围；关键缺口未解时记录证据，不能归入其他后宣称全部提取。
[报告](verification.md#外查与报告)汇总计数、排除及未决项，来源明细保存一份；验收见[自检](verification.md#交付自检)。

## 字符台账

字符基线限制非日文字符集合，不证明解码或宏正确。

### 核实

`charset_audit.py` 输出字符、次数及上下文，优先检查字形、宏、控制码和编码异常。
按来源规则分组登记，保留位置；段行与合并行不重复审计。
已核实结果可直接写基线；`check_text.py --init-charset` 只生成基线，仍须核实和最终品检。
新增字符先查来源，保留正确解码的原文符号、半角假名和同形字。

### 文件机制

| 项目 | 规则 |
|---|---|
| 默认路径 | 相对文本目录的 `../解析报告/allow/<文本名>.charset` |
| 数据 | 行首字符生效，后附频次或来源 |
| 注释 | 仅 `# `、`#@` 起首；字符 `#` 用 `#\t次数` 数据行 |
| 错误 | 缺基线或新字符报错；已登记字符仍可能组成未解宏 |
| 精确例外 | `.allow` 不替代 `.charset`，须有原文依据 |

宏和样式按[姓名规则](names-and-macros.md#名札与关联)及实际语法处理，不通配删疑似标签或括号。
解码见[解码](decode.md#字段与编码)，字形见[字体](decode.md#自定义字体)。报告只汇总来源类别及例外。

## 外查与报告

### 外查

仅解决未决码表、字形、身份或默认值；源码及官方资料优先，数据库、攻略和实况作佐证。
冲突核对版本、别名及编码，不以外部身份覆盖源码默认值。
VNDB：`POST https://api.vndb.org/kana/character`；`vn` 用嵌套过滤，角色字段 `vns.role`，按需分页取字段。

### 报告

保存到 `解析报告/<作品>_解析报告.md`。

| 内容 | 要求 |
|---|---|
| YAML | `作品、平台、引擎、主角、行数、日期`，或 `title/platform/engine/main/rows/date`；无主角可省略 |
| 版式 | `- **版式**：单版` 或 `双版对照`，品检前填写 |
| 范围与方法 | 源版本、收录及排除、解析和显示依据、复用条件及差异 |
| 验收 | 段行、多段页、变体、总行数、检查结果及未决项 |
| 复现 | 实际工具、参数和必要依赖；版本或摘要仅记影响复现者 |

清单、映射及反汇编在任务中用于核对，不重复粘贴到报告。完成后记录验收结果；归档与清理按[工作区](workspace.md#收尾与维护)，不要求长期保存证据或复现数据。

异常定位和具体格式线索按需查[验收异常与格式案例](verification-cases.md)，不作为每作必读项。
