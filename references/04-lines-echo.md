# 话者名自举 / 槽拆分与回声

> B10–B12（名札边界/记录框语义）见 `04-lines-names.md`。

**B14. 行式脚本「话者名」自举挖掘（爽海バッカニアーズ! 実証，无名表时通用）**
行式脚本（1 行 1 步）常常**没有独立的名字表**，`话者名` 与`正文`同为普通行。可靠做法＝**自举**：
1. 候选＝**短行**（≤15）、**不含句读**（`。、「」『』（）`）、不含 `\`。
2. 判定：候选的**下一个「非表现类」行**以 `「`/`『`/`（` 开头 ⇒ 该候选是话者名（名下可能是台词或 `（）`独白）。
3. 传递：若下一行**本身已是话者名** ⇒ 该候选也是话者名。用于覆盖 **「内部 ID ＋ 显示名」双行**形态
   （例：`ドレイク` ⏎ `リアンの父` ⏎ `「…」`；`フレデリック` ⏎ `ディーン` ⏎ `「…」`）。
4. 迭代 2〜3 轮至收敛 → 得到**全局话者名集合** → **丢弃其全部整行出现**（同一名札在各脚本反复出现）。

⚠️ 关键边界（这三条不注意就会误伤）：
- **lookahead 只许跳过「表现类」指令**（BG/BGM/SE/演出/表情等），**不可跨过分支/脚本名/标签等结构指令**。
  跨过的话，地点/选项列表（`教会`⏎`大通り`⏎`裏通り`⏎`<分支脚本>`）会因「再往后终于遇到 `（`独白」而被
  误链成名札 → 整组选项丢失。
- **选项文本常紧邻分支脚本名之前**（`支持する` ⏎ `00_kg_004_2` ⏎ `START` ⏎ `00_kg_004_1`）⇒ 其下一「非表现类行」
  是**结构指令或没有**，因此不会被判为名札 ⇒ 正确保留。**不要把「后面跟分支脚本」的短行当名札丢**。
- 名札里可能有**角色名以外的词**：职务/端役（`商人`/`門番`/`船員Ａ`/`隊員たち`/`舞台監督`）、
  **集团名**（`レッドホーク海賊団`）、**未知话者**（`？？？`，含 `？` ⇒ 候选判据要放行 `？`/`！`，只排 `。、「」『』（）`）。
- 少数**演出/SE/命令**混在短行里（`縦揺れ`/`横揺れ`/`縦横`/`移動モード`/`ビンタ1`）→ 人工核对后并入指令排除表。

**B23. 文本框被拆成多「槽」＋ 引擎写入回声（幕末Rock `SKTH`／馆内短剧，2026-10-11）**
- 馆内观看文本（`ui_skit_*.skt` 类）把**一个文本框**存成**连续多槽**：槽 = `[u32 字段]` ＋ cp932 文本。
  **槽内可含 `0x0A`** —— 扫描别把 `<0x20` 一律当终止，否则括号句被劈成两半（成品报 `引号不配对` E）。
- **合并判据＝括号闭合探针**：行尾 `（ 「 『` 未闭合 ⇒ 与下一槽同属一框，先并起来。
- **引擎写入回声**：上一句/上一本的句子会被再抄一遍（实测约 25%）⇒ 用「与最近 N 条已保留行完全相同 ⇒ 丢弃」清，
  N=3〜5（本作 4）；⚠ N 太大会**误杀故意的复读梗**，试读几本再定。
- 补漏：剩「孤立闭括号片段」⇒ 去掉括号后内容已在别处出现者丢弃，否则并回上一行。
- 名札：行尾全角空格（`晋作　`）＝独立名札行 ⇒ 丢；槽内「名札＋正文」粘连的**不强行剥离**，报告单列。

- ★ **「容器/结构节点」≠ 必然断行**：断行判据要写成**节点集合**。AK：`5(来訪者1) 8(様と) 5(来訪者2) 8(様…入ってもらおうかな？)`
  拼**一行** ⇒ 「提示节点起新行后**仍吸**续写节点」，框容器 `t=1` 才断。

**B32. 整段正文由「槽拼接」生成：`0xfc` 可**只带槽、不带字面串**（Takuyo gss／星色のおくりもの 2026-10-17）**
- 症状：某类脚本 `0x5a` 计数 = 0、`0xfc` 也不带 `(3,串)` ⇒ 提取器输出 0 行，看着像「该类脚本无文本」。
- 实态：`0xfd (6,<slot>)(3,<串>)` 建立 → 连串 `0x107 (6,<slot>)(3,<串>)` **累加** → `0xfc (6,<slot>)` **打印该槽**。
  实例（相性占い `PRG_*_FORTUNE`）：7 段短串拼成一段 100+ 字的运势文；同作 Little Aid 用它拼**场景标题卡**。
- 处置：提取器要带**槽求值状态机**（`0xfd` 赋值／`0x107` 追加／`0xfc` 无字面串时取槽值），**在打印点出文**（别在 `0xfd` 处出，否则出成碎片）。
- 判据：`0xfc` 的操作数**首项是 `(6,slot)` 且无 `(3,…)`** ⇒ 一定是槽打印，不是空指令。
- 附：同族另一坑 —— `0xfd` 写的是**名札槽**（本作 `d402`）时它在正文脚本里出现上万次，但按 §0 整条丢弃；
  **别把「`0xfd` 有日文串」误判成漏收正文**（本作 10,049 条 0xfd 日文串全指向名札槽）。
