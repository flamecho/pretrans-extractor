# 成行与多文本案例

## 格式与成行

主规则见 [输出规范](output.md#输出规范)，边界证据见 [取证](layout.md#边界取证)。
以下为格式定位信息，不以标点、长度或相邻记录代替显示语义。

### 点击与页界

状态与输出见[成行](layout.md#成行状态)。

| 结构 | 处理 |
|---|---|
| 连续记录或换箱记录 | 确认读取和显示用途后拼装，不凭相邻合并 |
| 内联变量、Naninovel `PrintText.parts` | 按片段顺序拼装并求值，完整保留显示文本 |
| 槽位 k 与尾标记 cmd | 联合判型，不能仅按 cmd 收取 |

アンジェリーク トロワ 的残片或变体不得按括号配平合并，也不能链式累积形似片段。
正文、选择和叙述即使共享同一缓冲仍按控制语义分别输出。

マスケティア EVB 的边界命令包括：

```text
0A 00
FB FF <u16> <u32 B> <u32×B>
FE FF <u16> <u32> <u32> <u8>
```

按命令长度消费参数，不用“跳过非字符字节”恢复对齐。
参数 B 表示后续 u32 数量，页首、扉文和选择须覆盖。

### 字符边界与扫描候选

NUL 串扫描只用于定位，不能替代命令解析。纯 ASCII、宏、PUA、希腊字符或单字
都可能显示；不使用字符白名单静默过滤。カヌチ 黒翼 的 `&&` 可能来自操作数，
须确认真实文本指令后替换。选项记录 `FD FF FF FF+8B+N串` 按结构读取，不作名札候选。
`FFE6/FFE7` 连续姓名宏按 token 链解析，不能要求每个宏前面都是正文命令。

alto 的尾随 `@` 应在 CP932 严格解码后按字符判断，或在解析器确认字符边界后处理。
`81 40` 是全角空格，不能因末字节 `40` 删除一字节。
解码失败保留来源并修正读取，不用 `errors='replace'` 继续产出。

### 重复与覆盖

去重与覆盖见[完整性](verification.md#完整性)。

Aromarie ATL 的 `sceneId,lineNo,type,param` 存在同槽多记录，
SQL 顺序为 `ORDER BY type,param`。先确认显示为覆盖而非逐条提交，
再按生效顺序选择最终值；排序本身不能证明最大 param 必为正文版本。
验证修改影响的记录及覆盖统计，未变作品的通过记录可复用。

### 宏、姓名与表结构

カエル畑的主角名同时使用 `0xFC:%s+type6槽` 与 `0xF0:@GameLast`，
本作 `@GameLast` 对应姓槽 `1802`。检查标题、选项和特效中的宏，
按来源确定值，不在纯 ASCII 过滤阶段删除。

ときメモ的 `Params[].DlgText` 可为列表，`DialogueText` 可为字符串。
先核对 schema，字符串视为单值，不逐字符迭代；未知类型登记后处理。
同引擎不保证业务字段名和类型相同。

ニルアド的 `k=2,KIND=0x4C0` 是全脚本重复的场景表候选；
结合正文引用和显示入口确认菜单用途后排除。逐文件相同和标题数量仅是辅助证据，
不能证明它不会作为叙事标题显示。

### 制作注记与资源残片

レッドベル的 `c04p0` 可由角色资源指令残留到正文末尾。
`[a-z]\d{2}[a-z]\d+` 只用于定位候选，核对资源表、源位置及调用后处理。
`CommentScriptLine` 也可存正文，不能整类当注释删除。
独立注记、粘连前缀与行尾旧稿批注须分别确认边界；短串或制作用语不直接决定排除。
详见 [注记分类](names-and-macros.md#姓名注记)。

清洗按已解析类型进行：先保留控制、宏和来源信息，再移除已证包装。
`#Pos/#Scale/#Color` 前后的空白分别判断排版和正文用途，不能统一 strip 后丢失段间空白。

### 选择与非正文块

选项前缀可能为单码或 `全角空格＋样式码`，按组元数据和显示用途确认。
Aromarie `choice.eval` 为 Lua 显示条件；同组相同文案仅在已证互斥且实际只显示一次时折叠。
公共资源前导块可跨文件重复，按记录类型排除；不使用 ASCII、PUA 或词表作为通用正文过滤。

裸制作批注按完整源记录及显示用途识别。
`CardGameMain/CardGameOld` 无静态引用仅提示旧版或调试候选，
须覆盖入口、动态分派和间接引用后才排除；`CardGame` 的真实调用保留。

SandalDash 的块标题可能是 `0x26` 或 `0x69`；
`tail=0`、无邻近等待或图像切换均不足以证明不上屏。
结合 opcode 读取和显示调用区分作者标注、菜单标题及叙事标题卡。

### シナリオくん追加与 OverFlowADV 配对

シナリオくん的 `追加` 写入同一行缓冲、不推进新块 y；非追加分支推进块顶并清状态。
这是同块追加的代码证据，但追加是否发生于同一点击仍须检查等待。
exe 的单行 47 全角上限只用于检查容量，不据此切页。

Apocripha0 / OverFlowADV 3.00 的本作配对为：

```text
G = count(0x00,0x09)
正文/语音/空 = 3g / 3g+1 / 3g+2
名字槽 = 3G+g
消息结构含四条 (0x80,0x11)
```

アレクディスク末尾可不发射名字槽，不能因此判整文件非脚本；确认旁白后以空名状态输出正文。
其选择由 `(0x20,0x11)` 分派块及连续空或数字语音槽页定位；
Happiness Cage 另用名字窗标记。按本作结构选择方法，不能以“前一种未找到”直接认定另一种正确。

## 多文本命令

适用于 Vridge 字节码、`script.memfs` 文本及 TIS 脚本。通用规则见 [输出规范](output.md#输出规范)。

### 文本命令覆盖

恋は校則に縛られない！的消息序列为 `FFFF → FFFE → FF8F → FFFB`；
`FF8F` 含同页特效正文，遗漏会截断句子。`FFAF`、`FFC2` 中的标点串则可能来自字库网格。

统计各 opcode 携带的字符串及所在消息状态，检查已知文本命令之外的可显示记录。
是否并入当前段由命令语义及点击、清屏状态决定；标点形态仅用于定位候选。
引号差异可提示漏收命令，不能直接判为原文笔误或决定拆合。

### 选项装饰

本作选项首码可能是 `<0x20` 图标槽；装饰也可能单独占一条消息。
仅在已确认的选项或装饰记录中移除图标，保留正文原有省略号、破折号及引用括号。
首字形去除须核对剩余正文；独立符号记录须确认未作为特效显示。
括号配对可辅助区分引用和按钮边框，不能单独决定删除。

### 自用字形槽

常用汉字也可能放在自用槽 `3456..3512`，CP932 基础区位置不能排除候选。
按字形、码表及源码定值，基础码的正文使用频次只作交叉核对：没有唯一编码证据时，
同字使用两个槽仍有可能。写入映射时核对实际字符与 `ord()`，避免手写 Unicode 转义偏移。
映射证据见 [自建字体](decode.md#自定义字体)。

### TIS 行内语法

不得用 `\[[^\]]*\]` 删除全部方括号内容。按语法分类：

| 形态 | 处理 |
|---|---|
| `[dic no=N text=WORD'ruby]` | 保留 `WORD` |
| `[基底'读音]`、`[基底'・]` | 保留引号前的显示基底 |
| `[主人公]`、`[Name]` | 按默认值或已授权值替换宏 |
| `[wait ...]`、`[nextpage]`、语音命令 | 更新控制状态，移除命令文本 |

按标签类型核对输入与输出，保留未识别类型的来源；不得静默删除未知标签。

## 半角、注音与双版

### 半角字符

源文可含半角假名、独立浊点及半角标点，先核对原载荷和映射，不按字符类型自动改字。
未命中原串不直接证明缺陷，还需核对宏、字形及编码别名。

### 注音

`{基底:注音}` 或全角冒号等语法按本作 parser 处理，保留基底。
不以宽泛括号正则吞掉表达式和正文；残留括号须回源，不要求字符数量为零。

### 字面符号

剥样式后残留的闭括号、反斜杠或标签形态可为原文，按实际显示登记精确例外。

### 局部双版

按页的点击段决定版式，不按合并比例判断。`--dual` 是已证声明，候选零命中不直接否定双版。
验收依据见 [双版映射](layout.md#成行状态)。

### 引擎标记

Tyrano 的 l/r/p、gss 的等待/页末以及 NSLua 全角标记均须核对实际实现和配置。
Utage 的 PageCtrl 空值不独立证明没有多段页。NScripter 见 [专册](engines/nscripter.md)。

### 核对工具

使用现有来源映射和技能品检，参数见 [脚本索引](../scripts/index.md)。
宏残留和拼接统计只定位问题，不能自动决定页界。
