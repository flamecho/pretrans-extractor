## 1. 判型
- `RomFS/Data/StreamingAssets/<字>/<名>.assetbundle`（每个 bundle 1 个 TextAsset `*.bytes`）；
  另有 `lang/ja/initialize.assetbundle` 装 JSON 表（UI／触摸台词／游戏内网读文）。

## 2. `.bytes` 结构

```
0x00  28B 头 = 7×u32 LE：<0x10><poolOff><poolOff><poolOff><1><773><772>   # 后两值恒定＝格式魔数
0x1C..poolOff  代码区：每条 4B = <u8 A><u8 B><u16 BE 参数>（长度严格 mod 4）
poolOff..EOF   字符串池：条目以**原始 0x00** 分隔
```
- **`05 03 <u16>` ＝ 引用字符串池**（参数＝池内偏移）。
- **消息块 ＝ `0316 … 0317`**；块后必跟 `0402`：

| 骨架 | 语义 | 处置 |
|---|---|---|
| `0316 0503 0400 0503 0317` 且块后 `0402` 再跟 **`01 04`** | 选项块（2 选项） | 2 个 0503 全收 |
| `0316 0503 0400 0503 0400 0503 0317` ＋ `0402 0104` | 选项块（3 选项） | 3 个全收 |
| `0316 0503 0400 0503 0317`（其他） | 名札＋正文（第 1＝人名，第 2＝正文） | 只收第 2 个 |
| `0316 0503 0400 031c 0500 0400 0504 0317` | 语音 ID（`B0708000_H00X00`） | 丢 |

★★ **名札＋正文 与 2 选项块骨架完全相同**：唯一的钥匙是**块后 `0317 0402` 之后的 `01 04`**
（三选项块 100% 命中）。❌ **别用「第 1 个 operand 是不是人名」判**——选项以「要不要邀请」等句式出现时极易误判。

## 3. ★★ 字符串池：XOR 键 = f(池内起始偏移) ＋ `0x00` 还原

```python
K(off) = 0x3C ^ ((off & 0xC0) | (off & 0x03))     # off = 条目在池内的起始偏移
明文 = raw XOR K ; 若明文字节 == 0x00 ⇒ 真实字节 = K
```
- 同一条目内 K **恒定**（100+ 字节台词整条解通）；跨条目变化 ⇒ **不是全局常量键，也不是逐字节键**。
- 公式来自「对每条试 256 键，取使结果成为合法日文的那一（唯一的）键」再拟合；
  本作 **217/218 命中**（唯一不符项是二进制条目被误判为 CJK）。
- **`0x00` 还原必做**：`（`=EF BC 88、`？`=EF BC 9F、好=E5 A5 BD、何=E4 BD 9C 等
  **中间/末位 0xBC/0xBD** 会被编码器写成 `0x00`；不还原就出现 `ｈ`(EF BD 88)／`！`→`ａ` 之类假字。
- 文本 = **UTF-8**；`\n`（反斜杠+n）＝框内换行、`@@`＝排版断行、`▼`＝继续提示符。

## 4. ★ 文本筛选：靠「合法 UTF-8 ＋ 允许字符集」而非「像不像日文」
- 池里**混装**台词／人名／资源 ID（`BG_*`/`EV_*`/`B0708000_H*`）／运行期参数（二进制）。
- 判据：**含 ≥1 个日文字符（假名/汉字/CJK 标点/全角）** ⇒ 资源 ID 一律出局；
  再对**整串字符集**设白名单（假名・汉字・CJK 标点・全角・ASCII・`…―“”▼♪`）⇒ 二进制条目全部落选。
- 反面：**别只按长度判人名**（`だろ？` 这类短台词会被人名阈值误杀）。

## 5. 运行时变量 `｛…｝`（全角括号 = 引擎语法）
- `｛佐伯＊＊｝` 等 = 角色名（`＊＊`＝称呼形式位）⇒ 交付取**姓氏**（＝名札形）。
- `｛主人公｝/｛主人公姓名｝/｛主人公苗字｝/｛主人公名前｝` = 主角名 ⇒ 取游戏默认名
  （本作 `主人公`，来源＝ `string_table.ExtraProfilePlayerName`）。
- `｛日付｝` 等运行期变量 ⇒ 输出 `〔日付〕`。
- `｛強調<变量>｝` 的 `強調` 是**样式标记**，剥除。
- ★ `string_table` 里的 `AddressBookAddress_N` = **全角色全名**、`lbl_to_char_id` = 名札←→charId
  ⇒ **零成本 cast 核对源**（本作 19+ 名与 vndb `v858` 零差）。
