# B · 标签记录与走查器的三个静默漏洞（结构层／跨引擎通用）

> 三条都**不报错**、只默默少收：标签族整族漏、段尾串丢、系统成员被当无文本。
> 来自 VitaminZ（PSP「Revolution」，HuneX IKA SEQ v3.4）2026-10-18；凡「`23 <L> <label> <tag>` 标签 ＋ `5C L` 串」的脚本都适用。

## 1. ★**标签记录 `23 <L> <ASCII label> <tag>` 的 `tag` 字节是任意值，别用 `[\x00-\x05]` 限定**
（2026-10-18，**VitaminZ（PSP Revolution）** HuneX IKA SEQ v3.4）系统包里 32 个标签族，
`tag` 分布在 `0x00–0x15` ⇒ 白名单式正则 `[\x00-\x05]` 把 `GOROU_0_____Q`(6)／`RINTAROU_0__Q`(0x10)／
`RIJI_0_Q_nnn`(0x12) **整族漏收**（≈400 问），且漏掉的串被"上一段"吞掉，
现象是「最后一条标签带 7,000 串」的畸形分段——**这本身就是中招信号**。
正解：判据只用 **`L == len(label) + 1`** 一条，`tag` 一律不限定。

## 2. ★**`while i < N - 6` 会吞掉「起点恰在 `N-6`」的串（off-by-one，静默丢尾项）**
（同上）每条授業クイズ＝設問＋**4 选项**，第 4 个选项的记录正好落在段尾 ⇒ `i == N-6` 时循环已退出，
实测 **89 条只收到 3 个选项**，无报错。自查探针＝**每条记录的串数直方图**：出现 `(4, 89)` 与 `(5, 1,539)` 并列即中招。
正解：`while i < N - 4`（`iter_records` 与「段内取串」两处都要改）。

## 3. ★**「剧本成员」与「系统成员」分装，判型看标签族而非"有没有文本命令"**
（同上）`GAMEDT.AFS`：AFS[2]（HFU2×337）＝剧本；AFS[1]（HFU2×104）＝系统包，
内含 **用語辞典(blk2)＋授業クイズ(blk3, 10 角色×2 套＝2,046 問)＋おみくじ(blk87)＋名簿(blk63, UI)**；
且**辞典在 AFS[2] blk1 还有一份同尺寸副本**。只扫"有 `26 ?? 24 ?? 5C` 的成员"会把系统包当无文本丢掉。
正解：对**所有**成员跑 `23 <L> <LABEL> <tag>` 标签族统计（`WORD_*` / `*_Q_*` / `FORTUNEWORD__`），
再对命中块做「标签 ＋ 后续 `5C` 串」解析；名簿类（`名前`/`学年` 字段）＝系统 UI ⇒ 剔。
