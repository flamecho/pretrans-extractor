# C2 · 交付 / 流程层 续

**① ★原文缺陷（漏收尾 `」` 等）必须 `LINE_FIX` 定值补，不要「为了不改写」硬留着**（2026-10-18，あさき、ゆめみし PSP 回修）
  某框正文以 `…けど。` 收尾即 NUL（源字节确证、**全库唯一、无平行副本**）⇒ 判为原作用漏收尾 `」`。
  第一次交付时按「不改写」留着 ⇒ `check_text.py` 挂 **2 项 [E]**（引号配对差 1 ＋ 行首 `「` 未闭合），
  用户拿到的就是一份「看起来有毛病」的稿子。
  **正确口径**（既有先例：アーメン・ノワール 3 处／Little Aid 3 处／月ノ光 FD 2 处）：
  * 建 `LINE_FIX = {原文: 修正后}` **定值表**（不写正则、不做批量猜），只修**已逐条证实**的原文缺陷；
  * 报告里**单列「原文缺陷 N 处」**并给行号／源偏移／判据（唯一性 + 无平行副本）；
  * 修正后重跑 `check_text.py` 至 **exit 0**。
  ⇒ 口径统一：**「不改写」约束的是「不许改写语义」，不是「不许补明显缺失的配对符号」**；
    凡补必留痕（`LINE_FIX` + 报告），不可静默修改。

**② ★交付前「名札复扫」是硬动作，`check_text.py` 抓不到泛用身份札**（同上）
  `check_text.py` 的「说话人残留」只认 `【名】` 独立行／行首 `【名】`+正文／`名前：` 三种形态；
  `<名>\r\n<正文>` 型引擎里，**未登记的平面名札**（`青年「…」`）它会**全部放行**。
  ⇒ 每作交付前必跑：`^([^\s「」（）]{1,14})「` 词频复扫（见 SKILL §1 人工必做③）。
  判读：残留项里**叙述句内引用**（`彼がわたしを「姫さん」と呼ぶ…`）是正常的；
  其余（纯名字／身份＋`「`）一律是名札表漏项 ⇒ 修 `mine_plates()` 或补表后重跑。细则见 `pitfalls/B9-late-6.md` ⓩ5。

★ **「同一句并存两种标点变体」＝源数据侧的历史遗留映射，先证再归一**（2026-10-15，ときメモGS2 NS）：
  日文台词里出现 `∋`(U+220B)／`∈`(U+2208)（各 619/547 处），上下文全是疑问/感叹句（`えっ∋`＝「えっ？」、
  `じゃあな∈`＝「じゃあな！」）。**判据＝「归一化后同文」**：把 `∋→？`、`∈→！` 后，
  **44 组文本出现两种写法**（`（えっ∋）`／`（えっ？）`、`そうなんですか∋`／`そうなんですか？`）⇒ 实证等价。
  ⇒ 交付归一为 `？`/`！`（脚本里的**同文变体**＝零成本判据，比引外部资料可靠）。
  ⚠ 别把这类 `∋/∈` 当「未解码字符」丢弃；也别忘了 **`？`/`！` 本身在同一文本里正常存在**（＝不是整体替换）。

★ **`check_text.py`「半角假名」判据已拆分**（2026-10-16 ソラ*ユメ）：原 `[\uFF61-\uFF9F]` 连**半角标点** `｡｢｣､･`(FF61–65)
  也算 ⇒ **原文自带**的 `･`/`､` 被误判 [E]；现 **FF66–9F 才 [E]**、FF61–65 降 [W] 待人工核。★「行首 `名前：`」
  亦会误报**书信/告示**（`注意：`/`追伸：`）⇒ 人工判，别盲改。

**③ ★★数据表（邮件/评论式表）成行粒度＝「字段行分离 ＋ 同件正文软换行合并」，交付前用「最长行宽」自检**（2026-10-18，アルコバレーノ! ポータブル PSP，被用户连打回两次）
  该表每条串＝画面上的一行显示，形态 `＞<件名>` / `宛先：X` / `―――…` / 本文行 ×n。三种粒度：
  - ❌ **一屏＝一行**（整封 join）⇒ 出现 200~3000 宽巨行，用户：「这有点太长了吧」。
  - ❌ **一显示行＝一行**（逐串成行）⇒ 正文被拆成一堆碎句，用户：「还是有啊」。
  - ✅ **件名・`宛先：`・`送信者：` 各自成行；同一件的正文行（软换行）合并为一行**（本作 `mail_join` 1,143 次）；
    装饰分隔线 `――――…`（309 行）无文本内容 ⇒ **不收**。
  ★**自检动作（30 秒，交付前必跑）**：`print(max(len(l) for l in lines))` ＋ 打印最长 3 行。
    若最长 >150 宽 ⇒ 多半「整封合并」；若大量 10~20 宽且以 `宛先：`/件名密集穿插 ⇒ 多半「逐串拆行」。
    ⚠ 判据不是字数而是**语义完整性**：一段正文读起来是连续的话 ⇒ 该合并；带 `＞`/`宛先：`/`送信者：`/`件名：` 前缀 ⇒ 独立行。
