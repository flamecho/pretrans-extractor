## ⓞ ★「标签字段」本身是数据表标识，不是正文

- **形态**：`23 <u8 L> <ASCII 标签 L−1> <u8 tag>` 之后**直接**跟一条 `5C` 串。
- **判据**：
  1. 标签长度 == `L−1`（L 是含标签的字段长）；
  2. 标签全 ASCII 且以 `_` 分段（`WORD_` / `SEL` / `PROLOGUE_`）；
  3. `<u8 tag>` 随类别变化（辞典 / 任务数据各一套）。
- **处理**：**标签并入该条目的键**（如 `WORD___001`），不当正文输出；同一块内按标签前缀分组，
  即可分出「用語辞典」「潜入ミッション数据」等不同数据表。
- **实例**（Lucian Bees）：`WORD___001..545` 每条 = `見出し語` + `解説` 两条串 → 即用語辞典。

## ⓟ ★「一命令多串」——一条命令可携带多条串，须按长度 / 序号切

- **形态**：`23 <u8 L> <标签>` 后跟 **n 条** `5C` 串，而不是一条。
- **判据**：同一 op 之后连续出现多个以 `5C` 起始的 SJIS 串，且各自以 NUL 或记录边界收尾。
- **处理**：按「长度数组 + 若干 NUL 串」切分；**只取第一条会静默丢掉后半**（如 `解説` 整段）。
- **副产物**：切出来的第 2..n 条往往没有独立题名 ⇒ 归属到该 `标签` 之下，成「一条目 + 多串」。

## ⓠ ★「多块＝多文件」：同一次运行内多个块等价于多个文件，须取并集

- **判据**：容器内块数 > 1，且各块都带独立头（`u32 n` + 偏移表）。
- **处理**：**逐块解析后取并集**；只解第一块会整段漏掉。
- **闭合校验**：全库「合法 `5C` 候选」总数应 ≈ 正文 + 选项 + 字幕 + 任务数据表 + 辞典（+ 伪记录）。
  差额过大 ⇒ 还有块没解开。
  - 实证（Lucian Bees）：`148,984 = 144,838（正文/选项/字幕） + 2,500（任务数据表） + 1,092（辞典） + 554（伪记录）`。
  - 伪记录来源：`0x5C` 是合法 SJIS 尾字节（`―` = `0x815C`），会落在真串内部或指令操作数里；
    抽查「未被覆盖且日文占比 >60%」的串，起点全部落在真串的 +1/+2 字节处。

### ⓡ 判型工具也会骗人：`identify.py` 可能报错引擎
- 实证：O＊G＊A 鬼ごっこロワイアル 被 `identify.py` 判成 KiriKiri，实际头是 `MComprHD`（CHD 镜像壳）。
- 做法：**工具的结论只当假设**，用「魔数 + 解出物」复核一次；镜像/压缩壳（CHD/zstd）会掩盖真实容器的头。
- 反例意义：见 `../02-false-signals.md` 第 23 条（工具与启发式都不是判据）。

### ⓢ 「容器里 1.9 万条」≠「文本在这里」
- 实证：`DATA.DAT`（PSPFS_V1，19,171 条）**解压后扫假名 = 0 命中**；正文全在 `STS.DAT` 的 271 个 `tob` 脚本的字符串表里。
- 判据：**解压全部条目 → 扫假名/汉字**，0 命中就换载体，不要继续在条目结构里找。
- 配套：`../05-completeness.md` 的「字节闭合」用来确认是否还有别的载体。

### ⓣ 「整库扫不到日文」也可能是**单字节 XOR**，不是没文本
- 实证：全库 cp932 假名 0 命中；**全字节 XOR `0xDA`** 后，ASCII 资源名立刻可读 ⇒ 同键解出的正文是**半角片假名**。
- 判据链：假名 0 命中 → 试「单字节 XOR」→ 看**资源名（ASCII）是否变可读**（这一步几乎零成本，且不属穷举）。
- 注意：解出的是**半角片假名**（`0xA1–0xDF`），须合并浊点/半浊点后再输出。

### ⓤ 串表首条常是**残留 4 字节**，必须丢
- 实证：串表第 1 条为 `ﾈe` / `ｰ)` 之类 4 字节垃圾（前一条记录的尾巴）。
- 判据：首条长度异常短、且不是合法假名/汉字起始 ⇒ 丢；**不要因为它把整个表的起始偏移 +4**。

### ⓥ 成行：「语音数 + 引号深度」双判；源侧漏引号用**净差校正**
- 实证：一次点击边界用「语音文件数 + 引号嵌套深度」双判比单用 op 码稳；
  该书源侧共漏 `」`（全书净差 3 个）⇒ 按「4 段 / 300 字上限」合并后 `rebalance()` 补 `」`/`「`（68 行 = 0.34%）。
- 原则：**补引号只能按「净差」做闭环**（补完总数守恒），不可逐行猜。
