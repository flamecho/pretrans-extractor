# 验收清单（交付前逐项打勾）

## A. 文件完整性

- [ ] 文本字节总数与旧版 / 预期对比，确认**没有丢文本**（不是"看起来没少"，是计数）。
- [ ] 空消息占比 **< 5%**（> 10% 几乎必是「未做字符宽度感知」的 bug，见 `SKILL.md` §1）。
- [ ] 首 3 字节 = `EF BB BF`（BOM 存在）。
- [ ] CR 数量 = 0（纯 LF）。
- [ ] U+FFFD 数量 = 0。
- [ ] 无残留 `%s` / `%N` / `Name[` / `〓` 等占位符（或已在报告声明）。

## B. 字符层

- [ ] 扫描输出里所有**非日文字符**（拉丁 / 西里尔 / 希腊 / 全角符号），逐个上下文复核。
- [ ] 所有「字体替换槽 / 罕见字」逐条渲染字形核实或实景反推，**不靠 cp932 推断**。
- [ ] 1 字节汉字宏 / 后字选词宏已用「同句拼写变体」法确证。

## C. 外部核对（**不得省略**）

- [ ] 说话人姓名表（去重）逐条比对 **vndb**（`vndb.org/v<id>/chars`）。
- [ ] 专有名词（歌名 / 乐队 / 品牌 / 术语）比对官方站 / wiki。
- [ ] **外部资料给出的字，全部能在自己的输出里找到**（找不到 = 还有未发现的槽位 → 回头复查）。
- [ ] 查不到的条目**单列**（码 / 次数 / 原句 / 可能读法），**未硬猜**。

## D. 结构

- [ ] 顺序 = 游戏内点击序（入口 → 调用图 DFS 前序去重 → 附录）。
- [ ] 排除项已清除：测试档、他作遗留串、重复的事件 CG 回放、开发菜单、内部日志（`error :` 等）。
- [ ] 词典 / 豆知识已按「一行一条、无读音、并入末尾」处理。
- [ ] 图片承载的文本未误当正文收入，已在报告注明。

## E. 抽样人工读

- [ ] `grep` 几个已知专有名词，人工读 **6 处不同位置**的抽样，确认上下文通顺且用字正确。
- [ ] 开头 / 结尾 / 中间各抽一段，确认无错行、无粘连、无截断。

## F. 报告

- [ ] 已产出 `_解析报告.md`，含：容器链路、脚本格式、字符层结论、未解析码位单列、排除项、行数统计。
