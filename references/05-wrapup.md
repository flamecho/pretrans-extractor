# 收尾（S8）—— 一条命令 + 拆分纪律

> 从 `SKILL.md` §5 下沉（2026-10-18），**内容未改**。每作交付后照此执行，不等用户提醒。

```bash
python scripts/wrapup.py --report "提取结果/解析报告/XX_解析报告.md" \
                         --text "提取结果/XX_全文本.txt" --name <主角名>
```

它串起四步，**只输出一张待办清单**（机器能判的都判完，人只做判断）：

| 步 | 工具 | 机器判据 |
|---|---|---|
| ① 成品品检 | `check_text.py` | 退出码 0（`[E]` 必修，`[W]` 人工确认） |
| ①b 行数一致性 | （`wrapup` 内置） | 报告声明的 `行数` vs 成品实际行数；差 >1% ⇒ `[W]`（用错文件/成品过期） |
| ② 体积体检 | `memcheck.py` | 超 10 KB ⇒ 直接给 `split_md` 命令；≥96% ⇒ 提前预警 |
| ③ 沉淀草案 | `distill.py` | 候选按 **已覆盖 / 待沉淀 / 单作特例** 三分，并给建议落位册 |
| ④ 落位片段 | `archive_work.py` | 生成 WORKS 块 / TOOLS 节 / 日报小节 / 引擎提示；`--apply` 幂等追加。**报告带 front-matter ⇒ 字段零歧义**；否则标「正则抽取，请核对」 |

人工只做三件：**看草案勾选 → `--apply` 落位 → 报告写「重跑步骤」**。
落位分工：**通用判据**进 `references/`（按阶段册）或 `pitfalls/`；**单作特例**只进 `WORKS` 作品块 / `engines/<slug>.md`。
`references/00-index.md` 不动（它只放铁律与导航，见 §5.2）。

## 拆分/重组的三条硬规矩（2026-10-18 事故后立，**不可绕**）

1. **禁按字节切**：`>10 KB` 只在**语义边界**（标题 / `**B22.` 条目 / 圈码）下刀 ——
   先 `python scripts/split_md.py <md> --dry-run` 看切点，再 `--names a.md,b.md` **语义命名**落盘。
2. **禁「先写新文件，再按 glob 删旧」**：新名会被 glob 算进"旧册" ⇒ 新旧一起删光（真实事故）。
   `split_md.py` 已内置：临时目录写入 → 校验（正文行守恒 / 边界守恒）→ **打印待删清单** →
   断言与输出名**不相交** → 才删旧、搬入。手工重组也照此顺序。
3. **拆完立刻改引用**：`grep -rn "<旧名>" .`（`references/` 与 `SKILL.md` 同步改），再跑 `00-index.md` 链接自检。

## 体积与落位约定

- `SKILL.md` 上限 **12 KB**（唯一必读）；其余 `.md` **10 KB**；`references/00-index.md` **8 KB**（自动注入）。
- 超限 ⇒ **先拆不压缩**（压缩只许删啰嗦句，**判据/例外/原文引用不可为达标而删**）。
- 新结论按 §4 落位，**别往 `SKILL.md` 堆**。

> 各引擎格式细则见`references/`：`engines.md`（**路由表**）→ 只读命中的 `engines/<slug>.md`。

> **后期条目（ⓒ〜ⓩ 等）已按层归入 `references/pitfalls/B4`〜`B9`、`E1`、`E2`**；不再在本文件追加变更记录。

## 未命中后的回填（判型表靠它长出来）

`§E` 四步走通、拿到可读文本后，**当场**补三处，缺一不可：

1. **本册**：在 `§B` 表加一行「魔数/头特征 → 引擎 → 该读哪册」；`§D` 有厂商线索就一并加。
2. **引擎册**：新建 `engines/<slug>.md`，首段＝`识别特征 → 容器链路 → 脚本记录 → 成行 → 易错`。
3. **路由**：`engines.md` 加一行（一句话索引 ＋ 详见），并在 `WORKS` 同族块里补本作条目。

> 判据：**回填后，同一引擎的第二作应该能在 10 分钟内定位到该读的册**。
> 做不到 ⇒ 说明这行写得不够「可判」——补上**特征串/偏移/结构**，别只写引擎名。

## 维护命令（改动手册后 / 收工前）

```bash
python scripts/lint_docs.py     # 断链 / 引擎册未进路由表 / 孤儿册 / 空册 / 超限
python scripts/pending.py       # 有成品无报告 / 有报告未进索引 / 未落位且无报告头
python scripts/memcheck.py --fix  # 超限时直接看切点（不落盘，确认后加 --names）
```

- `lint_docs.py` 的 **B 项（引擎册未进路由表）** 是「写了却没人知道去哪找」——新增引擎册后必跑一次。
- `pending.py` 的判据是「报告名是否出现在任何 `WORKS-*.md` 里」；备忘录类（`*_メモ.md`）默认跳过。
