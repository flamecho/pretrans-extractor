# 验收异常与格式案例

仅在出现对应异常或格式时读取；通用验收见[交付自检](verification.md#交付自检)。

## 问题定位

### 文本异常

| 信号 | 回源检查 |
|---|---|
| 姓名出现次数异常 | 区分姓名宏、称号、一人称和昵称；查槽初始化及输入，不以次数证明宏完整。 |
| 选项缺失 | 查独立表、参数包及显示调用；选项提示也可能由选择命令提交。 |
| 注音后缺正文 | 确认基底所在位置；`<読み>基底語\|` 的基底位于括号后。 |
| 名札重复或正文前缀缺失 | 查可见性、包装及来源；处理见 [姓名](names-and-macros.md#名札与关联)。 |
| 正文零命中 | 查其他显示命令、宏和调用，目录或单一 TextIns 计数不足以排除。 |
| 行数突变 | 回查引用、类型、编码和边界；长短行统计仅定位候选。 |
| 术语或人物表疑似遗留 | 查引用、版本及实际用途，角色关键词零命中不构成排除依据。 |
| 辞典释义重复 | 按 schema 区分词条、释义、读音及分类，不重复输出注音字段。 |
| 品检出现新异常 | 查源位置与后处理差异；allow 只记录已核实的精确例外。 |

未解项按 [输出规范](output.md#输出规范) 处置，格式统计不替代来源证据。

### 复现异常

归档密码优先查已有密码及随包说明；头部加密导致无法列目录时，不直接判归档损坏。
载体分类核对签名、长度、引用及未知变体。报告要求见[报告](verification.md#外查与报告)。
路径、编码和依赖见 [工作区](workspace.md#工作区与记录)，临时产物归属及清理见 [收尾](workspace.md#收尾与维护)。

## 交付格式案例

### 收取范围与非正文

| 来源 | 处理 |
|---|---|
| 裏語 薄桜鬼 `0x2E`、空名 `0x2D` | 同时可含年表、旁白和系统消息，按调用用途区分 |
| `termItem.dat` | 本作辞典，不能只提取 event.enc |
| `npc_album.dat/book.dat/TextDataEx.bin` | 他作遗留候选，结合内容、引用和入口确认后排除 |
| `☆/＊/＃/;//` 起首记录 | 制作注记候选，标记本身不够排除 |
| 回想、extra、菜单载体 | 保留独有叙事；同文比例只定位副本 |
| 白と黒のアリス `scene-set 16 nn` | 已证测试章，核对开发入口后排除 ev1601–ev1616 |

非媒体载体按索引、魔数和引用分组覆盖，不逐文件解包或扫固定“连续日文长度”。
他作词频和重复率只辅助定位，不独立决定归属或排除。
系统文件也可含正文，正文文件也可含开发块；记录具体排除范围及来源。

### ASCII、富文本与姓名

通用字符及残留验收见[自检](verification.md#交付自检)，姓名与样式见[姓名规则](names-and-macros.md#名札与关联)。
`件名/宛先/送信者/追伸/Q/A` 及记号线后的冒号字段不是姓名残留。

### 字形宏与标点探针

マスケティア的 `1D 00` 可位于显示参数区末尾，漏读时正文以孤立标点起首。
按打印命令及宏链恢复完整文本，不据标点直接并前行。

相关自用码变体的 `FFE6/FFE7` 为姓/名，
一人称可为 `FF08/FF0F`，名札区可有 `FFF0...FFFF` 或后接 `FF4D` 的形态。
这些参数限对应格式；`FF4D/FF4C` 的首码是否样式须按语法确认，不能无条件删一个字符。

ときメモ的 `∋/∈` 可映射问号、感叹号。
平行同文只辅助验证，源码或字体映射确认后按槽还原，不能全局改 Unicode 字面值。

标点异常的定位与修复见[行完整性](layout.md#映射与修复)。

### 多版本、辞典与邮件

裏語 薄桜鬼的独立指令块、零长 marker `1E`、台词 ID 和参数可定位文本变体。
不同称呼或表记保留；只有确认宏求值后显示相同且属于同一副本关系才折叠。

`termItem.dat` 本作记录 322 字节，含词头 32、读音 32 和解说；
解说的 `01+索引` 两字节前缀按结构处理，输出 `【词头】解说`，合并排版换行。
整除关系用于验证已证布局，不独立发现记录长。
重新生成辞典区使用已登记来源边界，不用“删除全部【】行”清除旧版本。

邮件表按已证显示字段处理：件名、收件人、发件人分别输出，同件正文合并排版换行。
长度分布仅检查异常；不能按最长行阈值或语义通顺自动拆合。
分隔线可能是装饰或显示特效，按用途确认。

### 引擎绘制的引号

Real Rode 的 `0x3C` 台词多仅存闭引号，`0x44` 为地の文。
统计只能提示显示模式，确认绘制实现后补引擎实际显示的开引号。
不把“末尾为闭引号”的全部记录当台词；缺失或异常原文仍登记保留。

相对 report/allow 参数可能基于文本目录解析，显式传入目标并按[工作区](workspace.md#工作区与记录)核对落位。
