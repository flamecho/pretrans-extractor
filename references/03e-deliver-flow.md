## C. 交付层（每次必查）

**C1. 主角名 / 称呼宏被当空控制码丢掉**
主角可改名 ⇒ 脚本里**必然存在**插入宏。已见：遥か3（`5d 17 00` 静默前缀 + `5b XX 00` 称呼表；
`0x16`=将臣くん…）、はかれなはーと（`f.name`/`f.family`）、ひめひび（`0x0c02`/`0x1802`）、
花宵（`FFE6`/`FFE7`）、カレイドイヴ。
→ 交付前**主角名出现性自检**（`check_text.py --name X`）。默认名从 eboot 名字输入初始值表 / Config 取。
→ 出现次数还要与被称呼的台词量**量级相符**。**若脚本内无任何改名机制 ⇒ 主角为固定名**，直接用其出现次数核对。

**C2. 选项文本整块漏掉**
被当 `[...]` 标签丢弃。→ 专门提取 `[seladd/_link/_click/_extmenu/_homepage … text="…"]`，一行一条。
⚠️ **注音正则必须限定基底语**（`[漢字'よみ]` 的基底不含 `= " '` 与空白），
否则 `[seladd text="X" target="*sel_1" cond='f.shiba==false']` 会被误当注音，
**把命令残骸当正文**输出（蝶の毒实证）。

**C3. 说话人前缀残留的 4 种形态**
1. 独立名字札行 `【秀雄】`（含原作笔误 `!【警官２】`）→ 丢弃该行
2. 行首 `【名】` + 正文 → 去掉前缀
3. 行首 `名前：` / `名前「` → 去掉前缀
4. 大字号演出写进正文流的裸名行（见 B5）

**C4. 系统 / UI 文本混进正文**
`sysscn/`・`main/`・config/help/save 类 → 不收、也不产出「系统・UI テキスト」附属文件。

**C5. 行数 / 长度异常时先查合并逻辑**
不要急着怀疑源。（コルダ 最长行 152 字 / ときたま 589 字都是合并 bug。）

**C6. 未解码位占位符不得用 `〓`(U+3013)**
§1 自检把 `〓` 判 **E**（历史遗留占位符）。要「留占位符（不猜测）」同时过品检 ⇒ 用全角括号式
**`〔未解析〕`**（遥か5 实证，运行时变量 12 处）。仍须在报告里**单列未解析码位**。

**C7. 用「尾部固定签名」批量给载体分类，别逐条启发式**
同一作里 **载体用途不同、尾部签名不同**：遥か5 实证
`CLOSE + C7 + 1e 5e9008d3` = 用語辞典解説文；`CLOSE + M91 + 1e 5e9008d3` = 系统/UI（整体排除）。
→ 先按签名把 leaf/文件**分成 剧本 / 辞典 / 系统UI** 三堆，再各自处理；
比「关键字黑名单逐条过滤」稳得多（系统/UI 会以零散长句混进正文，关键字扫不干净）。

**C8. 「用語辞典 / 术语表」载体可能是同发行商他作的遗留串 —— 先读内容再决定收不收**
Otomate 系常见：`SYSTEM.cpk/DATABASE/dbDictionary.gbin`、`strGame.gstr` 等**按模板复用**，里面装的却是**他作**数据。
- Norn9 Act Tune 实证：`dbDictionary.gbin`（39 KB）整表是 **薄桜鬼** 术语（`会沢正志斎`/`新選組`/`幕末`/`藩士`…），
  **无一条本作词条** ⇒ **整体排除，本作无用語辞典可并入**。
- 判据：抽 3–5 条看是否与**本作角色/世界观**相关（本作关键词 `ノルン`/`能力者`/`空汰`/三名女主 → 命中 0 即遗留）。
- 与 A4（eboot 串表遗留）、铁律 12 同类；**千万别把遗留术语表当本作辞典并入成品**。

## D. 流程 / 环境

**D1. 清理产物只在用户明示「清理产物」时做**；任务收尾**不要**主动清理。
**并且：用户说「清理产物」时，顺手检查 skill 是否需要修订/补充**（新踩的坑要沉淀）。

**D2. 成品「不见了」= 用户主动删/移**
→ **不复原、不报警、不当异常**。（多次误判为丢失并重建，属多余动作。）

**D3. 本工作区有并行 agent**
→ 覆盖 `scripts/` 或重跑前先看产物 mtime 与内容。

**D4. 源母本迟早会被清**
→ 报告里必须写**重跑步骤**（逐条命令 + 依赖）。

**D5. 环境**
pip 走 `-i https://pypi.org/simple`；GitHub raw 被墙走 `api.github.com`；
7-Zip `C:/Program Files/7-Zip/7z.exe`；managed python
`python`。

**D6. 派生 / 合并版本（如 `@n` 合并版）保留原文不删改**，原版另存。

**D7. 外部核对不得省略**（见 `04-verify-and-report.md`）——
「解出来读得通」≠「字对」。

**D8. 压缩包头部加密**
`.rar/.zip` 可能**带头部加密**（7z 列不出文件名）→ 密码常在同目录小 txt 里；
`otoame.com` 统一密码 `otoame`。

Git-Bash から **7-Zip に日本語パスを渡すと必ず化ける**（`ϵͳ�Ҳ���ָ����·����` / System ERROR）。
→ **PowerShell 経由**で `& "C:\Program Files\7-Zip\7z.exe" x $src "-o$dst" -y` を実行する
（または Python `os.link()` で ASCII 名 hard link を作ってから解く）。
