# 名札与说话人剥离（实战）

> 本册专收**名札/注记剥离**的判据与案例；台账机制、改名槽、回填取证在 `S7-charset-ledger.md`。

## 实战判据与案例

### ★ 默认名判据：**源数据「双写」的第一版**（2026-10-26 ビルシャナ 教训）

同一句在源里存两份（硬编码版 + 宏版）时：

```
「義経様に近付くな！！」「${FirstName}様に近付くな！！」
 └─ 硬编码版＝默认名版            └─ 宏版＝玩家改名版
```

⇒ **默认名 = 硬编码那一版里的名字**。统计两类的双写行数即可定论（ビルシャナ：義経＋宏 **149 行** vs 遮那王＋宏 **8 行**）。

⚠ **不要用 vndb 的角色名直接回填**。vndb 记的是**本名/正式名**，游戏内默认显示名可能是另一个：
v32229 记「遮那王」，但游戏默认「義経」——「遮那王」是幼名，只在改口叙事里出现
（`久しいな遮那王。いや、今は${FirstName}と言ったか`）。**回填错会导致全篇称呼改写、且极难回滚。**

校验三件套：① 双写第一版；② 名札（`｛源　${FirstName}｝` ⇒ 默认「源 義経」）；③ 成品内被称呼频次（`義経様×698` 居首即正常）。

### ★ 名札可能夹在**行中间**（2026-10-26 用户指出 `『赤狼の狩場』店主「…」`）

只剥「行首纯人名 `名「…」`」「独立行 `【名】`」「`名前：`」还不够——**名札常出现在行中**：

```
『赤狼の狩場』店主「ニュクス！？　って……ああっ！！…」     ← 前缀是『店名』店主
アプローズ「……」（177 行）                              ← 前缀是女主名
リュウ・クロア（子供時代）「…」                            ← 前缀是名+状态注
（独白）ギャレット・ウェルキン（独白）                       ← 名札夹在两个括号段之间
```

**判据（对 `「` 之前的前缀 P）**：

| P 的形态 | 判定 |
|---|---|
| 以身份词结尾：店主／店員／兵士／衛兵／声／男／女／王／姫／様／さん／殿／君／くん／ちゃん／主人／客／商人／門番／騎士／侍女／執事／使用人 | **名札 ⇒ 剥** |
| 纯人名形态（含 `（状態注）` 如 `（子供時代）`） | **名札 ⇒ 剥** |
| 含句读（。、！？…） | 叙述 ⇒ 保留 |
| 末尾是助词（は／が／を／に／で／と／も／の／へ／や／ね／よ） | 叙述 ⇒ 保留（`彼は「…」`、`私は「…」`、`フィンは「…」`） |

⚠ `スリの子ども` 末尾是「も」会被助词规则误判 ⇒ **名词尾（子ども／こども／供）要特判**。

**验收命令**：
```bash
# 列出「行中「前的前缀」并按频次排序，人工认领前 30 种
python -c "import io,os,re,collections;T='提取结果';c=collections.Counter(m.group(1) for f in os.listdir(T) if f.endswith('.txt') for x in io.open(os.path.join(T,f),encoding='utf-8-sig').read().split(chr(10)) if x.strip() for m in [re.match(r'^([^「]{1,30})「',x)] if m);print(c.most_common(30))"
```

★**这一条与「四探针」是同一件事的两面**：`(?!^)「` 命中的行里，前缀性质必须逐个判——**探针命中 ≠ 已处理**。

### ★ 名札前面还可能挂着**台本注记**，而且必须用「形态」不用「名单」（2026-10-27）

剥完 `名「…」` 之后还会剩一类：**演出注记 + 名札 + 台词** 拼在一行。

```
ラウド、ロストした誰かを忘れた事に葛藤リュウ・クロア「ラウド……大丈夫？」
タイトルとキャッチの読み上げカンテ・ラウド「悪は悪で正す。…」
ソディックファミリーを選択ソディック・モネ「何でも調べてくれて構わないよ」
もう二度と、ボスを失いたくない、と言いかけるリュウ・クロア「ラウド！」
表情を無くす。収録時は小さく「あ？」でお願いします。モネの言葉に、Ｒの顔からは表情が消えた。…   ← 注记里自带引号
```

**判据（形态）**：

```
名札形态 = [ァ-ヶー]{2,}(・[ァ-ヶー]{2,})+（可选「（状態注）」如「（子供時代）」）
处理     = 从「名札形态紧接的那个「」起保留；其前（注记 + 名札）全丢
特例     = 注记自带引号（`…「あ？」でお願いします。`）⇒ 用注记的结束语截断，保留其后正文
两句夹名札 = `「A」名札「B」` ⇒ 按名札切开，各段单独成行；段内含 `/`（`「それは嫌/そんな手はない」`）的是「两版标记」段，丢弃取最终版
```

⚠ **上一轮 12,387 行剥离用的是硬编码角色名单**，所以漏了 `バジョウ・モクレン（子供時代）`——这正是 skill 反复强调的
「**禁止用黑名单猜**」。**形态判据才是一次扫干净的做法**（本次全批 33 行一次清完，复扫归 0）。

⚠ 报告里若写「遇到舞台注记即停」这类脚本层判据，要实测：本作**注记与名札在同一个 `CommentScriptLine`**，
脚本层停不下来 ⇒ 必须在**成行后**按形态再剥一次。

### ★★ 剥注记时**必须把混排的正文留住**（2026-10-27 误删实证）

台本注记常与**正文地の文**挤在同一行，一刀「丢前缀」会把正文一起删掉：

```
キーランのことを思えばこそ言わずにはいられなくて、真っ直ぐにキーランを見つめた私は反論の言葉を口にした。不要なのでカット・ローズ「大丈夫じゃないのはあなたのほうよ。…」
└──────────────── 正文（必须保留）────────────────┘└─ 注记 ─┘└名札┘└── 台词 ──┘
```

第一次处理时我把整段前缀丢了 ⇒ **正文整句消失**。事后用备份 `difflib` 逐行对比才发现。

**正确做法（三步，缺一不可）**
1. 先定位**名札形态**（`[ァ-ヶー]{2,}(・[ァ-ヶー]{2,})+` 可选 `（状態注）`）；
2. 名札**前面**那段里，若含**完整句**（有 `。` 且是叙述语气 `〜した／〜だった／〜ていた`），**拆出来单独成行**；
   剩余部分才是注记（`不要なのでカット`／`立ち絵表示ナシ（着ぐるみ）`／`タイトルとキャッチの読み上げ`／`（対マルベリーのイメージ）` 之类）；
3. 处理完**必须用备份 diff 逐行复核**：`difflib.SequenceMatcher` 打印每条 `删除→保留`，人工确认被删的都是注记。

**口诀**：**注记去掉、台词与地の文一律保留**（这条本来就写在多数报告的切行判据里，执行时别忘）。

**复核命令（每次剥注记后必跑）**
```python
sm = difflib.SequenceMatcher(None, 备份行, 现文件行, autojunk=False)
for tag,i1,i2,j1,j2 in sm.get_opcodes():
    if tag != 'equal':
        print('删|', *A[i1:i2], sep='\n')
        print('留|', *B[j1:j2], sep='\n')
```
⚠ **不要**因为「注记里也有句号」（`表情を無くす。収録時は小さく`）就放弃拆分——看的是**整段是否有叙述主语与过去式**。

### ★★★ 名札的**锚点不能只写 `「`**：还有 `（独白）` 这一大类（2026-10-27）

只按 `名札「台词」` 剥离，会整类漏掉「名札 + 内心独白」——ネオンクラッシュ 实测 **940 行**：

```
リュウ・クロア（しつこい……！）        ⇐ 锚点是「（」，不是「「」
ソン・マシロ（……こっちだ）
小声でリュウ・クロア（うう、恥ずかしい……）   ⇐ 注记 + 名札 + 独白
警備員１（っ……こんなの、あんまりだ……）      ⇐ 名札无「・」（身份词+编号）
```

**完整判据（锚点＝任意开符号）**

```
名札形态   = [ァ-ヶー]{2,}(・[ァ-ヶー]{2,})+  或  身份词+编号（警備員１/店員２/兵士３/男１/女２/声１）
触发位置   = 名札形态后面紧跟「（「『
处理       = 从该开符号起保留；其前（注记 + 名札）全丢
```

**必须排除的「合法括号」（否则会毁正文）**

| 形态 | 例 | 为什么不能删 |
|---|---|---|
| 台词内动作/读音 | `「……（コクリ）」`、`テリトリーは陽樹（ヒキ）` | `（…）` 在台词/正文**内部**，是正文 |
| 人名 + 年龄 | `マヤ・カークランド（２６）職業：メイド…` | `（２６）` 是年龄 |
| 人名 + 罗马数字 | `【シアン・ブロフィワーズ（Ⅰ）】６０年前に…` | `（Ⅰ）` 是编号 |
| 双语对照 | `What's up？（何をしているのですか？）` | 英日对照 |

⇒ **判据**：`（` 内若是**纯数字/罗马数字**，或 `（` **前不是「名札形态结尾」**，一律不动。

### ★ 批量前必须逐行预览（这次踩了两次）

第一次用「行首 `キス` ⇒ 删」的粗糙判据，把 `キスをされると`、`キスの合間に` 这类**正常正文**的「キス」也删了；
第二次全批跑「注记+名札+（独白）」时，把宵闇 `マヤ・カークランド（２６）職業：…`、終遠 `【シアン・ブロフィワーズ（Ⅰ）】…`
的名札部分删掉，**毁正文 17 行**（靠 `.preNoteNameMono` 备份回滚）。

**铁律**：改之前先 `print` 出「将处理的每一行：删什么 → 留什么」，人工扫一遍；
改完再 `difflib` 对备份逐行复核。**「结果读得通」不等于「没删错」**。

### ★★★ Naninovel：`EmptyScriptLine` 是「注记块 / 正文块」的分界（2026-10-27 ネオンクラッシュ）

**症状**：一行里前半是演出注记、后半是正文，屏幕上只显示后半。

```
背景がブレている赤、青、緑に版ズレ加工。別々の思念であるとわかりやすくする為に、基調にする色を変えることで複数のイメージを見る。——手を触れさせた途端、この『壁』に込められた想い、声、匂い、様々な情報が脳に流れ込んできた。
└────────────────── 注记（不显示）──────────────────┘└──────────────── 正文（显示）────────────┘
```

**源结构**（Naninovel 的 `lines[]` → `references.RefIds[rid].data`）：

```
◆背景：白            ← 注记（`◆` 前缀，is_stage 能识别）
画面演出：…          ← 注记（`XX：` 形式，能识别）
背景がブレている      ┐ 注记块
赤、青、緑に版ズレ…    ┘
EmptyScriptLine      ★ 块边界
——手を触れさせた途端、 ┐
この『壁』に込められ…  ├ 正文块（多条 = 一句按显示行拆开）
様々な情報が脳に…      ┘
CMsg                 ← 这一行
```

**根因**：把 `EmptyScriptLine` 当「空行」穿透。作者用它**分隔注记与正文**，穿透就会把注记拼进正文。
`◆`／`XX：` 只能挡住更早的注记，挡不住「夹在标记与正文之间」的那块。

**判据（两层，缺一不可）**

| 层 | 判据 | 抓到什么 |
|---|---|---|
| ① 结构 | `EmptyScriptLine` = 块边界；CMsg 前**最近一块**若为注记则丢 | 28/29（本例） |
| ② 形态 | 行首标记剥离：`回想ここまで`／`セリフ合成ここまで`／`立ち絵(にモヤ\|ナシで\|IN\|OUT)`／`画面揺れ`／`暗転`／`場面転換`／`カットイン…`／`ポップアップ…`／`BGM…`／`SE：…` | 另 7 行（无 Empty，直接粘） |

**⚠ 例外必须复核**：Empty 两侧可能是**同一句被切开**，不是注记。

```
いつも使っている時の逆再生の音  ← Empty 前
読み取るのではなく解き放つ——…   ← Empty 后（缺宾语「を」⇒ 两侧本是一句）
```
⇒ 丢之前看「Empty 前那块的形态」：**若是制作指示（表情/立绘/画面/演技，无主语）⇒ 丢；若像正文前半句（与后块语法连贯）⇒ 保留**。
本作 29 例里只有这 1 例属于后者，已保留并在报告登记。

### ★★★ 名字窗是**记录内的独立首行**：删换行后变成「名字+正文」，锚点有三种（2026-10-27 ミストニア 67 行）

UTXT / 类似容器里，名字窗常与正文**同一条记录**，用框内换行 `0x00` 分隔：

```
#32119  エドワード⏎（『何か』はあったんだろうな。…）
#33161  名もない少年⏎（くそ、くそ、くそ！！）
#33236  ダニエル⏎『彼女が不幸を振りまく前に』
```

`clean()` 把换行删掉 ⇒ `エドワード（…）` / `ダニエル『…』`。所以名札的**锚点有三个**：`「`、`（`、`『`。

**名札形态的四种漏法**（早前只按「片假名+`・`+`「`」剥，全中招）：

| 漏法 | 例 |
|---|---|
| 单个名字没有 `・` | `エドワード` / `ジョン` / `ルーカス` |
| 身份词名札 | `名もない少年` / `救貧院の少年` / `露店の店主` / `若い貴族風の男` |
| 名札前还有舞台注记 | `ここに背景入れる・ローズ（…）` / `カットイン終了・ローズ（…）` / `幻影・ローズ（…）` |
| 回填后的主角名 | `アプローズ（…）` / `コティングリー（…）`（源里是 `%`／`&`，按回填值再剥一遍）|

**名札判据（关键：把「正文前半」排除掉）**

```
首行 ≤14 字
  且 不含标点（。、！？…「」『』（））
  且 **不以助词结尾**（は/が/を/に/で/と/も/の/へ/や/から/まで/より）
  且 （次行以（「『开头  或  首行是纯片假名）
⇒ 名札
```

反例（**不能剥，剥了吃正文**）：
`ジョンがエドからの『ランドルフを継がないか』…`（结尾「の」）／
`気になるのは『…』`（结尾「は」）／
`肩を掴むジョンの顔には『…』`（结尾「は」）。

**⚠ 一次误剥与回滚（必须记住）**：第一版判据只写「首行 + 次行以（「『开头」，把**台词首行**（`「あー、違う違う。そうじゃなくって。`）也当名札，
一次性误剥 **165 行**。**改前必须逐行 print「删什么 → 留什么」人工扫一遍**（这条已在本册别处写过，我这次又跳过了）。

**复查命令（剥完必跑）**
```python
PUNC=re.compile(r'[。、！？…「」『』（）?!]')
PART=re.compile(r'(は|が|を|に|で|と|も|の|へ|や|から|まで|より|て|ば|る|た|だ)$')
# 行首到「（」之间：长度≤14、无标点、非助词结尾 ⇒ 名札残留
```
本次结果：ミストニア 67 → 0；レッドベル 3 → 0；其余作命中项全是合法（`【アドルフ（Ⅰ）】` 罗马数字、`マヤ・カークランド（２６）` 年龄、`鳴雷神（ナルイカヅチ）` 读音、`武器（※枕）` 演出注）。

### ★ 剥「行内前缀」必须**回源验证**，否则把叙述删成残句（2026-10-27 白と黒のアリス 8 行）

用户复查（拿成品与重跑逐行 diff）时发现 8 行被削了句头：

| 成品（错） | 源（`(message ...)` 原文） |
|---|---|
| `「都合がよい」と思い直す。` | `慌てて「都合がよい」と思い直す。` |
| `「保護者」を強調して、スノウを睨みつける。` | `嫌味っぽく「保護者」を強調して、…` |
| `「隠し味」は、人を処刑する時に使うものだということを。` | `さっきお母様がタルトに振りかけた「隠し味」は、…` |
| `「安っぽい」「美味しくない」と言っていた…` | `カノンが以前「安っぽい」…` |
| `「紅茶の茶葉でぐずるなんて…」など皮肉を言った。` | `確か「紅茶の茶葉で…` |
| `「喜び」という感情が、胸から取り出して…` | `俺の抱く「喜び」という感情が、…` |
| `「嫌い」となじられたときも、…` | `私の嘘があなたに伝わり「嫌い」と…` |

**共性**：这些前缀都是**叙述**（副词／主语＋副助词／连体修饰），不是名札。
「行首短 + 后面紧跟 `「`」**不足以**判名札 —— 名札在源侧一定另有承载（名字窗单独给 / 记录首行 / `name-w` 宏）。

**硬规则**：任何「删行首前缀」的动作，必须先回源取该条 `message` 的原始字符串，
① 删的部分**不在**该字符串里 ⇒ 是名札（可删）；② 删的部分**在该字符串里** ⇒ 是正文（不许删）。
批量删前逐行 print「删什么 → 留什么」，并用**重跑 vs 成品逐行 diff** 收尾（diff 为空才算干净）。
