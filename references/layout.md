# 点击、成行与选项

## 成行状态

### 状态

维护点击段、页、窗口、姓名、宏及来源；先执行状态变更，再决定内容是否收取。
排版更新当前内容，等待结束点击段，清屏、翻页或替换结束页；页结束按[输出规范](output.md#输出规范)输出。
参数内符号不计点击。宏、命令的隐式等待，以及设名、调用、跳转和计时行为按实际处理确认。

共用段继承调用状态；只有文本或页界不同才保留调用变体。姓名包装见[名札与姓名](names-and-macros.md#名札与关联)。

### 映射

映射由已证控制流生成，核对来源顺序、页归属和准确拼接；同一解析器的文本与映射只能证明实现一致。
字段与修复见[行完整性](layout.md#映射与修复)，参数见[自检](verification.md#交付自检)，计数见[完整性](verification.md#完整性)。

### 格式定位

[KAG](engines/kirikiri.md)、[NScripter](engines/nscripter.md) 见专册，其他消息处理见[取证线索](display-cases.md)。
[混合编码 SPT](engines/spt.md) 的已证构建可复用消息替换与末尾等待策略，不重建通用页状态机。
FORIS-OS 的 `FUNCTION MESSAGE` 使用前一兄弟 RESOURCE 的指定 STR 参数；相同结构的选项按调用类型分类。
マスケティア 的结束记录与参数宽度见[格式线索](layout-cases.md#格式与成行)。

## 边界取证

用于未决显示边界；已证语义在适用条件内复用。输出要求见[规范](output.md#输出规范)，格式定位见[线索](display-cases.md)。

### 证据

| 级别 | 用途 |
|---|---|
| L0 | 处理实现、配置或实际显示确定等待、追加、替换、清屏及排版 |
| L1 | 自定界记录经独立证据确认显示单元 |
| L2 | 引号、空白、字数、频次和相似度仅定位疑点 |

只检查影响当前边界的实现与配置。摘要或地址变化只提示复核；字节消费完整、文本通顺或映射一致不能代替显示证据。

### 方法

| 缺口 | 操作 |
|---|---|
| 宏、系统脚本 | 追踪展开及等待、清屏调用 |
| 原生命令 | 定位分发、相关 handler 和状态读写 |
| 记录与显示关系 | 核对实现、实际显示或独立结构关系 |
| 静态证据无法区分候选 | 观察最小区分场景 |

按现有授权观察或推进游戏；需修改资源或注入时使用隔离副本。
磁盘材料不足才读进程。保存来源、配置、结论及必要画面，证据充分即结束。

### 容量与未决项

仅当自动翻页、溢出、截断或跨窗布局可能改变边界时核对容量。
先确认生效尺寸；元数据足够时不解码像素。已证上界可排除溢出，否则核对字体、缩进、禁则及行高，模型存疑再观察。
估算字数或他作偏移不生成页界；KAG 见[实现定位](engines/kirikiri.md)。

未决项记录候选、排除依据、缺口和下一条线索，继续独立工作；结构与覆盖见[完整性](verification.md#完整性)。

## 映射与修复

### 定位与修复

`struct_probe.py` 汇总 A 引号失衡、B 括号失衡、C 多段引号、D 多段括号，统计仅定位候选。
按源记录、控制流和显示状态区分点击、排版、整页合并、姓名及原文异常；不按标点配平或相似度拆合删文。
确认错误后修改提取规则，重建受影响范围并核对来源、边界、宏、姓名及行数；原文异常继续保留。
无源依据时记录缺口，不从成品猜页界，不修改 allow 掩盖差异。

`fix_wrap_pairs.py`、`fix_multi_brackets.py`、`merge_name_variants.py` 仅用于已证修复范围，不进入通用验收。

### 双版映射

品检声明与报告版式一致，参数见[自检](verification.md#交付自检)。已有映射使用以下字段：

| 字段 | 含义 |
|---|---|
| `pages` | 多段页数组 |
| `segments` | 从 1 起的连续段行号 |
| `merged` | 紧接段行的合并行号 |
| `source` | 可追溯源位置 |
| `merged_text` | 包装导致拼接差异时，提供已证准确合并文本 |

页间不复用行号。默认合并行逐字等于段行拼接；包装差异用 `merged_text` 校验。
缺行、行号错、拼接不符或版式冲突报错；已声明双版的映射至少含一个多段页。
映射须有显示语义依据，拼接候选不能判定或否定双版。

### 完成依据

边界、字符和未决项按[自检](verification.md#交付自检)验收，合法部分引号按来源分组，不要求 A=B=0。
报告记录版式、段行、多段页、总行数和未决项。

## 选项与分支

### 守卫块

HuneX 等变体可用 `_IF__ … _ZY` 表示守卫。
核对条件实际成立时执行还是跳过 body，按标签配对与栈消费；同变量不等于互斥。
相同条件的两块可能都执行，不删除后块。互斥条件内不同正文均属有效剧情。
只有证明同一显示事件的等效副本时折叠，不固定取第一支。
不含正文的演出守卫无需文本折叠。

### 重复

相同文本、周期及宏归一化仅定位重复候选。
按源位置、执行条件和显示用途区分编译副本、姓名变体和自然重复。
不使用重复长度、最近行数或相似度阈值删文；不同角色或分支的同文保留。
源码字面版本与宏版本按已证默认分支处理，不删除独有文字、结巴或标点。

### 选项载荷

选项可为内联记录、地址表、代码外数据区或连续页链。
参数按类型解析，字符串指针不要求落在指令自身区间，库函数常量不当正文地址。
名札、变量及章节 op 是否影响页界仍须核对显示处理，不统一作为断点。

D3P 变体可用连续 FFFF run 表示选项，样式前缀长度、填充与组界按真实布局确认。
系统菜单按整组调用用途分类，不按单词黑名单或全角空格数量排除。
宏链 FFE6/FFE7 各自消费完整载荷。

### 条件选项

Aromarie 等记录可带 eval 表达式；只在证明条件互斥且代表同一文案时合并等效项。
条件真值、变量和默认运行状态须确定，不按同文自动去重。
选项按源剧情位置输出，不追加全文末尾。

### 参数包

自定义 ComSelect 后可能连续带 ArgCondition、ArgBranch 等参数包。
已证变体中码≥45为 Arg、≤44为命令；范围、参数数量及跳转值须核对版本。
遍历完整组再提各文案，条件包不生成选项。组计数与来源核对用于查漏，不推广阈值到其他命令表。

### 提示文字

选项前文字可能由选择命令提交显示，即使没有单独等待标记也不能丢弃。
NScripter 需核对缓冲、select 及文本提交，见 [专册](engines/nscripter.md)。

## 成行特殊情况

### 空格与边界

全角空格可为缩进、排版分隔或语义词间空格。按真实显示保留，不全局删除或只保护字母之间。
一条语音和一条文本 op 不证明只有一次点击；软换行按 handler 确认。
连续记录、goto 和页标记分别核对状态，不以记录外观统一拆合。
页标记可能有多种结构形态，集合来自实际处理，不能把未识别的其余取值全部当断点。

共用导入或姓名变体的同文须确认执行关系，不按出现文件数、包含关系或默认名归一化直接去重。

### 字符范围

纯全角拉丁、ASCII 及标点可为正文；日文字符白名单只定位异常，不能用于过滤显示记录。
缺文本先核对引用、载荷及转换，不能以引号配平作为完整性依据。

### 内容分类

身体部位、演出及表情词可出现在剧情中，不按常用子串删除。
只在实际类型、调用或精确源位置证明非正文时排除；全匹配词表也不代替用途证据。

### 系统消息

错误关键词、活用形和资源名仅定位候选，不直接过滤。
来源命令和显示用途确定系统或调试内容；异常原文按源保留。
格式案例见 [取证](display-cases.md)，范围见 [完整性](verification.md#完整性)。
