# 脚本结构与显示调用

## 结构与字段

已识别格式先用匹配解析器核对字段编码、操作数宽度、游标及引用边界。跨平台适配可复用调用与栈模型，未知或失配处再查读取原语和相关 handler；不因某个字段变化重建整套 VM。Malie 的 PC/PSP 差异见[格式册](engines/malie.md)。
未知字节码从分发和操作数读取原语确定 schema，只追踪文本、调用与显示相关 handler。
循环、条件参数和变长数组按实际次数消费，保存 schema、版本和覆盖统计。编译剧情走[原生调用](script-structure.md#原生显示调用)，无需寻找 VM 分发器。
记录模式见[专册](script-structure.md#记录模式)，STCM2L 见[结构](engines/stcm2l.md#记录布局)，Unity 见[资源](engines/unity.md)。

### 编码与消息流

混合正文与控制码先按编码消费字符。CP932 前导区 `0x81–0x9F/0xE0–0xFC` 通常消费两字节，尾字节可等于控制码；边界检查剩余长度。
已证消息流可为 `7c <u16 id>＋可选76头＋正文＋07参数`；`07 00/01/02` 与其他 `07 XX` 的结束/排版语义按版本确认，`7e XX` 等转义整体消费。

### 宏与分支

编码与字形见[解码](decode.md#字段与编码)，槽及控制流见[姓名宏](names-and-macros.md#宏与动态文本)，名札见[可见性](names-and-macros.md#名札与关联)。
定长表由已知槽及地址反推 `base = address − index×stride`，核对其他槽、范围与内容。
姓名、地名、术语及姓/名可能用不同槽，空文本字段仍可能引用非空表项；频次、行距和最近姓名不能替代求值。

### 区段

按长度、地址表、尾部签名和引用区分代码、资源及元数据。HFU2/IKA 同名包装可能为 UI 或演出，成员索引不固定指向剧情。
前缀区亦可含正文；代码区外候选见[归档](archives.md#容器与读取)。

### YU-RIS / ERIS

已证 YSTB V300 正文为 `code91` 的 type=0 裸串参数，`code29 ES.SEL.SET` 提供选择，空参数可占位；只搜 4D 压栈串会漏正文。
`code30 arg#2` 等长日文块按实际日志用途分类。分别验证参数消费、分段长度、调用与显示状态；命令表用于定位，无需集齐命令名。

## 记录模式

未知或变体按头、表、长度、对齐和读取实现定结构；已识别格式复用适配解析器。
以下参数限已证构建。字符频次、计数一致或走到文件尾只定位候选；显示边界见[取证](layout.md#边界取证)，未消费区与引用见[完整性](verification.md#完整性)。

### 模式

| 模式 | 结构及核对 |
|---|---|
| STCM2 | addr、样式、0、L/4、1、L、text；样式段数及 padding 可变 |
| u16 长度串 | len、bytes、尾 NUL；核对字节/字符单位及是否含 NUL |
| u32 UTF-8 串 | len、bytes；混合编码按类型读取 |
| System-NNN | 地址表及对齐串槽，见[专册](engines/system-nnn.md) |
| 标签与载荷 | tag、labelLen、label、payload；一标签可带多串，标签为键 |
| 池与索引 | offsets/sizes、pool；区分有效项与容量，顺序按调用或表 |
| 双字节字形码 | 字符表索引与控制码混流；按宽度解析，未知槽登记 |
| 标签文本 | 命令、宏、正文、选择；不以物理行或 @ 前缀定点击 |
| printf 与姓名槽 | text、n×u16 slotId；核对端序和占位符 |
| Broccoli FF | FF、op、字段、载荷；文本 XOR FF，命令结构另核 |
| HuneX HDLG | 语言表与脚本引用；本地化键约束覆盖 |
| BlueImpact BSF1 | label 表、u16 op 和载荷；按真实读取原语定大小 |

### 指针与姓名槽

HuneX ALS 操作数可存 u32 串绝对位置，本构建 `0D 02` 可定位代码终点。
正文、全角选择、单字表及尾区按指针、布局和显示调用分类，不以池序、最后签名或无假名串定范围。

Takuyo `0xFC` 的 `%s` 后为 LE u16 槽：`30 02` 为 `0x0230`，非 `0x3002`。
按占位符消费槽并核对未知值；标签顺序查调用和分派表，零静态引用查动态入口。

### Broccoli FF / うたプリ

命令可为 `FF op idLE bLE cLE payload`，文本 XOR FF：

| op 或 id | 本构建 |
|---|---|
| op0A | 12B 文本头；id00CC 续行、07DE 段首、00D5 姓名槽 |
| op00 | 4B 无样式文本 |
| op0E,id0074 | 16B 选择头；邻近0003/0072组标记 |
| id07DD | 注音基底及后续正文 |
| 876E | 页内改行 |
| 32A4–32A6 | 演出标记 |

注音按语法取完整显示段，不用同文删除；memorial 查独有正文。工具 `scripts/utapri_extract.py`。

### HuneX HDLG

StarrySky `script_dialog_ja.hdlg`：HLZS 壳、HDLG、version、count、dataOffset、offsets；其他语言可提供键与引用映射。
`firstname/lastname` 及第二姓名槽按初始化求值；UI、标题和正文按键及调用分类，W 前缀不决定用途。
工具 `scripts/sspm_extract.py`；姓名求值见[宏](names-and-macros.md#宏与动态文本)。

### BlueImpact BSF1

Angel's Feather 标签表自 `0x04` 起，为 `name\0＋absoluteOffset`，空名以单00结束，之后为代码。
本构建 VM 分派：op>`0x38` 可为 CP932 串首，op≤`0x38` 为命令；不可用全库字符最值生成通用阈值。
部分 L 不决定实际消费：

| op | 读取 |
|---|---|
| 2F | u32 n＋ReadString(n) |
| 30/38 | skipstr |
| 31/32/35/36 | ReadString、skipstr及比较 |
| 34 | u16 |

offset=fileBytes 可为 EOF 空段，越界另报。行与页由行缓冲、行号重置及等待确定；串内控制按类型查源。
工具 `scripts/angelfeather_extract.py`。

## 原生显示调用

用于剧情编译进 ELF/PE 的构建；与解释型脚本区分。先确认程序段和地址映射，从少量叙事串交叉引用定位显示函数，只解码实际文本参数。

### 参数恢复

一次扫描相关可执行段建立显示、选项及包装函数的调用清单，随后在同一记录集补全字段；间接分派按表或相关控制流扩查。
先恢复常量、寄存器复制和栈内传值，仅对未决参数追踪前驱、内存来源和格式化返回缓冲。函数边界及调用约定决定状态重置，不要求完整反编译或枚举运行时剧情路径。

| 缺口 | 核对 |
|---|---|
| 地址 | ELF 段或 PE 节逐段转换 VA/文件偏移，不假定全文件共用差值 |
| MIPS 调用参数 | 延迟槽执行后取参；分支共用高位常量、likely 与浮点分支须按实际路径处理 |
| R5900 指令不支持 | 保留原字及地址，补解影响参数的指令；常规 MIPS 反汇编不完整，不能遇未知指令就结束函数 |
| printf/动态缓冲 | 沿格式化结果追踪到显示点；格式串和值分开记录，按[动态策略](names-and-macros.md#宏与动态文本)处理 |
| 包装及表驱动调用 | 展开真实调用或表项，标记共用来源；同一显示不同时消费包装层与内部转发 |

### 显示与覆盖

读相关处理函数的缓冲替换、追加、空参数、等待与清空语义。多文本参数不必然是多个点击；只有等待而未新增文本时不生成行。
同一选项表按源项收取，运行时可用状态或排列组合不自动新增原文；不同剧情调用同文仍保留。
覆盖按调用、文本字段和收排状态核对，未决字段单列；全字符串池不作为正文分母。来源、统计和显示反汇编各保存一份，验收见[完整性](verification.md#完整性)。

### Palais de Reine 入口

仅限 PS2 `SLPM_668.17`、SHA-256 `55ba49185b2ba783401f8ac7e4290e499358bbdfaa5cc6c0c7be9ff423f892c4`。
既有实现为工作区 `scripts/palais_reine_extract.py`，输入是光盘主程序 `SLPM_668.17`；仅提取主程序即可，不需解包 PDR.AFS。清理见[工作区](workspace.md#收尾与维护)。
正文 `0x13F180`、选项 `0x13EE40`、提交 `0x13ED40`、等待并清空 `0x13E950`、格式化 `0x1F2640`；详细映射和函数证据查本作报告。其他构建重新定位。

## 序列化字段

### 记录及页状态

id 连续或差值不证明页界。BOUND/C7/M91、CLOSE/INS 等作用按实际处理确认，
不从记录名或外观统一判断。talk 的 phrase 多段按已证字段顺序组合，再依据等待/替换成行。
同文后写可能为覆盖，也可能为独立对白，核对字典赋值及调用，不能只取最后版本。

### 多型记录

STCM2L 已证变体可混用不同头长：

| k | 头长 | 特征 |
|---|---|---|
| 1 | 44B | REF、self 和样式参数。 |
| 2 | 56B | 多参数，部分 p2 指向节点末尾。 |
| 3 | 32B | KIND 与文本对象后接裸续写记录。 |

类型指针及长度关系按本作校验。跨文件聚合可查变体和未知类型，
假名比例、串长及样式数不直接定义 TEXT/NAME/NOISE。
额外字典、人物资料或章节条目按显示用途处理，名札按 [姓名](names-and-macros.md#名札与关联) 关联。

### 长度冗余

SceneMasterVO 等序列化格式中的 `i32 X,u32 L,payload` 可能以 `-X-1` 冗余编码长度。
相等可定位长度字段，仍须核对解析器、后续记录及类型布局，不单凭等式排除字段标记。
没有标签时以实际对象 schema、读取顺序及引用确定位置语义；
后随同类短串只能定位姓名候选，不证明它是名札。

### 复用

记录签名、游标闭合、编码和显示语义分别验证，不按同引擎或同构建串复用所有常量。
边界见 [取证](layout.md#边界取证)，结构见 [模式](script-structure.md#记录模式)。

## 误导信号

用于当前判型、边界或解码疑点；通用流程见 [记录模式](script-structure.md#记录模式)。

### 编码与字符宽度

| 误判 | 正确核对 |
|---|---|
| 尾字节像命令即切开 | 先按真实编码消费字符，再处理控制语法 |
| 半角假名、PUA、稀有汉字即坏文 | 查字体、码表和源字节；同字可有多个槽 |
| 标准解码成功即可确认映射正确 | 核对实际映射和读取代码 |
| 图集物理顺序即码序 | 通过码表、索引及已知字形建立映射 |
| 字符似然或日文频次决定明文 | 仅作候选，不代替结构和已知内容 |
| 解码失败即删整行 | 保留来源，修复缺字或读取，登记未决缺口 |

### 记录与页界

| 误判 | 正确核对 |
|---|---|
| `align4(textBytes)` 就是记录长 | 核对 NUL、padding、双写长度及尾字段 |
| NUL、00 00 或连续地址决定消息 | 分别解释串边界与显示、等待、清屏 |
| offset0 是空项 | 按该格式长度和有效引用确认；0 可是池首 |
| msgid 唯一，可以直接建字典 | 先确认重复语义，来源索引保留文件和序号 |
| 无边界标记就续写或默认新页 | 核对实际处理，未知状态登记 |
| 同引擎的 D2/D3 语义相同 | 检查本作处理函数及配置，不凭句末比例定案 |

STCM2 的 slot、cmd 和构建布局可改变；记录指针也只确定记录范围，
不单独证明点击。见 [变体](engines/stcm2l.md)。

### 语义、引用与完整性

池序、数组序和归档索引可为排序或编译顺序，按调用或已证顺序表排列。
显示序列中相同文本可出现多次，不能按 ID、同文或相邻位置去重。
宏按槽定义及初始化求值；控制符按语法处理，保留显示基底。
FFFE 后接姓名宏不自动表示翻页。

旧白名单可能漏掉选择或特效命令；
按实际指令类型与载荷分组查未知类别，不以原始 opcode 字节搜索替代解析。
引用未命中须覆盖动态分派和入口，不能直接判弃稿或证明无正文。

### 载体与包装

日文零命中可能来自压缩或字形码；可见明文也可能是压缩流字面量。
PACK 的 nameLen 后字节可为密钥，必须核对读取代码和已知内容，
不能按高位比例或长度规律直接试所有变换。

PE 加 UPX 段也可为资源壳；先检查 overlay 和尾部目录，必要时再分析模块。
魔数或版权串可能属于资源、密钥或代码，按真实用途登记。
方法优先索引、参考实现和已知明文，不无界扫偏移或靠相似度选择结果。
