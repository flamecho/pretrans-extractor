# 工作区与维护

## 工作区与记录

使用指定工作区；当前默认 `<工作区>`。技能目录保存规则与通用工具，源与临时产物分开存放。

| 内容 | 位置 |
|---|---|
| 最终文本 | `提取结果/<压缩包名>.txt` |
| 解析报告 | `解析报告/<作品>_解析报告.md` |
| 字符基线、精确例外 | `解析报告/allow/` |
| 需长期保留的来源或显示证据 | `解析报告/证据/<作品>/`，仅按任务需要保存 |
| 本作解包、探针与派生文件 | `_work_<slug>/` |
| 可复用提取工具 | `scripts/` |
| 作品与工具记录 | 已有 `references/` |
| 引擎与格式知识 | 技能内 [引擎索引](engines/index.md) |

### 执行

Windows 文件操作使用 PowerShell 与 `-LiteralPath`；文本 I/O 显式指定 UTF-8。
交付文本设置 BOM 与 `newline='\n'`；Markdown 使用 UTF-8、LF、单个末尾换行，短标题、同级步骤或表格，块前留空行。
Python 使用 `-B -X utf8`；PowerShell 传递复杂代码时使用 UTF-8 脚本文件。
原生工具不支持 Unicode 路径时，才建立本作 ASCII 临时副本。

当前 Python：`<本地路径>`；7-Zip：`C:/Program Files/7-Zip/7z.exe`。
只安装当前工具需要的依赖。技能工具见[脚本索引](../scripts/index.md)，平台操作见[PSP](decode.md#psp-eboot)、[PSV](platforms/psv-pfs.md)、[Switch](platforms/switch-nca.md)。

### 探查与记录

目录只列相关层级，搜索限制路径和类型；大清单输出计数、分类及代表项，明细只查询当前疑点。
先看文件大小；`summary.json` 只查询总计和所需字段，`rows.jsonl` 按行号或源 ID 查询。工具已有摘要输出时直接复用，不把逐脚本统计、来源映射或工具目录全文送入上下文。
计数、异常、来源映射和边界查询共享解析结果，稳定记录以 ID 引用。批量查询独立问题；已有索引或映射能回答时不另写重扫源文件的探针，证据充分即结束。
单进程复用内存记录；跨进程需要时保存带源摘要及解析版本的缓存，未决结论和参数记入已有报告、摘要或 NOTES。后处理变化不重建解析结果；完整指令或事件转储仅为具体未决问题生成。
验证复用见[自检](verification.md#交付自检)，清理及文档维护见[收尾](workspace.md#收尾与维护)。

## 收尾与维护

### 清理

默认只归档需要复用的脚本到 `scripts/`、最终报告到 `解析报告/`，其他产物由用户自行删除。仅在明确要求删除时，核对本作临时目录的绝对路径与归属后执行；链接与目录联接只处理自身。
复用工具已在 `scripts/` 时不再复制。清理不触发重提、复检、全工作区扫描、记忆落位或额外保存主程序、证据包及临时文件摘要；已完成的验收结论留在报告即可。
归档前核对目标路径和同名文件。
成品缺失只记录现状，不推定原因或自动重新提取。

### 修订

共用规则保留一处，格式和条件流程按需链接；引擎册按实际格式归并，单作参数、统计和状态写入已有报告与工作记录。保留有效判据及适用条件，删除重复说明、口语、历史备注和无决策价值的例子。
合并或移除文档前核对调用方；不固定生成备份、进度草案或新增记录层。

| 变更 | 检查 |
|---|---|
| 文档 | 元数据、引用、路由、指令一致性及 Markdown；未改记忆时 `lint_docs.py --mem <skill>/references` 只检查技能 |
| 品检实现 | `selftest.py` |
| 收尾或页映射实现 | `test_workflow.py` |

验收复用见[自检](verification.md#交付自检)；需要时只选品检或 `wrapup.py` 一个入口，维护参数见[脚本索引](../scripts/index.md)。
仅改文档不触发游戏重提或脚本回归；仅要求发布时构建，并排除缓存、草案及游戏数据。
