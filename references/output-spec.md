# 输出规范细目（可执行版）

本文件把 `SKILL.md` §0 的规范展开成可逐条执行的规则。任何产物 txt 交付前必须全部满足。

## 1. 文件层

| 项目 | 要求 | 校验命令 |
|---|---|---|
| 编码 | UTF-8 **with BOM**（首 3 字节 `EF BB BF`） | `xxd -l3 file.txt` |
| 换行 | **纯 LF**，0 个 CR | `grep -c $'\r' file.txt` 应为 0 |
| 损坏字符 | **0 个 U+FFFD**（`�`） | `grep -c $'\ufffd' file.txt` 应为 0 |
| 占位符残留 | 0 个 `%s` / `%N` / `Name[` / `〓`（除非报告声明） | `grep -nE '%s\|%N\|Name\[' file.txt` |

> 写文件时用 `io.open(p, 'w', encoding='utf-8-sig', newline='')`，`newline=''` 保证 LF 不被转成 CRLF。

## 2. 行层（一次点击 = 一行）

- **切分依据**：真正结束"一页/一框"的指令才换行。
- **合并依据**：框内软换行一律合并成空格或直接相连（按原作排版：日文一般**直接相连**，不要插空格）。

常见"软换行"标记（一律合并）：

| 标记 | 引擎 |
|---|---|
| `\n`（字面反斜杠 n） | Takuyo gss / MNP / 多数自研 |
| `\`（反斜杠） | System-NNN / 自研「テキスト方式 ADV」 |
| `<br>` | KiriKiri DropWave |
| `^` | HuneX Ogre |
| `0x01` / `0x5C` | Unity CSR / TKG |
| `\r\n` | System-NNN（框内换行） |

常见"真换行 / 换页"（**另起一行**）：

| 标记 | 引擎 |
|---|---|
| `@n` | HuneX Ogre（框内再点一次） |
| `\`（NScripter 的翻页清框） | NScripter（与 System-NNN 的语义相反，勿混） |
| `[pb]` | KiriKiri |
| `<pb>` | LTEngine |
| 页断指令 | 各自引擎 |

## 3. 控制码清理

| 类别 | 例子 | 处理 |
|---|---|---|
| 着色 / 颜色 | `$ @ #`、`\c`、`#RRGGBB`、粉/蓝/紫标记 | **删** |
| 演出 / 等待 | `@w<n>`、`@h<n>`、`!s0`、`!d300`、`@e` | **删** |
| 注音 / ruby | `漢字(かんじ)`、`<基,読>`、`%R<读音>%R<字数>正文` | 留基字，**只删读音部分** |
| 图标 / 精灵 | `^:s/…;`、`exec_dll gaiji` 映射的字符、`#心` | **删或替换为语义符号**（如 `♥`） |
| 说话人名 | `name "…"`、`_MTLK`、`06 00 <nameid>` | **不进正文流**（按规范不加前缀） |
| 全角空格缩进 | U+3000 | **保留**（是正文的一部分） |

## 4. 变量 / 占位符行内替换

- 主角名：`%s` / `＊Ａ` / `[橘]` / `《鈴音》` / `%h1` → **替换为实际姓名**（用作品默认名）。
  默认名来源：`Gameexe` 配置、`SystemInfo`、脚本内 `mov $name`、eboot 串表。
- 术语表引用：`7e XX` → 查术语表得实际词。
- 名词 form：姓氏 / 名 / 全名分开的码 → 按 form 取值。
- 无法静态求解（运行时计算、玩家输入）→ **保留原 token** 并在报告单列，**不猜**。

## 5. 词典 / 追加数据档

- **用語辞典 / 辞書 / 豆知識 / TIPS**：`【見出し語】解説文` **一行一条**、**无读音**、条内换行合并。
- **并入 `_全文本.txt` 末尾**，用一行分隔标题标识区块；**不拆独立文件**。
- 头图、缩略图、读音假名栏 **不入正文**。
- **图片承载的正文**（纹理/逐张图片）→ 不提取，报告注明"需 OCR"。

## 6. 顺序

- **游戏内点击顺序**，不是文件名字典序。
- 入口 → 调用图 DFS 前序去重 → 奖励/附录脚本置于末尾。
- 多盘（PS2 等）分开文件。

## 7. 报告（随成品一起产出）

每个作品输出一份 `_解析报告.md`，至少含：

1. 源与容器链路（如何从原始 dump 解到文本层）；
2. 引擎 / 脚本格式判定（魔数、记录结构、操作码表）；
3. 字符层结论（码表、替换槽清单、外部核对结果）；
4. **未解析码位单列表**：码 / 次数 / 原句 / 可能读法；
5. 排除项（测试档、他作遗留串、重复事件 CG 等）与判据；
6. 行数统计（正文 / 选项 / 标题 / 系统 / 词典分列）。
