# 输出范围与格式

## 输出规范

### 范围与格式

指定范围优先；未限定时按下表收取。交付原文文本及解析报告，文本为 UTF-8 BOM、LF、无空行，不翻译或润色。

| 内容 | 处理 |
|---|---|
| 正文、额外剧情、回想独有剧情、叙事资料 | 按记录、调用和显示用途收录 |
| 剧情选项 | 按源顺序一条一行；无文字图片选项跳过 |
| 图像、影片文字 | 收可见叙事文字，见[媒体文字](output.md#媒体文字) |
| 辞典 | 合并排版换行，以 `【词条】释义` 追加末尾 |
| 系统菜单、帮助、存读档、调试串、名字字库、日志副本 | 排除 |

文件名、长度和频次仅定位候选。文本沿用源压缩包名或作品名，不加版式后缀，不另交姓名表或 UI 文本。
解码失败、未映射 PUA、控制码及未授权的变量残留须解决；原文异常登记来源，不以 `〓` 猜填。
已指定保留原始动态模板时沿用该策略，见[宏与动态文本](names-and-macros.md#宏与动态文本)。必要值未定且无适用策略时记录位置和范围，请求所需信息并继续独立工作。

### 点击与页界

每次点击新增文本一行，同次点击的排版换行合并；等待而无新增文本不生成空段。
清屏、翻页或已证记录与配置确定页界。同页多次点击先列各段，再列整页合并行；单段页只列一次。
一次点击跨多页时按页输出。

状态与映射见[成行](layout.md#成行状态)，未决边界见[取证](layout.md#边界取证)。

### 姓名与验收

默认将可见名札关联到台词或心声，旁白不冠名；指定姓名策略优先。
宏、别称、匿名及包装见[名札与姓名](names-and-macros.md#名札与关联)。
按[完整性](verification.md#完整性)核对覆盖，按[自检](verification.md#交付自检)验收；字符机制见[台账](verification.md#字符台账)，结构异常见[行完整性](layout.md#映射与修复)。

## 媒体文字

### 定位

仅在提取范围包含媒体文字时使用。按索引、类型与剧情调用定位载体，已证装饰和按钮状态按组排除；
未知叙事载体再检查代表内容，覆盖存疑时扩大检查。脚本文本不能证明影片无字幕。

### 核对与收录

收可见叙事字幕、章节和幕间标题，排除 Logo、制作署名及操作菜单；歌词仅收实际显示内容。
保留原文空格和标点。

影片总览用于定位，在文字出现、变化和消失处加密检查；总览无法排除短暂字幕时连续检查相关时段。
渐入或同画面连续补全的一段文字按完整内容合并，独立替换或显示的文字分别输出。

转录按剧情调用位置输出，不同剧情调用分别保留，菜单重播和按钮多状态不重复收录。
图片文字用整图或联系表核对，疑难字再放大；字形编码问题见[字体码表](decode.md#自定义字体)。

### 复现

保存资源标识、源位置或时间段、已核对转录和必要画面。转录固定于提取器或数据文件，复现无需重新识别媒体。
证据复用与验收见[自检](verification.md#交付自检)。
