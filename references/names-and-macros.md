# 名札、姓名与动态宏

## 名札与关联

### 显示与关联

指定策略优先；默认关联可见名札到台词或心声，旁白不冠名。
可见性由实现、脚本和配置确定，存疑才观察。独立窗口、图层或字段不证明隐藏。
补充脚本说话人时，正文别称及匿名优先于后台真名。

姓名继承、重置、同页多人及跨页行为按显示状态处理；设名仅在已证语义下结束页。
剥除包装，保留字形、装饰和原文空格，不加冒号或重复冠名。
段行与合并行按已证姓名状态包装，正文已有姓名不重复冠名。
源码明确无引号台词才补 `「」`，部分引号按源保留。
称谓、编号、复合名和匿名可合法，外形或角色表缺项不决定过滤。

### 宏

从槽定义、初始化、输入和渲染求值，采用源码默认值、确定表达式或指定值。
只替换宏，保留字面姓名；不同槽按定义组合，不重复填 UI 回退值。条件求值见[姓名宏与表](names-and-macros.md#宏与动态文本)。
按嵌套语法求值和剥样式，保留注音基底；未知标签按类型调查。未定值按[输出规范](output.md#输出规范)处理。

### 混排与验证

| 候选 | 来源依据 |
|---|---|
| 名字前的身份或状态词 | 名札字段、正文载荷与实际显示 |
| CommentScriptLine、EmptyScriptLine、台本标记 | 命令、宏及显示用途；同块可含正文 |
| 人名后的年龄、编号、动作或读音 | 原记录用途，不统一删括注 |
| 同点击多段对白或心声 | 姓名与显示状态，括号不定义页界 |

只剥已证不显示的注记，保留同块正文；格式线索见[姓名注记](names-and-macros.md#姓名注记)。
按状态变化、宏和异常抽查，前缀统计只查遗漏。疑难身份才[外查](verification.md#外查与报告)。
姓名来源及策略记入映射；修复见[行完整性](layout.md#映射与修复)，NScripter 见[专册](engines/nscripter.md)。

## 宏与动态文本

名札关联见[姓名策略](names-and-macros.md#名札与关联)。本册处理槽、动态值和条件求值。

### 动态策略

从本作既有参数或报告取已确认的槽值；区分原有模板和解析失败产生的占位符。

| 目标 | 处理 |
|---|---|
| 展开文本 | 求源码默认值、确定表达式或指定值；未定必要值按[输出规范](output.md#输出规范)处置 |
| 已授权保留模板 | 保留源 `%s/%d` 等语法，登记格式串、显示来源和行号，不猜值或枚举运行时组合 |

仅限脚本文本的任务，展开或保留模板都不读取范围外姓名、地名、物品或存档值。必要值缺失且没有既定策略时一次列出所缺槽，请求取值并继续不依赖这些值的工作；源中称呼与别名不证明默认姓名。
模板及精确例外从来源映射自动生成，按共同规则分组核对；字符基线仍须核实，授权模板不豁免其他错误。

### 槽与表

| 线索 | 核对 |
|---|---|
| `FF08` | 已证变体为一人称，默认私；不等于姓名 |
| `FFE6/FFE7` | 已证变体为姓、名；逐作确认初始化 |
| 高码槽 | 可为配角、称呼或术语，按定义求值 |
| `07 ff ff 02 <u32 index>` | 已证术语表引用；核对表头、逻辑编号及其他引用 |
| `＄默认名`、`＠` | 按语法区分姓名插入、显示名和内部名分隔 |

姓、名、全名、昵称及宠物可使用不同槽。名札空 run 不结束后续读取；字面名转宏可能对应剧情改名。
保存槽、源位置和求值依据，转换在提取器中完成；覆盖见[完整性](verification.md#完整性)。

### 分支求值

沿控制流追踪赋值、追加、条件和调用状态，在显示点展开。
保留不同剧情取值；同变量未写入且无未知调用影响时，重复条件保持同一结果，避免生成互相矛盾的组合。
仅合并后续显示状态等价的路径，不将各槽候选值作无条件笛卡尔积。
不能确定的运行索引或值记录范围，按[输出规范](output.md#输出规范)处理。

## 槽文本与候选

### 行式姓名候选

短行、无句读及下一非演出行以引号开头可定位姓名候选，不能据此全局删除同名行。
向前查看只跨无状态影响的演出指令，不跨分支、脚本名或标签；地点及选项也可能是短行。
内部 ID 与显示名可能相邻，称谓、团体和未知人物均可能合法。
姓名须回源确认可见性和关联，按 [姓名规则](names-and-macros.md#名札与关联) 输出，不把候选集合当排除表。

### 多槽文本

SKTH 等格式可把一页拆为多个 `u32 字段 + CP932 文本` 槽，槽内 `0x0A` 可能为排版换行。
不能把全部低字节当终止，也不能据括号配平合槽。按容器、引用及显示状态确定节点集合与页界。
回声去重须证明重复来源，不使用最近若干行同文过滤；孤立括号片段也须回源修正。
名札依显示状态关联，不凭行尾空格删除。

### gss 槽求值

| 命令 | 作用 |
|---|---|
| `0xfd (6,slot)(3,text)` | 赋值。 |
| `0x107 (6,slot)(3,text)` | 追加。 |
| `0xfc (6,slot)`，无字面串 | 打印当前槽。 |

维护槽状态，在打印点输出，不能在赋值点输出碎片。
`0xfc` 无字面串不等于空指令；`0xfd` 有日文串也不等于正文，姓名槽按名札规则处理。
槽含未知值时记录未决项，覆盖统计包含该缺口。

## 姓名标签

通用规则见 [名札与姓名](names-and-macros.md#名札与关联)。识别名札后按可见性关联正文；
独立窗口、短串、标点或字符种类不构成删除依据。

### STCM2L 名札异常

| 情况 | 处理 |
|---|---|
| 后续正文以 `「`、`（`、`『` 起头 | 都可用于定位候选，仍须确认槽位 |
| 名札槽末尾多一个 `。` | 核对同角色正常槽及源码；仅处理已证异常包装，保留正文句号 |
| `U+F8F3` 等 PUA 填充 | 根据字体或字段语义移除已证填充，不删除整个 PUA 区 |
| `？？？`、拉丁姓名、合署名 | 确认显示用途，不能因无汉字或假名排除 |

アンジェリーク 魔恋の六騎士的 `script/03142` unit 2265 出现 `ジョヴァンニ。`，
相邻同角色槽无句号，可作为异常定位点。VitaminZ 的 `0x44` 正文记录可能直接含
`姓名「台词」`；这是源文本，保留姓名，外部名札不再重复冠名。可用 `0x3E` 表核对角色，
不能把姓名白名单用于删除正文内人名。

Python 起首判断使用 `bool(nxt) and nxt[0] in '「（『'`；
`nxt[:1] in '「（『'` 对空串也为真，会把正文首句误判为名札。

### 选项保护与独立表

先按选择命令和组引用识别选项，再处理正文与名札。短选项不能经过裸名过滤。

マイナスエイト的 `xls/0` 为 `96 B` 定长表：

| 字段 | 字节 |
|---|---|
| group | 16 |
| 文案 | 64 |
| 场景名 | 16 |

脚本的 `select` 与组名位于记录偏移 24；在对应选择调用处插入组内选项。
核对表组、脚本引用及未引用组，解释重复引用，不能要求所有变体一组仅引用一次。
`xls/100` 为邮件件名及差出人 UI；邮件正文在脚本中，按实际用途分别收取。

### Daisy2 DDP 字面换行

`<名字>\n<正文>` 的第一个字面 `\n` 也可能只是正文软换行。
`scripts/dystopia_extract.py: split_name()` 的本作分支为：

1. 首段为空：无名札。
2. 首段以 `「` 或 `『` 起头：按正文处理。
3. 首段为 `？/?/…/・` 组成的已证占位标签：按名札槽处理。
4. 首段 ≤12 字、次段以 `「（『` 起头、首段无句末标点：名札候选。
5. 其余：保留正文。

上述形态须结合槽位证据使用，不跨作直接删除。分类前后核对正文覆盖，
因为误删首个软换行前的正文时总行数仍可能不变。

### YKC/YKS 前缀命令流

`scripts/jade_yks.py: classify()` 处理 `[0x13][X][Y]` 的 NUL 结尾 CP932 串。
本作存在正文缺 `0x13` 的异常，须基于已解析 token 上下文定位，不能按长度或频次猜名札。

| 前一 token | 本作分类线索 |
|---|---|
| 已证 ASCII 命令、资源串或 u32 参数 | `X` 位于名札槽 |
| 已证正文串 | `X` 可能是连续正文 |
| 无前项 | 保留正文候选，核对入口及记录语义 |

`Takashi/T1411.yks` 是缺前缀长文的定位案例。`--audit` 可输出槽位分类。
ASCII 或“含假名”本身不能定义 token 类型；使用命令解析结果。

## 姓名注记

先确认记录用途和显示状态，再应用本作分类规则。名札显示要求见 [姓名规则](names-and-macros.md#名札与关联)。

### Unity CMsg 制作注记

レッドベル的 `Comment` 可存正文、名札或制作注记。引号异常、句长、敬体和制作用语
只用于定位候选；`EmptyScriptLine` 也不能单独证明分页。

| 证据 | 用途 |
|---|---|
| `CMsg`、`@cMsg` 及显示调用 | 确认正文归属和消息边界 |
| `◇SE:`、`@ //` 等已证注记标记 | 识别制作指令，核对未标记长注记 |
| 制作用语或无句点敬体结尾 | 产生注记候选，须检查调用及上下文 |
| 同场景、平行版本及相邻页 | 检查正文连续性和改稿副本 |

`scripts/redbell_dialog.py` 可定位页内非末行已闭引号及多名札消息。候选可能是双人对话、
原文笔误或制作残留；不凭出现次数删除正文或拆页。源中已有的异常标点保留并登记来源。

本作曾用 `PROD_ANY` 和 `(?<!ま)(します|ください|ません|ます)$` 定位未标记长注记。
这些条件依赖本作写法，不能跨作作为排除规则。修改过滤器后检查命中源记录和输出差异，
确认仅移除了已证制作内容。

### 名札归一化

同消息可出现多个角色标签。分别关联对应正文，不据此推定改稿残留。
`#`、`・` 前缀及全半角数字只在已证包装范围内归一化；不全局修改姓名。
未知可见名札仍须输出，隐藏或制作标签才排除。保留全部正文，点击边界按显示语义取证。

### ときメモ GS1–GS4 的 0503 块

相同块骨架不保证相同语义；`0317 0402 0104` 在 GS3 同时用于选项和名札正文。

| `0503` 数量 | 本族已证用途 |
|---|---|
| 0 | 语音或资源骨架 |
| 1 | 可含旁白、结局叙述，不能因单记录排除 |
| ≥3 | 选项组候选，按引用确认 |
| 2 | 名札＋正文或两个选项，结合名表及选择调用分类 |

姓名来源为 `lang/ja/initialize.assetbundle` 的 `string_table`：
`AdvNameCh*`、`ExtraProfileCh_*`、`AddressBookAddress_*` 及固定 `主人公`。
姓名字段按全角空格拆姓、名。注册 label 可能同时是选项文案，名表命中也须核对用途。

已有分类器的局部回退条件包括：去样式前缀后长度 ≤9、无句读、非 `（` 或 `｛` 起头，
结合末字及块类型判断；不能把这些形态提升为跨作名札定义。选项对判别的对话标记集包含
`「」（）()。！？…―～♪∋∈▼、!?`，遗漏半角 `!?` 会误判台词。
`OPTION_ONLY` 只登记本作已核实例外。

`ダミー`、`デバッグ`、`テスト`、`セリフ`、`サンプル` 等标签及
`[A-Za-z]{1,2}\d{2}_\d{2}_\d{3}` 可定位调试候选；只有确认正文实际为脚本注释或不可达调试内容才排除。

### Takuyo gss 调试选项与槽形选项

ソラ*ユメ的 `c808` 在 INIT 由 `0x25` 置 0；全脚本无置 1，结合执行入口可判调试分支不可达。
查写点、条件与目标标签，不能用“前 N 条出现调试旗”识别整个选项组。

| 命令 | 语义 |
|---|---|
| `0x30`、`0x36`、`0x3a` | 构造条件 |
| `0x22(T)` | 条件假时跳转 |
| `0x23(T)` | 标签 |
| `0x5c` | 选择组 |

本作条件真区间由紧邻的 `0x36(flag==1)`、`0x22(T)` 和后续最近的同名 `0x23(T)` 界定。
仅排除处于不可达区间内的组；`0x36 → 0x18 goto *_end` 可能在调试时跳过正常选项，区间外内容保留。

选择组同时存在行内及槽形文案：

| 形态 | 读取 |
|---|---|
| `(count,"文本,FLAG",...)` | 取最后一个 ASCII 逗号之前 |
| `0xfd(slot) ← "文本:FLAG"`，后由 `0x5c` 引用 | 取冒号前文案，维护槽的清空与赋值状态 |

仅收 `0x5c` 实际引用的槽；本作为 `2006/4806/7006/9806/c006`。
`d004`、`2402` 可能存立绘或名札，不作为选择文案收取。
`0x10c` 格式化写入的内容仍须按可达性和显示用途分类。
